# 米作り365（kome365.html）の 改善ループ

西尾の 田んぼ 一枚で、**スワイプ だけ**で 1年の お米づくり（種もみ → 苗 → 代かき・田うえ → 水管理・中干し・溝切り・追肥・穂肥 → 出穂 → 登熟 → 稲刈り → 乾燥 → 検査）を 進める ゲーム。運営者の 指示は「米作り365は スワイプする 楽しさを 軸に」。
1周ずつの 記録・出典・遊び方は `docs/kome365.md`（まず ここを 読む）。

## ぜったいに 守る こと

- **返事は 日本語**。docs も 日本語。
- **本物に ついて 書く ことには 出典を つける。出典が ない ことは 言いきらない。** 吹き出しの 注（`<span class="src">（栃木県）</span>`）と docs の 出典を そろえる。出典が 弱い ものは docs の「作らなかった・言いきらなかった もの」に。
- **ボタンは「はじめる」「もう一回」（と 音の 切りかえ）だけ**。ゲーム中は スワイプ だけ（↑水を 入れる・↓落とす／まく・→あした・←しごと／見る）。新しい 操作は スワイプに 割り当てる。
- **ほかの ゲームの 名前・絵・音は 使わない**。音は WebAudio で 作る。こめつぶ・スズメの 絵は この リポジトリの もの（ミシン糸と 共通）。
- **素朴な かわいさ**（米屋の 手書き POP・はんこ・田んぼの 生きもの。アニメ調・キラキラ・広告っぽさ では ない。お客さんは 50〜80代も）。字は 少なく、こめつぶの 短い 吹き出し、ていねい語。`.claude/skills/mishin/SKILL.md` の「素朴な かわいさ」の 節を 守る。
- **スクショ・試しの 台本の 出力は リポジトリの 外**（`KOME_OUT`）。
- 作業は セッションで 決められた ブランチ（いまは `claude/kome365-1`）。**マージ・PR は 運営者が 言った ときだけ**。main には push しない。
- コミット・コード・docs に **モデル名を 書かない**。コミットの おわりは セッションの クレジット 2行。
- 本番の「米づくり365」（ricepia.jp/kome365/、Mac 上の 別の git。engine.js・field3d.js は 変更禁止）とは 別の 試作。運営者が「どちらを 続けるか」を 決める。

## 1周の 流れ

1. **何を 直すか きめる**。運営者の 声が あれば それ。なければ まだ 見て いない 面：スワイプの 手ごたえ／お客さん目線（吹き出しの 矢印だけで 通せるか）／むずかしさ（遊び方で 差が つくか）／リアルさ（出典）／かわいさ／コード（`/code-review medium origin/main...HEAD -- kome365.html tools/kome365`）／小さい 画面・横向き・字 200%／はじめて 開く とき。2〜3周 ごとに コードレビューを はさむ（直した あとで こわれが 見つかる）。
2. **別の エージェントに 辛口で 見て もらう**（general-purpose・バックグラウンド）。たのみ方は 下。返って きた 指摘は コードと 出典で たしかめて から 直す。
3. **調べる**（リアルさの とき）：WebSearch で 農林水産省・県の 普及・農研機構・全農。わかった ことと URL を docs に。YouTube や いくつかの サイトは この 環境から 開けない。
4. **作る**：`kome365.html` を 直す。本物に もとづく 所は 吹き出しに 注。
5. **確かめる**：`node tools/kome365/check.js > <スクラッチ>/check.log 2>&1 && …`（終わりの 値で 止める）。しくみを かえたら `node tools/kome365/playtest.js`（約 8分。10分 こえると バックグラウンドに なる ので、単体で 回す）。`shots.js` と `shots.js 360 560` の `sheet.png` を 自分の 目で 見る。新しい 確かめは「こわれた 版で 落ちる」ことも 見る。
6. **記録**：`docs/kome365.md` に「### N周目（テーマ）」。何が どう だったか → どう 直したか、出典、作らなかった もの。
7. **コミット・push**：題は「米作り365：…（サイクルN）」。`git push -u origin <ブランチ>`。
8. **公開**：`python3 tools/mishin/to_artifact.py kome365.html <スクラッチ>/kome365.html` → `docs/kome365.md` への リンクを GitHub の ブランチの URL に 置きかえ → Artifact の publish（同じ file_path で 同じ URL：https://claude.ai/artifact/LMq6Nz4WmncgCgXEDCUq7e）。1日の 上限（200回）に 当たったら 次の 周で（UTC 0時に 戻る）。
9. **伝える**：何を 直したか、確かめた こと、本物の スマホで 試して ほしい 点。
10. **次の 周**：`send_later` で 3分 後に。運営者の 新しい 指示が あれば 優先。「一時停止せずに 進める」が 運営者の 指示（2026-11-07）。

## 学んだ こと（やらかしと 決まり）

- **手で コマを 進める テストでは 時計も `K3.step` の 時間**（`now()`）。本物の 時計を 見ると 台本の スワイプが ぜんぶ「はじき」に なる。ゆっくり＝24コマ（0.4秒）、はじき＝3コマ。
- **吹き出しは かならず 更新する**（`narrate()` の 末尾は 既定の 一言）。古い「↓で 中干し」が のこると、↓が 効かず 詰む（10周目）。吹き出しだけで 遊ぶ お客さん（`check.js customer`）が 通せる こと。
- **class 名の 衝突**：`#talk.pop`（吹き出しの 弾み）と 新しい `.pop` が 衝突して 吹き出しが 画面いっぱいに（9周目）。新しい class は 一度 grep。`check.js fit` が すぐ 見つける。
- **`setPointerCapture` は try/catch**、`pointercancel` は なかった ことに（8周目）。テストの 指は id 1 だけで なく id 2 も。
- **HUD は 言った 時・画面が かわった 時に はかる**（`measure`・`TALK_H`・`HUD_H`）。毎コマ `offsetHeight`・`getComputedStyle` を 読まない。
- **はじきの 日数**：ふつうの 速さ（0.6px/ms まで）は 1日、1.5px/ms で 4日、3px/ms で 9日、最大 10日。引いて 止めて はなすと 1日。実機で さわって 決める 数は docs の「好みで かえられる 数」。
- **ゆっくりの ↓ は 2.5cm のこす**（1cm だと 翌日 0 で ↑↓の ピンポン）。空に するのは はじくか もう一度。
- **むずかしさは ボットで 見る**：ふつう（矢印どおり）は 一等に なって よいが、ほったらかし・せっかち・のんびりは 半分 以上の 年で 二等 以下、みずびたしは 収量 半分 以下。等級（本物の 規格）とは 別に「出来ばえ」の 点で 差を 見せる。
- **絵は 1回 かいて はる か 軽く**：毎コマ 重い 絵を かかない。`check.js perf`（1コマ 60ms）。
- **古い Safari で 止まる 書き方を 使わない**（正規表現の 後読み など。`check.js syntax`）。

## レビューの たのみ方（別の エージェント・general-purpose・バックグラウンド）

共通：日本語で。リポジトリは さわらない。作業は スクラッチの 下。`docs/kome365.md` を 読む。`window.K3` の 使い方、本物の タッチは `tools/kome365/helpers.js`、見本は `check.js`・`playtest.js`、Playwright は `require('playwright')`（install 不要）。390×844 と 360×560。影響の 大きい 順に 7つ、証拠（数か スクショの 道）と 具体的な 直し方（関数・変数・新しい 値）、700〜800字 いない。

- **スワイプの 楽しさ**：指の 動きと 田んぼの 反応が 直結しているか、慣性・はね返り・音、はじきの 日数が 実機で 扱いやすいか、← の しごとが 場面で わかるか。
- **お客さん目線**：50〜80代・片手・ルールを 読まない。どこで 詰まるか。
- **面白さ**：もう一回の 理由、だれる 区間、判断の 考えどころ、失敗の 声。
- **リアルさ**：出典と 吹き出しの 注が 合っているか、言いすぎ。
- **素朴な かわいさ**：`sheet.png` を 見て、足す・へらす 所を 具体的に。
- **コード**：`/code-review medium origin/main...HEAD -- kome365.html tools/kome365`。
