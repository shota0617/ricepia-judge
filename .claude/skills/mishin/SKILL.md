# ミシン糸 一本どり（mishin.html）の 改善ループ

米袋（30kg の クラフト紙の 袋）の 口を とじた ミシン糸を、本物の 手順で ほどく ゲーム。
コイン精米機に 来た お客さんが 糸の 取り方を おぼえる「れんしゅう」（`mishin.html#coin`）と、タイムアタックが ある。
1周ずつの 記録と 出典は `docs/mishin.md`（まず ここを 読む）。

## ぜったいに 守る こと

- **返事は 日本語**。docs も 日本語（このリポジトリの 書き方に そろえる）。
- **本物に ついて 書く ことには 出典を つける。出典が ない ことは 作らない・言いきらない。**
  - 出典が 見つからない ものは docs の「作らなかった もの」に 書く（例：糸が ぬける 速さ・音、縫い目と 縁の 距離）。
  - 出典どうしが くいちがう ときは、今の まま に して 言いきらない（例：1本糸の 袋の ほどき方）。
  - **運営者が 本物の 袋で 確かめた ことは いちばん 強い 出典**（例：「白糸は 自然に ぬける」）。docs に「運営者が 確かめた」と 書く。
- YouTube・いくつかの 日本の サイト（山口紙袋・木下製粉・農家の ブログ など）は この 環境から 開けない（プロキシで ことわられる）。WebFetch が だめなら WebSearch の 要約で 引く。開けない ときは そう 伝え、ネットワークの 許可の 場所を 案内する（`read_documentation` の `environment.network`）。**開けない まま 新しく 言いきらない**：docs に「出典が 弱い・ない・くいちがう」と ある ものは「（〜の 説明）」「〜という 方法も」の 形に（56周目）。
- 作業は セッションで 決められた ブランチ。**マージは 運営者が「マージ」と 言った ときだけ**。
- コミット・コード・docs に **モデル名を 書かない**。コミットの おわりは セッションの クレジット 2行。
- スクショや 試しの 台本の 出力は **リポジトリの 外**（スクラッチの フォルダ。`MISHIN_OUT`）。
- 運営者が 決めた ことを くずさない：
  - タイムアタックは **二本指で つまむ**（れんしゅう だけ 1本指でも よい：片手の お客さん用）
  - **白糸は 赤が ぬけたら 自然に ぬける**（白糸を 引く のは 引っかかった ときの 直し方 だけ）

  - **素朴な かわいさを 随所に**（運営者の 声）。下の「素朴な かわいさ」を 守る
  - **説明の 字は やめて、こめつぶとの 会話に**（運営者の 声「文字を 廃止して。素朴な 可愛い キャラクターとの 会話」。74 周目）。ゲームの 画面は こめつぶの 吹き出し（`drawMsg`・`talkLine`）、題・れんしゅうの 帯・まとめ・結果は `.talk`（こめつぶ＋吹き出し）。袋の 上・メーターに 字を 書かない（矢印・輪・指の 見本は よい）。数（点・時計・袋の 数）と 袋の 印刷は そのまま。出典の 注（「〜の 説明」）は 吹き出しの 中に のこす

## 素朴な かわいさ（運営者の 声：「素朴な かわいさを 随所に 散りばめて」）

ねらいは **米屋の 手書き POP・はんこ・田んぼの 小さな 生きもの** の ような、ほっこり する かわいさ。アニメ調・キラキラ・広告っぽさ では ない。

- **かざりは 手がきの 線**：少し ゆれた 線、まるい 角、クレヨン・マーカーの ような 色（クラフト紙・藍・朱・稲の 緑）。キャンバスに かく ときは 線を 少し ふるわせる（まっすぐ すぎない）。
- **登場する もの**：こめつぶ（点の 目と 小さな 口だけ）、スズメ、稲穂、おにぎり、はんこ（「よくできました」「済」）、手がきの 吹き出し・矢印。顔は 点の 目 だけ くらいに 控えめに。
- **袋と 糸は リアルの まま**：Blender の 袋・糸・縫い目の 上に かざりを かぶせない。かわいさは 袋の まわり（空・床・余白・画面の 字・おわりの 画面）に。ほどき方の 手順を まちがえて 見せる かざりは 作らない（本物の 手順は 出典どおり）。
- **遊びの じゃまを しない**：引いている 間は 動く かざりを 出さない か ごく 小さく。メーターや 端の しるしを かくさない。「動きを へらす」設定（`KB.calm`）では 動かさない。
- **字は やさしい 言い方**：ひらがな 多め、「〜だよ」より「〜です・〜しよう」くらいの 店の 人の 声。ふざけすぎない（お客さんは 50〜80代も）。
- **重く しない**：かざりは 1回 かいて はる（`layer`）か 小さく。毎コマ 重い 絵を かかない。`check.js` の 重さ（60ms）を こえない。
- **見て 確かめる**：`shots.js` の `sheet.png` を 見て、「かわいいか・うるさくないか・袋が 主役か」を 自分で 見る。別の エージェントにも「かわいさ」の 目で 見て もらう（下の たのみ方）。

- 線は こげ茶 `#3e2a1a`、朱 `#c8352b`、クラフト `#f1dfba`・生成り `#fbf3e0`、稲の 緑 `#6b8e3a`。ふちは 少し ゆらす（`bubblePath`）。
- いま ある 場所（62 周目の 引き算の あと）：タイトルの 藍の のれん「らいすぴあ」・季節の POP・見出しの こめつぶ・ボタンの スズメ／上の 余白の 板壁（下の 端は ぼかす）・電線と スズメ（`drawBirds`。一本どりで はねて「ちゅん」、連続で ふえる、まちがいで「？」、「そこまで！」の 拍子木で ぴょん。横向きの 低い 画面では 出さない）／知らせの 吹き出し（`drawMsg`）／張りの 目安の こめつぶの 顔（`drawFingerGauge`）／まとめの はんこ「よく できました」・こめつぶ 3つぶ・「ここから！」／目標の「済」／ランクの はんこと 育つ 絵／ヒント欄の 手書き POP／素朴な 音（木・拍子木・ちゅん）。
- **足す 前に 引き算も 考える**：同じ 役目が 2つ ある・引いている 間に 動く・朱の 丸が 多い・こめつぶが どこにでも いる と、特別で なく なる（47 周目）。ときどき「へらすなら どれか」を きく 周を はさむ（47・62 周目）。
- **金の 字は 1画面に 1行**（結果は「じこベスト更新！」だけ。62 周目）。**吹き出しは 短く**、くわしい 文は 読み上げに（`say(字, 種類, 長さ, 読む, 読み上げの 文)`）。同じ 説明を 吹き出しと 袋の 上の 字で 2回 言わない。
- もう ある もの：まちがい・ハサミの 小さな 反応（スズメの「？」「…」）、素朴な 音、新米の きせつの POP。けした もの：まばたき・寝ている こめつぶ・店の はんこ（47 周目）。まだ ない 場所の 例：季節ごとの 小さな 絵（いまは 新米 だけ）。足すなら 1つ ずつ、引き算と セットで。

## 朝まで ループ（「朝まで」「夜通し」と 言われた とき）

- 運営者の 時間は 日本時間（`TZ=Asia/Tokyo date`）。**朝 7時** を めどに やめる。
- 1周 ずつ 上の「1周の 流れ」を 最後（コミット・push・Artifact の 公開）まで やりきる。周の 途中で 止まらない。
- 周の おわりに `send_later`（claude-code-remote の MCP）で 1〜2 分 後に「つぎの 周へ」を 自分に 送って 続ける（運営者が 途中で 口を はさめる ように、1周 ごとに ターンを 区切る）。朝 7時を すぎたら 送らない。

## 1周の 流れ

1. **何を 直すか きめる**
   - 運営者の 声が あれば それ。言葉が あいまいな ときは、いちばん ありそうな 意味で 進め、さいごに「〜と 受けとった」と 一言。
   - 「改善ループ」だけ なら、まだ 見て いない 面を えらぶ：タイムアタックの 面白さ／れんしゅう（お客さん目線）／リアルさ（出典）／コード（`/code-review`）／重さ／小さい 画面／見えにくさ・使いにくさ（色だけに たよらない・字の 大きさ・読み上げ・キーボード・動きを へらす。23 周目）／はじめて ひらく とき（電波の 弱さ・読み込み。24 周目）。
2. **別の エージェントに 辛口で 見て もらう**（先入観なし。下の「レビューの たのみ方」）。返ってきた 指摘は、コードと 出典で たしかめて から 直す。
3. **調べる**（リアルさの とき）：WebSearch で メーカー（紙袋・袋口ミシン）・製粉会社・JA・農林水産省・消費者庁。わかった ことと 出典の URL を メモ。
4. **作る**：`mishin.html` を 直す。本物に もとづく ところは コードの コメントにも 出典の 名前を 一言。
   - れんしゅうと タイムアタックで 数を 分ける ときは、`zoneLo()`・`knotGrace()`・`knotLen()`・`knotSlow()`・`untangleTaps()`・`freePx()` の ように `S.practice` で 分ける 関数に。
   - 重い 絵は 1回 かいて はる（`layer`・`strip`）。毎コマ 全部 かかない。
   - **1行に 書いた 関数の 途中に コメントを 足す ときは `/* */`**。`//` だと 行の 後ろの コードが 消える（22・36・41 周目で 3回 やった。`check.js syntax` が すぐ 見つける）。
   - **キャンバスを 自分に `drawImage` しない**（スマホで 画面 ぜんぶの コピーに なり 重い）。れんしゅうの 拡大窓は かわった ときだけ うつして とっておく（`zoomBmp`。58 周目）。
   - **時間ぎれの きまり**：引きはじめた 袋は「ラスト1袋」（`S.lastBag`）。もつれ・0.8 秒 はなす・2.5 秒 すすまない（`S.lastIdle`）・あく で `finish()`（「そこまで！」と 拍子木、0.8 秒 後に 結果）。この 間は 時計を ふやさない（`addTime`・フィーバーの +0.02 秒）。
   - **キーの 人の 見分けは `kbUser`**（矢印・スペース・Enter・Tab だけ。Ctrl＋ や Esc では かえない）。キーの 人には れんしゅうの 帯を キーの ことばに（`stepText` の `k()`）、まとめ・結果の フォーカスを 見える 所へ（`focusEnd`）。
   - **かざりの 乱数は `Math.random`**。袋の 乱数（`rnd()`）を 使うと、「動きを へらす」設定で かざりを 出さない ときに 袋が かわって 点が かわる（41 周目）。
   - 画面の 字を 書き足したら `python3 tools/mishin/fonts.py`。袋の 絵（`BAGIMG`）は いちばん 下の 別の script（電波が 弱くても ボタンが 早く きく ように）。
   - 袋の 形や 紙を かえる ときは `build_bag.py`（`--fast` で 荒く 試す → 本番は 4分 ほど。バックグラウンドで 回して その間に ほかを）→ `pack_bag.py`。
5. **確かめる**
   - `node tools/mishin/check.js`（ぜんぶ ✔ に なる まで）
   - `node tools/mishin/playtest.js --runs 10 --goals`（順位：expert ＞ regular ≧ human ＞ novice、greedy・careful・guesser は human より 点が 低い こと。ずるい 打ち方 flick・alwaysL・noKnot・noKnotH も human より 低い こと（さいごに ✔／✖ が 出る）。画面の 幅は `--w 768 --h 1024` などで かえられる（72 周目。幅で 順位が かわらないか）。expert の 1回は 2分 くらいまで）
   - `node tools/mishin/shots.js` と `node tools/mishin/shots.js 360 640`・`844 390` の `sheet.png` を 目で 見る（字の 重なり・はみ出し・かくれ）。結果の「もう一回」は 低い 横向き（568×320・667×375・740×360）でも 画面の 中に。字 200% は 幅 195px（`deviceScaleFactor` 4）で かわりに 見る。
   - 新しい しぐさや 直しを 足したら、その 確かめを `check.js` に 足し、直す 前の 版で 落ちる ことも 見る（`git show HEAD:mishin.html > <スクラッチ>/old.html` → `MISHIN_FILE=<スクラッチ>/old.html node tools/mishin/check.js <名前>`）
6. **記録**：`docs/mishin.md` に「### N 周目（テーマ）」。何が どう だったか → どう 直したか、出典、ボットの 表（数が かわった とき）、作らなかった もの。
7. **コミット・push**：`git add` → コミット（題は「ミシン糸 一本どり：…」）→ `git push -u origin <ブランチ>`。
8. **公開**：`python3 tools/mishin/to_artifact.py mishin.html <スクラッチ>/mishin.html` → Artifact の publish（同じ ファイルの 道で 同じ URL を 更新。`label` に「N周目：テーマ」）。
9. **伝える**：何を 直したか（表）、確かめた こと、運営者に たのみたい こと（本物の 袋で 試してほしい 点・写真）。`sheet.png` などを SendUserFile で。マージや 公開（go.ricepia.jp）は 運営者の 一言 待ち。

## レビューの たのみ方（別の エージェント・general-purpose・バックグラウンド）

共通：日本語で。リポジトリは さわらない。台本と スクショは スクラッチの 下の フォルダ。`docs/mishin.md` を 読む。`window.KB` の 使い方、本物の タッチは `new PointerEvent(type,{pointerId,pointerType:'touch',clientX,clientY,bubbles:true})` を `#cv` に 送る こと、`tools/mishin/check.js` が 見本、を 書く。390×844 と 360×640。影響の 大きい 順に 7つ、証拠（数か スクショの 道）と 具体的な 直し方（関数・変数・新しい 値）、650 字 いない。

- **面白さ（タイムアタック）**：読みの 判断・引く 手ごたえ・むずかしさの 上がり方・ずるい 勝ち方・もう一回の 理由・重なり。
- **お客さん目線（れんしゅう）**：50〜80代・農家・片手に スマホ・もう片手は 袋・外の 明るさ・急いでいる。ルールを 読まずに 終われるか、字の 大きさ、本物の 袋に うつせるか、やめられるか。
- **リアルさ**：本物の 袋・ミシン・表示の 資料と くらべる。目の 間かく・糸の 色と 種類・表示の 欄・手の 動き・コイン精米機の 使い方。出典が 弱い ものは そう 書かせる。
- **コード**：`/code-review medium origin/main...HEAD -- mishin.html tools/mishin`。
- **素朴な かわいさ**：`sheet.png` と 遊んだ 画面を 見て、「米屋の 手書き POP・はんこ・田んぼの 生きもの」の ような ほっこり 感が あるか、うるさく ないか、袋（リアル）が 主役の ままか、50〜80代の お客さんに ふざけすぎて いないか。足すと よい 所・へらす 所を 具体的に（どの 画面の どこに、何を、どの 色・大きさで）。

## 本物の しくみ（出典は docs/mishin.md）

- 二本糸の 環縫い：表は 白い まっすぐな 目だけ。裏は 白（上糸）の 輪の 中を 赤（下糸）が 通る くさり。
- ほどくのは 裏から：赤の 端が 白い 輪に ささって いる 端（たいてい 裏から 見て 左）。赤の 端を 輪から はずし、縫い目に そって 横へ ゆっくり 引く。反対の 端（縫い始め）から だと からまる（「よった しっぽで 見分ける」は 出典に ない）。
- 引っかかったら 表側の 白糸を 少し 引いて から 赤（JA の 案内として 紹介された 方法。孫引き）。製粉会社は「細いもので ゆるめて もどし、やりなおす」。赤が ぬけたら 白は 自然に ぬける（運営者）。
