# PR を 見はる ときの 決まり

くわしい 進め方は `.claude/skills/nishio-go-dev/SKILL.md`。PR の 知らせ（レビュー・CI）では とくに：

- **マージは ユーザーが「マージ」「マージ公開」と 言った ときだけ**。緑でも、指摘が なくても、自分からは マージしない。
- 返事・コメントは 日本語。GitHub の コメントの おわりに `---` と `_Generated by [Claude Code](https://claude.ai/code)_`。
- Codex の 指摘：起きる 道すじを 確かめて、本当なら 直す → `.claude/skills/nishio-go-dev/scripts/playtest.sh` → コミット（`scripts/precommit.sh`）→ スレッドに 返事 → push → 解決 → 「@codex review」。
- Vercel が 赤い：`.claude/skills/nishio-go-dev/scripts/deploy-status.sh <sha>` で 前の main と くらべる。「Account is blocked」の ように どの コミットでも 同じなら このPRの せいでは ない。PR に 1回 コメントして ユーザーに 伝える（コードでは 直せない）。
- 小さな 指摘への 返事は 1つずつ 短く。同じ ことを 何度も 書かない。
