# 農家さんの SNS の声で、トラクターのゲームをリアルにする

1 回分のループで、**新しい声を 1 つ** 拾い、**ゲームの動きを 1 つ** 本物に近づける。文を足すだけで終わらせない。

## いちばんの 目的（運営者の ねがい）

**平和な 世界で、のんびり トラクターを 走らせる** こと。リアルさは この 目的の ために 使う。

- **文字は 最小**：画面に 出る 文字は できるだけ 少なく。知らせは ふだん はじめの 一文だけ（「📖 くわしい説明」を 入れた 人には ぜんぶ）。農家の声も ふだんは 運転中に 出さない。新しい ものは まず 文字なしで、動きと 景色で 伝える。
- **素朴な 自然と 生きものを あちこちに**：田んぼ・畦・水路・空に、その 季節と 時刻に 本当に いる 生きものを、のんびり くらす 姿で。
- **運転する 人も 素朴で かわいく**：麦わら帽子・首に 手ぬぐい。止まると のんびり まわりを 見わたす。
- 失敗や 故障の 話を 入れるときも、こわがらせず、やさしく。
テスト・PR・Codex レビュー・自動マージ・公開の確認は、`.claude/skills/tractor/SKILL.md` の「1 回分の進め方」の 3〜8 にしたがう（ぜったいに守ることも同じ）。

## 1. いま入っている声を見る

```sh
cd .claude/skills/tractor-sns/scripts
python3 koe.py list    # VOICES のキー・出どころ・はじめの画面のリンク
python3 koe.py sites   # 人・サイトごとの数
```

- 同じ人のブログが 5 件をこえていたら、ほかの人・ほかの SNS をさがす（かたよらないように）。
- 季節（春・秋・代かき）、時間（朝・昼・夕・夜）、天気（晴れ・くもり・雨）のうち、声が少ない所をねらう。

## 2. 拾う

**農家さん本人の発信だけ**を使う。まとめサイト・AI の文・うわさの孫引きは使わない。

- **X**：`grok-research.yml` を `topic: tractor` で回す。focus に「米農家さん本人の言葉を短く、投稿の URL つき」と書き、ジョブのログ（`research.json`）を読む。
  - xAI のクレジットが切れていると 403 で失敗する。そのときは WebSearch に切りかえる。
- **ブログ・note**：WebSearch で、具体的なことばで さがす。例：
  - 「田起こし トラクター 失敗 ブログ」「秋起こし ひこばえ 絡む」「代かき 浮き藁 ブログ」
  - 「トラクター はまった 田んぼ 脱出」「ロータリー 爪 交換 ブログ」「耕運 枕地 ターン コツ note」
  - 「田んぼ 耕していたら（鳥・カエル・ヘビ・モグラ）」「トラクター 夜 作業灯 田起こし」「霜 田起こし 朝」
  - サイトをしぼる：`allowed_domains` に `note.com`・`ameblo.jp`・`exblog.jp`・`hatenablog.com`・`fc2.com`・`livedoor.blog`
- **YouTube・Instagram**：本人のチャンネル・アカウントの説明文やタイトルで、場面がはっきりわかるものだけ。
- **研修・就農の報告**：新規就農者の日記、JA・普及センター・農業大学校の研修の報告。

### 読めないとき

- このコンテナからは、WebFetch や curl で開けないサイトがある（例：ameblo.jp）。そのときは WebSearch の要約と抜き書きで読む。
- **読んだその場で、控えを残す**（下の 3）。あとで読みなおせないことがあるので、要約は控えから書く。
- 中身がたしかめられないものは使わない。

## 3. 控える

`.claude/skills/tractor-sns/koe-log.md` に 1 件ずつ足す（使わなかったものも書くと、次のループでむだに さがさない）。

```
## <キー>（YYYY-MM-DD）
- 出どころ：<だれ・どこ>（<URL>）。いつの話か（わかれば）
- 本人の話（要約）：<2〜4 文。読んだその場で>
- ゲームに：<どの季節・時間・場面の、何を変えたか>／使わない理由
- たしかめた資料：<メーカー・公的資料・図鑑の URL>
```

## 4. ゲームの動きに作りかえる

声は「ゲームで何が起きるか」に直す。例：

| 農家さんの声 | ゲームの動き |
| --- | --- |
| 伸びた 2 番穂がロータリーに絡む（X） | 秋に点検しないと 巻きついて重くなり、止まって上げると取れる |
| 耕していたらウシガエルを起こした（ブログ） | 春、ロータリーのうしろの 耕した土から 出てきて はねていく |
| 切り株のあいだを ウズラが走った（ブログ） | 春・秋の昼、近づくと 株の列のあいだを 走り、止まると うずくまる |

- **数値は出典で確かめる**：速さ・深さ・時間・大きさ・季節・時刻は、メーカーの取扱説明書・県や農研機構の資料・図鑑で裏をとる。合わなければ資料のほうに合わせ、コメントに両方の出典を書く。
- **季節・時間・天気**：その声が いつの話かを守る（春の話を秋に出さない）。`season`・`TOD`・`DARK`・`RAIN`・`SHIRO` で出しわける。
- **生きもの**：大きさ・色・動き・出る時期と時間を図鑑で確かめる。トラクターの中に入らない（tractor スキルの「作るときに気をつけること」）。
- **安全**：危ない話（回っている爪に手を出す など）は、そのまま出さない。正しい手順（PTO を切る・エンジンを止める・台でささえる）といっしょにするか、使わない。

### 自然や生きものの 素朴で 平和な かわいさ（運営者の ねがい）

田んぼの まわりの 自然や 生きものの、素朴で 平和な かわいさを ゲームの あちこちに ちりばめる。文字は できるだけ 減らす。

- **毎回 1 つ**：その回の 動きに あわせて、小さな かわいい しぐさを 1 つ 入れる（例：畦で 首を かしげる セキレイ、葉の 上で のどを ふくらませる アマガエル、ひなたで 羽を 広げて かわかす チョウ）。声そのものが 生きものの 話なら、それを そのまま 動きに する。
- **本物の しぐさで**：図鑑・観察の 記録で たしかめた 動き・大きさ・色・季節・時刻だけを 使う。顔を かいたり しゃべらせたり しない（漫画に しない）。
- **さりげなく**：作業の じゃまを しない。画面の すみや トラクターの まわりで、気づいた人が にっこり する くらい。知らせ（toast）は 1 回まで、点数には 入れない。
- **こわがらせない・いためない**：生きものが ひかれたり けがを したり する 場面は 出さない。トラクターが 近づくと 逃げる・よける。
- koe-log の「ゲームに」に、入れた かわいさを 1 行 書く。
- **文字は できるだけ 減らす**：新しい 生きものや 景色は、知らせを 出さずに 動きだけで 見せるのを まず 考える。出すときも 絵文字＋短い 一言（20 字 前後）。くわしい 説明は「農家の声」の 行と コードの コメントに 書き、画面には 出さない。毎回、前から ある 長い 知らせも 1 つ 短くする。
- **平和に**：こわい・いたい・争う 場面に しない（威嚇・けんか・食べる 場面は 出さない）。生きものは のんびり くらしていて、トラクターが 来ると そっと よける。
- **出したい 生きもの**（運営者の ねがい・季節と 場所は 図鑑で 確かめる）：アメリカザリガニ（代かきの 畦ぎわを のんびり 歩く・近づくと うしろへ すっと 水に もどる）、アメンボ（もう ある：代かきの 水面を すいすい）、ゲンゴロウ（代かきの 水で おしりを 出して 息つぎ）、ウシガエル（もう ある：春の 土から 出てくる・のどで 息）。ほかにも 田んぼの 素朴な 生きものを。

## 5. 「農家の声」に入れる

- `VOICES` に `key: ['要約（やさしい日本語・1〜2 文）', '出どころ（ブログ名「記事名」など）']` を足し、その場面で `voice('key')` を 1 回だけ出す。
- はじめの画面の「農家の声」（`<details class="how">`）に 1 行足す：要約…`<a href="URL" target="_blank" rel="noopener">だれの「記事名」</a>`（ゲームでは ○○）。
  - リンクがないと、終わりの画面の説明が うそになる。
- 本人の言葉を長く写さない。短く要約する。
- 足したら `python3 koe.py check <URL>` で入ったことを確かめる。

## 6. このあと

tractor スキルの 3〜8（テスト → `tractor-blender` で PR → `@codex review` → 指摘を直す → 条件がそろったら自動でマージ → 公開の確認 → 日本語で短く報告）。
Codex には、コードに加えて「農家さんの話の要約が出どころに忠実か・季節や数値が本物か」も見てもらう。

## ループ

「このスキルをループ」と言われたら、/loop の動的モードで次のプロンプトを回す：

```
/loop 農家の声のスキル（.claude/skills/tractor-sns）を 1 回分まわす：SNS・ブログから農家の声を拾う → 控える → ゲームの動きに作りかえる（自然や生き物の素朴なかわいさも 1 つ）→ テスト → tractor-blender で PR → Codex レビュー → 指摘を直す → 条件がそろったら自動でマージして公開を確かめる → 日本語で短く報告
```

- 待ちのあいだ（Codex・Vercel）は、PR の知らせが起こしてくれる。ScheduleWakeup は 1200 秒の予備にする。
- 「朝まで」と言われたら、日本時間の 朝 7 時（UTC 22 時）を すぎたら 次の回を 始めずに 止める（とちゅうの PR は マージまで 見る）。
- ユーザーが止めてと言ったら、ScheduleWakeup を `stop: true` にして待つ。
