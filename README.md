らいすぴあ 品質判定AI

- `index.html` … 精米の写真から品質を判定するAI
- `meta-ads.html` … Meta（Facebook / Instagram）広告の成果診断。広告マネージャのCSVを読み込み、CPA・ROAS・CTR・フリークエンシー・前後半の推移から「増額／維持／要改善／停止／データ不足」を判定し、AIが改善策と次の広告案を提案
- `sns-posts.html` … SNS投稿メーカー。目的・商品・事実メモ（任意で写真）から、Instagram（フィード／リール台本）・LINE公式・X・Facebook・Googleビジネスプロフィール向けの投稿文をAIが媒体ごとに作成。文字数・ハッシュタグ数と、景品表示法・健康表現・「無農薬／減農薬」「新米」表示を自動チェック。数週間分の投稿カレンダーも作成でき、各予定から下書きを作れる
