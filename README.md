らいすぴあ 品質判定AI

- `index.html` … 精米の写真から品質を判定するAI
- `meta-ads.html` … Meta（Facebook / Instagram）広告の成果診断。広告マネージャのCSVを読み込み、CPA・ROAS・CTR・フリークエンシー・前後半の推移から「増額／維持／要改善／停止／データ不足」を判定し、AIが改善策と次の広告案を提案
- `comment-reply.html` … Facebook / Instagram のコメント自動返信。Graph API でページの未返信コメントを取得し、AIが店舗情報だけを使ってコメントと同じ言語で返信案を作成（日本語・スタンプ・タグだけのコメントには返信しない）。景品表示法・薬機法に触れそうな表現、店舗情報にないURL・電話番号、同じ文面の連投を送信前に止め、送信間隔と1時間・1日の上限を守る。自動モードでは場所・営業時間・注文方法などの低リスクな返信だけを自動送信し、苦情や健康の話題などは人の確認待ちに残す
