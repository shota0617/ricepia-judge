らいすぴあ 品質判定AI ／ Marketing Studio

近藤米穀店「らいすぴあ」のための、ビルド不要の静的Webアプリです（Vercel：https://ricepia-judge.vercel.app/ で公開）。

## アプリ

| ファイル | 内容 |
|---|---|
| `index.html` | 精米品質AI判定（写真→12項目採点・グレード判定・レシート印刷） |
| `marketing.html` | **らいすぴあ Marketing Studio**（AIマーケティング統合ツール） |
| `nishio-go.html` | **にしおさんぽGO**（西尾市のお散歩ポイントラリー）。地図上のスポット（神社・お寺・公園・史跡・駅など）に歩いて近づくとチェックインでき、ポイント・レベル・バッジが貯まる |
| `tsunagu.html` | **つなぐ**。店舗どうしをビデオ通話でつなぐだけのページ。開くだけで最大3台がひとつの部屋に入る（設定・ID・パスワード不要） |
| `meeting.html` | **らいすぴあ ミーティング**（Zoomのようなビデオ会議）。発言を自動で文字起こしし、AIがお客様のニーズを抽出して開発バックログ・GitHub Issue・開発依頼書につなげる |
| `meta-ads.html` | Meta（Facebook / Instagram）広告の成果診断。広告マネージャのCSVを読み込み、CPA・ROAS・CTR・フリークエンシー・前後半の推移から「増額／維持／要改善／停止／データ不足」を判定し、AIが改善策と次の広告案を提案 |

## つなぐ（`tsunagu.html`）

店舗どうしをビデオ通話でつなぐだけのページ。設定・ID・パスワード・リンクの受け渡しは不要で、各端末で https://ricepia-judge.vercel.app/tsunagu.html を開くだけ（ホーム画面に追加推奨）。

- ひとつの部屋に最大3台。開いた順に席（1〜3）に入り、ほかの席に自動で発信する。4台目は「満室」と表示し、空くと自動で入る
- 相手が閉じる・回線が切れる・タブレットがスリープから戻る、などでも自動で再接続。だれかが入ると音で知らせ、上部に「n台でつながっています」と表示
- 予備のZoom：「Zoom」ボタンで、この画面の通話を切ってから らいすぴあのZoom（パーソナルミーティングID 544 001 0563、`https://zoom.us/j/5440010563`）を開く。⚙ で pwd= 付きの招待リンクを入れるとパスコード入力が不要になる（その端末にだけ保存）。つながらないまま30秒たつと待機画面にも案内
- 注意：URLを知っていればだれでも入れるため、公開ページ（品質判定など）からはリンクしていない。URLは店の外に出さないこと
- 通話はWebRTCで端末どうしが直接やりとり（接続の仲介はPeerJSの公開サーバー）。録音・文字起こしはしない

## ミーティング（`meeting.html`）の機能

| 区分 | 機能 | 概要 |
|---|---|---|
| 会議 | ビデオ会議 | ブラウザだけで参加できるビデオ通話（目安6人まで）。招待リンクをLINE・メールで送信、ミュート・カメラ・画面共有・チャット・参加者一覧 |
| 会議 | 自動文字起こし | 参加者それぞれの端末が自分の発言をブラウザの音声認識で文字にし、話者名・参加区分（当社／お客様）つきで全員に共有。字幕表示、ミュート中は自動停止、開始・停止は全員に通知 |
| 会議 | 録音 | 「⏺ 録音」で全員の音声をミックスして録音し、押した人の端末（IndexedDB）に保存。録音中は全員の画面に表示 |
| 会議 | AIメモ | 会議の途中で「ここまでの要望」と「次に聞くとよいこと」をAIが整理（聞き漏らし防止）。手書きメモも記録に残る |
| 分析 | 要望分析 | 文字起こしから明示・潜在ニーズを抽出し、根拠の発言（時刻つき）、優先度（Must/Should/Could）、ユーザーストーリー、受け入れ条件、開発メモ、確認事項、次のアクションを整理。議事録（Markdown）とお客様への確認メール文面も作成 |
| 分析 | 取り込み | Zoom・Meet・Teams などの文字起こし（.vtt / .srt / .txt）と録音ファイルを取り込んで同じように分析 |
| 分析 | 聞き直し・修正 | 文字起こしの各発言と「お客様の声」の引用から録音をその位置で再生。誤変換の修正、話者の区分（お客様／当社）の切り替え。修正後は再分析を案内 |
| 開発 | 開発バックログ | 会議をまたいでニーズを蓄積。同じ目的の要望はAIが既存項目に統合し、言及数・優先度・影響からスコア順に並べる。状態管理（新規→検討中→開発中→リリース済み） |
| 開発 | お客様の声レポート | 分析済みの全会議を横断し、よく出る困りごと・お客様のタイプ別の違い・新しい機会・開発ロードマップ案・次のヒアリングの仮説をAIがまとめる |
| 開発 | リリースのお知らせ | 項目を「リリース済み」にすると、要望してくれたお客様ごとに「いただいたご要望に対応しました」という文面案を作成（コピー・LINE送信・連絡済み管理） |
| 開発 | GitHub Issue / 開発依頼書 | 項目からお客様の声・受け入れ条件つきのIssueを作成（GitHubの新規Issue画面を開く）。選んだ項目から開発依頼書（Claude Code へそのまま渡せる依頼文つき）をAIが作成 |

- 通話：WebRTC（参加者どうしのメッシュ接続）。接続の仲介に PeerJS（`peerjs@1.5.4`、既定は公開サーバー）。自社のPeerServerを使う場合は `meeting.html?peerhost=ホスト&peerport=443&peerpath=/` で開く（`peersecure=0` で http）。
- 文字起こし：Web Speech API（Chrome / Edge / Safari）。Chrome では音声がブラウザ提供元の認識サーバーに送られる。
- データ：会議記録・バックログはブラウザの localStorage（キー接頭辞 `rmt_`）、録音は IndexedDB（`rmt_audio`、バックアップ対象外）。AI分析を実行したときだけ文字起こしを Anthropic API に送信。APIキーは Marketing Studio と共通（`rpm_key`）。
- AI：要望分析・開発依頼書は `claude-opus-5-5`（effort high、分析は JSON Schema の構造化出力）、会議中のAIメモは `claude-sonnet-5-5`（effort low）。

## 使い方

1. `marketing.html`（https://ricepia-judge.vercel.app/marketing.html）を開き、右上の「🔑」から Anthropic APIキーを設定（[console.anthropic.com](https://console.anthropic.com/settings/keys)）。
2. まず「ブランド設定」で所在地・営業時間・価格などの【　】部分を埋めて保存。
3. 「売上と配信」で月次KPIを、ホームの「数値を更新」で各SNS・LINEの数字を入れると、ホームの診断が具体的になります。

## 技術メモ

- 構成：`marketing.html` + `mkt/`（`style.css`, `core.js`, `charts.js`, `data.js`, `studio.js`, `plan.js`, `insight.js`, `home.js`）。外部ライブラリなし。
- AI：Anthropic Messages API をブラウザから直接呼び出し（SSEストリーミング）。既定モデル `claude-opus-5-5`（設定で `claude-sonnet-5-5` に切替可）、`effort` 指定、拒否時の `fallbacks: "default"`、リサーチは `web_search_20260209`（`pause_turn` の継続にも対応）。
- データ：すべてブラウザの localStorage（キー接頭辞 `rpm_`）。APIキーは既定でセッション内のみ保持。
- 品質判定との連携：`index.html` が最新の判定結果を `ricepia_last_judge` に保存し、コンテンツ生成画面で利用。
- 注意：APIキーをブラウザで扱う構成のため、店内の信頼できる端末での利用を想定しています。複数店舗・多人数で運用する場合は、APIキーをサーバー側に置くバックエンド（認証付き）への移行を推奨します。

## にしおさんぽGO（`nishio-go.html`）

ポケモンGOのポケストップのように、西尾市内のスポットへ実際に歩いて行くとポイントが貯まるゲームです。

- 地図：国土地理院の地理院タイル（淡色地図）＋ Leaflet 1.9.4（unpkg、SRI付き）。
- スポット：OpenStreetMap（Overpass API）から **西尾市の行政区域内** の神社・お寺・史跡・公園・博物館・展望所・図書館・駅・海岸を自動取得（端末に7日間キャッシュ）。取得できないときは注目スポットだけで動きます。
- 注目スポット：`nishio-go/spots.json` に57か所（西尾23・一色6・佐久島8・吉良12・幡豆8。うち44か所は Wikipedia・マピオン・NAVITIME などで調べた座標つき）。`match` の名前で OSM の同じ名前の場所を探し、確かな座標なら300m、概算（`approx: true`）なら1km以内で見つかればその位置に補正します。座標なし（null）のスポットは名前で1か所に絞れたときだけ表示します。
- ポイント：スポット10pt（注目30〜50pt）、初訪問 +30pt（注目 +100pt）、その日最初のチェックイン +20pt＋連続日数ボーナス、100m歩くごとに1pt（1日100ptまで。ページを開いて画面がついている間だけ数える）。同じスポットは60分ごと。数値は `nishio-go/game.js` 冒頭の `CFG` で調整できます。
- 不正対策（簡易）：チェックインは約40m以内＋GPS誤差の上乗せ（最大25m）、GPS精度80m超は不可、時速約30km超の移動を検知すると2分間チェックイン停止、更新が3分以上途切れた間の移動は歩数に数えない。
- 今日のおさんぽクエスト：毎日3つのお題（ちがうスポットを2か所・神社かお寺・500m歩く・たからばこを2つ・はじめてのスポット・その日の地区の注目スポット、ときどき当店に寄る）。日付だけで決まるので同じ日はだれでも同じお題（その日の地区は船のいらない西尾・一色・吉良・幡豆から）。3つぜんぶでボーナス50pt。進み具合は「きろく」と地図の下の案内に出ます。
- たからばこ：400m四方ごとに1〜2個、日付で決まる場所に現れます（ドット絵の地図とふつうの地図の両方）。「操作して移動」では道や小道の上、「あるいて移動」では実際に歩いて行くので道や小道（地図データでは車道や私有地の通路と見分けられない）には置かず、スポットになっている公園・神社・お寺・城跡・海岸・展望地そのものに置きます（地図の下の案内に「たからばこが近くにある！（伊文神社・120m）」のように出ます）。近づくと開いて10〜30ptと「西尾まめちしき」（地区の豆知識・紹介文と注目スポットの説明から）が手に入り、「きろく」に集まります。
- プレイの確認：`node tools/playtest.js 出力フォルダ` で、ヘッドレス Chromium が通しでプレイして（操作して移動でたからばこと3か所めぐり → 当店の案内 → せかいちず → きろく → あるいて移動）、スクリーンショットと結果（playtest.json）を残します。
- 音楽：`nishio-go/bgm/` の mp3 を流します（ふだんの曲・せかいちずの曲・チェックインとレベルアップの効果音）。4曲とも `python3 tools/make-sound.py` で作るオリジナルのファミコン風の音で、お店の宣伝にも使えます。Suno AI の曲に差し替えるときの指示文と使ってよい条件は `nishio-go/bgm/README.md`。地図の下の 🔊 ボタンと「せってい」で消せます。
- 遊びかたは2つ：「🚶 あるいて移動」（位置情報で実際に歩く）と「🎮 操作して移動」（ドット絵の地図では十字ボタン／矢印キー、ふつうの地図ではタップした所へ移動）。はじめの画面でえらび、地図の下の切り替えボタンや「せってい」でいつでも切り替えられます。ポイントと記録はモードごとに別に保存し、お店のとくてんは「あるいて移動」でだけ使えます。
- 特典（ポイント交換）：`nishio-go/rewards.json` に登録。`"active": true` の特典だけ本番の「とくてん」タブに表示されます（特典が1つも有効でなければタブ自体が出ません）。いまはサンプル3件（プチギフト・100円引き・コイン精米無料）を `active: false` で入れてあり、「操作して移動」でだけ試せます。交換するとポイントが減り、店頭で見せるクーポン画面（動く時計・残り時間・番号）が出ます。店員さんが確認して「使用済みにする」を押します。`perDay` で1日の交換回数、`validMin` で有効時間を設定できます。
- ドット絵の地図（👾ボタンで切り替え、`nishio-go/pixel.js`）：OpenStreetMap の道・建物・田畑・森・公園・川・海岸線などを 8m 四方のマスに塗り分け、16×16 のドラクエ風ドット絵タイルで表示（航空写真・Googleマップは使いません）。主人公は勇者のドット絵（ふつうの地図の現在地マーカーも同じ絵）、スポットは城・鳥居・お寺・町・宝箱で表示し、注目スポットは大きくきらきら。約1km四方ごとに Overpass API から取得して端末に30日保存（最大60区画）。「操作して移動」では十字ボタン／矢印キーで1マスずつ歩け、水と建物には入れません。西尾らしさのために、田んぼ・畑・茶畑（`crop=tea`）・ビニールハウス・工場地帯・神社やお寺の境内・墓地を描き分けます。山・丘・海は国土地理院の標高タイル（`dem_png` ズーム14＝約8m）から作り、標高35m以上の草地を丘、150m以上を山にし、斜面に陰影を付けます。海は海岸線（右側が海）から塗ります。海岸線が通らない区画は、地図データが何もなく標高データの大半が「データなし」のときだけ海とみなします（標高の欠損だけで陸を海にしない）。水辺には波打ち際を描きます。標高が取れないときは地図データだけで描きます。
- せかいちず（ドット絵の地図の🌏ボタン）：西尾市と周り（碧南・安城・幸田の一部）を1マス100mのドラクエ風フィールドマップで表示。はじめて開く人は、このダンジョン風のせかいちずから始まります。海・丘・山は国土地理院の標高タイル（ズーム12）から、川・国道・県道・線路・森・町なみと地名・駅名は OpenStreetMap から作り、注目スポット（名所57か所すべて）と大きな建物をドット絵で重ねます（寄ると名所の名前も表示。中くらいの縮尺から川の名前（水色）、いちばん寄ると町名（灰色の小さな文字）も出します。めぐった名所には金色の✓が付き、左上に「めぐった名所 n/全体」を表示。駅が名所になっている所は駅名を重ねて出さない）。地図データは「地名・駅・大きな建物」1回と、範囲を4×4に分けた16回（自分に近い区域から順）に分けて取り込み、取れた区域から順に道や川が描き足されます（左上に「ちずを くわしくしています… n/16」）。1回で全域を取ると無料サーバーで時間切れになりやすいためです。引いて見ると1マス＝色のブロックの全体図、寄るとドット絵タイル。いちばん寄ってさらに拡大すると歩く地図に、歩く地図をいちばん引いてさらに縮小するとせかいちずに切り替わります。ドラッグで移動、アイコンをタップで説明。作った地図は端末に30日保存（取れなかった区域があれば1日で作り直し）（この縮尺では海岸線を使わず、標高データのない所を海とみなし、地図データで森や町なみがある所は陸にします）。
- せかいちずの地図データ（`nishio-go/world.json`）：GitHub Actions（`.github/workflows/bake-world.yml`）が、ゲームと同じ `pixel.js` をヘッドレスのブラウザで動かして、実際の OpenStreetMap と国土地理院の標高タイルから作ります。このときは川・道・線路・森・町なみに加えて、田んぼ・茶畑・畑・工場・境内・墓地・公園・学校・砂浜・干潟・養鰻池なども、範囲を8×8に分けて取り込みます（歩く地図と同じ分け方）。ゲームはまずこのファイルを読むので、開いてすぐ西尾市全体の地図が出ます（端末に7日保存）。ファイルがない・大きさが合わないときだけ、ブラウザで軽い地図データを取って作ります。作り直すときは、Actions の「Bake Nishio world map」を手動で実行するか、`tools/world-version.txt` の数字を上げてプッシュします（せかいちずの作り方を変えたときも）。
- 歩く地図の区画データ（`nishio-go/chunks/区画.json`）：GitHub Actions（`.github/workflows/bake-chunks.yml`）が `tools/bake-chunks.js` で、西尾市にかかる1km四方の区画をすべて、実際の OpenStreetMap（2×2区画ずつまとめて取得）と国土地理院の標高から、ゲームと同じ `rasterize()` で作ります（ランレングスで保存）。ゲームはまずこのファイルを読み、なければブラウザで地図データを取ります。作り直すときは Actions の「Bake Nishio walking map」を手動で実行するか、`tools/chunks-version.txt` の数字を上げてプッシュします。
- 地区ガイド（`nishio-go/areas.json`）：西尾市を西尾・一色・吉良・幡豆・佐久島の5地区に分け、特徴・名物・人口・面積・豆知識を出典付きでまとめたもの（2026年10月調査）。せかいちずに地区の札（めぐった名所の数）を出し、タップで地区ガイドを表示。`spots.json` の各注目スポットの `area` で地区を決め、きろくの「地区ごとのめぐり具合」と「○○制覇」バッジに使います。
- タイトルロゴ（`nishio-go/logo.svg`）：`python3 tools/make-logo.py` で生成するドット絵のSVG。文字は16pxのビットマップフォント Unifont-JP（SIL OFL）を2倍にして太らせ、黒ふち・影・西尾城・抹茶の茶葉を添えています。
- 主要な建物：市役所・支所、病院、学校、図書館、警察・交番、消防署、郵便局、スーパー・ショッピングモール、駅を、OpenStreetMap の位置にドット絵の建物アイコンで表示（タップで名前。チェックインはしない）。せかいちずには市役所・支所・病院・図書館・消防署・ショッピングモールなど大きな建物だけを出します。西尾市役所は注目スポット（20pt）。
- いまのGPS：「せってい」に現在地の座標を表示・コピーできます（お店などのスポットを登録するときに、その場で座標を取るのに使えます）。
- データ：記録はブラウザの localStorage（キー接頭辞 `nsg_`）。現在地は外部に送信しません。
- 注意：ポイントは端末内で計算しているため、改ざんは防げません。特典は「動く時計が出ていること（スクリーンショットでないこと）」と残り時間を店頭で確認する運用が前提です。高額な特典にする場合はサーバー側での検証（ログイン・チェックイン記録の照合）を追加してください。
