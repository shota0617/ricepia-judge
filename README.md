らいすぴあ 品質判定AI ／ Marketing Studio

近藤米穀店「らいすぴあ」のための、ビルド不要の静的Webアプリです（GitHub Pages等にそのまま置けます）。

## アプリ

| ファイル | 内容 |
|---|---|
| `index.html` | 精米品質AI判定（写真→12項目採点・グレード判定・レシート印刷） |
| `marketing.html` | **らいすぴあ Marketing Studio**（AIマーケティング統合ツール） |

## Marketing Studio の機能

| 区分 | 機能 | 概要 |
|---|---|---|
| 概要 | ダッシュボード | 月次KPI（売上・客数・客単価・EC注文・LINE友だち・Instagram・販促費）の入力とグラフ、今後2週間の予定、季節の販促ヒント、AI経営アドバイザー |
| つくる | コンテンツ生成 | Instagram / X / LINE / Googleビジネス / ブログ / EC商品ページ / POP / チラシ / メルマガ / プレスリリース / ギフト文面。チャネル別の文字数・書式ルール、複数案、写真添付、修正指示、**品質判定結果からの投稿作成** |
| つくる | コピー診断 | 6観点の採点、景品表示法・食品表示・米トレーサビリティ法などの表示リスク指摘、改善版3案 |
| つくる | 口コミ対応 | ★評価に応じた店主らしい返信文／複数口コミの傾向分析（テーマ・強み・改善点・打ち手） |
| 計画する | キャンペーン設計 | 目的・予算・期間から、コンセプト・ペルソナ・KPI・予算配分・スケジュール・制作物・リスクまで一括設計。カレンダーへ連携 |
| 計画する | 販促カレンダー | 月表示の予定管理（状態：アイデア／下書き／予約済み／完了）、季節行事の表示、AIで1ヶ月分の発信計画 |
| 分析する | 顧客分析（RFM） | CSV取り込み→RFMスコア→7セグメント分類。セグメント別の施策とLINEメッセージをAIが作成（**AIには集計値のみ送信**） |
| 分析する | 市場リサーチ | Claudeのweb検索ツールで最新の米価・トレンド・事例を調査し、出典付きでまとめ |
| 管理 | ライブラリ / ブランド設定 / 設定・データ | 生成物の保管・検索・CSV出力、店舗プロフィールと商品マスタ（全AI生成の前提知識）、モデル選択・AI利用料の概算と月予算、バックアップ／復元 |

## 使い方

1. `marketing.html` を開き、右上の「🔑」から Anthropic APIキーを設定（[console.anthropic.com](https://console.anthropic.com/settings/keys)）。
2. まず「ブランド設定」で所在地・営業時間・価格などの【　】部分を埋めて保存。
3. ダッシュボードで月次KPIを入力し、各機能を利用。

## 技術メモ

- 構成：`marketing.html` + `mkt/`（`style.css`, `core.js`, `charts.js`, `data.js`, `studio.js`, `plan.js`, `insight.js`）。外部ライブラリなし。
- AI：Anthropic Messages API をブラウザから直接呼び出し（SSEストリーミング）。既定モデル `claude-opus-5-5`（設定で `claude-sonnet-5-5` に切替可）、`effort` 指定、拒否時の `fallbacks: "default"`、リサーチは `web_search_20260209`（`pause_turn` の継続にも対応）。
- データ：すべてブラウザの localStorage（キー接頭辞 `rpm_`）。APIキーは既定でセッション内のみ保持。
- 品質判定との連携：`index.html` が最新の判定結果を `ricepia_last_judge` に保存し、コンテンツ生成画面で利用。
- 注意：APIキーをブラウザで扱う構成のため、店内の信頼できる端末での利用を想定しています。複数店舗・多人数で運用する場合は、APIキーをサーバー側に置くバックエンド（認証付き）への移行を推奨します。
