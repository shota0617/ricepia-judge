Metaの規約・法令のために、このツールが守っていること

Meta（Facebook / Instagram）の規約

  • 公式のGraph APIだけで読み書きします。Business Suiteの画面を拡張機能やRPAで自動操作する方法は、Metaの利用規約（許可のない自動化された手段でのアクセス禁止）に反するため使いません。
  • 同じ文面の連投をしません。最近7日の返信と同じ文面は自動送信せず、AIにも毎回言い回しを変えさせます（定型文の連投はスパム判定・アカウント制限の原因）。
  • 送信のペースを制限します（間隔＋ランダムな間、1時間・1日の上限）。MetaのAPI制限に当たった場合は自動モードを止めます。
  • 二重返信をしません。送信直前に、店がもう返信していないかを確認します。
  • 古いコメントへの一斉返信をしません（既定7日以内）。
  • 公開コメントで電話番号・住所・注文内容などの個人情報を聞きません。注文の詳細はDM等へ案内します。

日本の法令（食品の販売）

  • 景品表示法：「日本一」「最安」「絶対」など根拠のない表現や、店舗情報にない価格・条件を書きません（該当しそうな語句は送信前に止めます）。
  • 薬機法・健康増進法：玄米などの健康効果・病気への効果を断定しません。
  • 他店・他社を悪く言いません。

データの扱い

  • 返信文の作成のため、コメント本文と投稿本文を Anthropic API に送ります。コメント主の名前は送りません（「お客様A」などに置き換え）。
  • トークンとAPIキーは保存しません。送信履歴と対応済みのコメントIDだけをこの端末のブラウザに保存します。
