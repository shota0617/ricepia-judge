# にしおさんぽGO を、いま出している広告に出す準備（2026年10月）

いま出している広告：
- Google広告（P-MAX「西尾の米屋 らいすぴあ #2」、検索「新米２」。`docs/google-ads-review-2026-10.md`）
- Meta広告（`meta-ads.html` で分析しているもの）
- LINEヤフー広告（`nishio-go/analytics.js` の計測タグ）

この3つに、にしおさんぽGO（https://go.ricepia.jp/）を足すための材料と手順をまとめました。
**この環境からは広告の管理画面や API に入れないため、反映はまだしていません。** 下の手順で反映してください。

## 2. リンク（どの広告から来たかを数える）

`?play=1` で、はじめての人もすぐ「操作して遊ぶ」で始まります（家で見る広告向け）。

| 広告 | リンク |
|---|---|
| Google（サイトリンク） | `https://go.ricepia.jp/?utm_source=google&utm_medium=cpc&utm_campaign=game_sitelink&play=1` |
| Meta | `https://go.ricepia.jp/?utm_source=meta&utm_medium=paid&utm_campaign=game&utm_content={{ad.name}}&play=1` |
| LINEヤフー広告 | `https://go.ricepia.jp/?utm_source=line_ads&utm_medium=paid&utm_campaign=game&play=1` |
| LINE リッチメニュー | `https://go.ricepia.jp/?utm_source=line&utm_medium=richmenu&utm_campaign=game` |

## 3. Google広告

`tools/google-ads-game-2026-10.js`（Google広告スクリプト）が、次のことをします。何度実行しても同じ結果になります。

- サイトリンク「お散歩ゲーム（無料）」（説明「西尾の米屋がつくったゲーム」「無料・登録なしですぐ遊べる」）を作り、P-MAX #2 と 新米２ に付ける
- コールアウト「お散歩ゲームも無料公開」を作り、同じ2つに付ける

広告文・入札・予算・目標（10/15 に決めた「LINE重視」）は変えません。

手順：Google広告 → ツールと設定 → 一括操作 → スクリプト → ＋ → ファイルの中身を貼り付け → 承認 →「プレビュー」でログを確認 →「実行」。
API の認証情報があれば `node tools/google-ads-run.js --job game`（検証だけ）→ `--job game --apply`（反映）でも動きます。

**ゲーム専用のアセットグループやキャンペーンは、まだ作らないでください。** ゲームのページには LINE 友だち追加のコンバージョンがないため、いまの目標（LINE重視）で入札すると配信されにくくなります。作る場合は、目標（例：ゲームを始めた＝`game_start`）を決めて、別のキャンペーンにしてください。

## 4. Meta広告・LINEヤフー広告

どちらも、いま出している広告セット（広告グループ）に、ゲームの広告を1本ずつ足すのがおすすめです（予算を増やさずに、ゲームの反応を見られます）。

- Meta：広告マネージャ → いまの広告セット → 広告を複製して作成 → 画像（1080×1080・1080×1350・1080×1920）か動画（mp4）→ 本文・見出し（1章）→ リンク（2章）→ CTA「詳しくはこちら」。
  **Meta ピクセルのデータセットIDが、まだ `nishio-go/analytics.js` に入っていません。** IDを教えてもらえれば入れます（ゲームの中の行動を Meta で数えられるようになります）
- LINEヤフー広告：広告マネージャー → いまの広告グループ → 広告を作成 → 画像（1200×628・1080×1080・600×400）か動画 → タイトル・説明（1章）→ リンク（2章）

## 5. LINE リッチメニュー（ドライブスルーをやめて、ゲームを足す）

LINE 公式アカウントのリッチメニューは、LINE Official Account Manager で設定されています（この環境からは変えられません）。

いまのメニュー（大きいサイズ 2500×1686・5マス）の絵をそのまま写して、ドライブスルーのマスだけ「お散歩ゲーム」に替えた1枚の画像を用意しました：
`mkt/nishio-go/richmenu-2500x1686.png`（`tools/make-promo.js` の `richMenu()`）。ほかの4マスは、位置・色・文字ともいまのままです。

1. LINE Official Account Manager → ホーム → トークルーム管理 → リッチメニュー → いま表示中のメニュー →「編集」
2. 画像：「背景画像をアップロード」で `richmenu-2500x1686.png` をアップロードする（テンプレートはいまのまま）
3. アクション：左上のマス（ドライブスルーだった所）を「リンク」にして、URL を `https://go.ricepia.jp/?utm_source=line&utm_medium=richmenu&utm_campaign=game`、ラベルを「お散歩ゲーム」にする。ほかの4マスのアクションは変えない
4. 保存して、スマホの LINE で表示とリンクを確かめる

テンプレートを自分で決める（自由に区切る）場合のタップ範囲（2500×1686 の座標）：

| マス | x | y | アクション |
|---|---|---|---|
| お散歩ゲーム（左上） | 0〜825 | 0〜830 | 上のリンク |
| 店舗・営業時間（左下） | 0〜825 | 830〜1686 | いまのまま |
| 新米 販売中（中央） | 825〜1674 | 0〜1686 | いまのまま |
| 価格表PDF（右上） | 1674〜2500 | 0〜830 | いまのまま |
| 常連さまポイント（右下） | 1674〜2500 | 830〜1686 | いまのまま |

マスだけの画像（`richmenu-tile-833x843.png`・`1250x843`・`1250x1686`）は、別の形のメニューを作るとき用です。
ドライブスルーの案内は、ricepia.jp のページ（`#drive-thru`）には残ります。

## 6. 累計プレイ人数

- ゲームは、遊び始めた端末を `game_start`、その日はじめて遊んだ端末を `play_day` として Google アナリティクス（GA4）に送ります（アクセス解析をオフにした人と、手元の確認は入りません）
- **累計プレイ人数 ＝ 公開した 2026-10-15 からの `game_start` の数**（端末ごと。同じ人が別の端末やブラウザで遊ぶと2人と数えます）
- GA4 で見る：レポート → エンゲージメント → イベント → `game_start`（期間を 2026-10-15〜今日に）。広告ごとには「探索」で、イベント名 `game_start` × セッションのソース/メディア
- 毎日自動で数える：Actions の「Count Nishio players」（`tools/ga4-stats.js`）が `nishio-go/stats.json` に書き、100人をこえたら はじめの画面に「👥 これまでに〇〇人以上が遊んでいます」と出ます。動かすには GitHub の Secrets に次の2つを入れます（**値はチャットに書かないでください**。GitHub の画面に直接入れます）
  - `GA4_PROPERTY_ID`：GA4 → 管理 → プロパティの詳細 の数字
  - `GA4_SERVICE_ACCOUNT_JSON`：Google Cloud でサービスアカウントを作って鍵（JSON）を作り、そのメールアドレスを GA4 → 管理 → プロパティのアクセス管理 で「閲覧者」にする

### 6-1. Secrets を入れる手順（くわしく）

1. **プロパティIDを控える**：[Google アナリティクス](https://analytics.google.com/) → 左下の歯車（管理）→ プロパティの列の「プロパティの詳細」→ 右上の「プロパティ ID」（9〜10けたの数字。`G-` ではじまる測定IDではありません）
2. **Google Cloud のプロジェクトを用意**：[Google Cloud コンソール](https://console.cloud.google.com/) で、プロジェクトをえらぶ（なければ「新しいプロジェクト」。名前は何でもよい。料金はかかりません）
3. **API を有効にする**：「API とサービス」→「ライブラリ」で **Google Analytics Data API** を検索して「有効にする」（これを忘れると、鍵があっても数えられません）
4. **サービスアカウントを作る**：「IAM と管理」→「サービス アカウント」→「サービス アカウントを作成」。名前は `nishio-go-stats` など。ロールは付けなくてよい（「完了」）
5. **鍵（JSON）を作る**：作ったサービスアカウント → 「鍵」タブ →「鍵を追加」→「新しい鍵を作成」→ JSON →「作成」。JSON ファイルがダウンロードされます（**これは合鍵です。チャット・メール・リポジトリには貼らない**）
6. **GA4 で閲覧できるようにする**：GA4 → 管理 → プロパティの「プロパティのアクセス管理」→ 右上の「＋」→「ユーザーを追加」。メールアドレスに、サービスアカウントのアドレス（`…@….iam.gserviceaccount.com`。JSON の `client_email`）を入れ、役割は「閲覧者」。「メールで通知」はオフ
7. **GitHub の Secrets に入れる**：GitHub のリポジトリ → Settings → Secrets and variables → Actions →「New repository secret」を2回
   - Name `GA4_PROPERTY_ID`、Secret に手順1の数字
   - Name `GA4_SERVICE_ACCOUNT_JSON`、Secret に手順5の JSON ファイルの中身を全部（`{` から `}` まで）
8. **動かして確かめる**：Actions →「Count Nishio players」→「Run workflow」。成功して `nishio-go/stats.json` のコミットができれば完了（それからは毎日 0:23 に数えます）。失敗したら、ログの日本語のメッセージ（「アクセストークンを取得できません」＝鍵の貼りまちがい、「GA4 のレポートに失敗」＝手順3か6）を見ます
9. 使い終わった JSON ファイルは、パソコンから消してよい（なくしても、手順5で作り直せます）

## 7. Google Search Console（検索に出るように）

go.ricepia.jp のページが Google 検索にどう出ているか（検索された言葉・クリック数）を見られ、サイトマップを知らせて早く見つけてもらえます。料金はかかりません。

1. [Search Console](https://search.google.com/search-console) を開き、「プロパティを追加」
2. どちらかでサイトの持ち主であることを確かめる
   - **ドメイン**（おすすめ。ricepia.jp と go.ricepia.jp をまとめて見られる）：`ricepia.jp` を入れ、出てきた TXT レコードを、ricepia.jp の DNS（ドメインを管理している会社の画面）に足して「確認」
   - **URL プレフィックス**（DNS をさわれないとき）：`https://go.ricepia.jp/` を入れ、確認方法は「HTML ファイル」。`google〇〇〇〇.html` という名前のファイルが出るので、**そのファイル名**をチャットで教えてください（中身はファイル名を書いただけの公開してよいもので、秘密ではありません）。リポジトリの一番上に同じ名前で置いて公開し、そのあとで「確認」を押します
3. 確かめられたら、左の「サイトマップ」に `https://go.ricepia.jp/sitemap-go.xml` を入れて「送信」（サイトマップは PR #90 で足したので、それが公開されてから）
4. 数日〜数週間で「検索パフォーマンス」に、検索された言葉とクリック数が出ます
- GA4 で `game_start` を「キーイベント」にしておくと、Google広告でもゲームを始めた数を見られます
