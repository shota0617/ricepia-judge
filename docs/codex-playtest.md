# にしおさんぽGO をプレイしてレビューする手順（Codex などのレビュアー向け）

コードを読むレビューではなく、**実際に遊んでみての感想と不具合**を集めるための手順です。

## 動かし方

```sh
npm install --no-save --no-package-lock playwright@1.48.2   # repo の直下の node_modules に入れる（-g だと require できない）
npx playwright install chromium                              # Chromium（すでにあれば CHROMIUM=場所 でもよい）
node tools/playtest.js playtest-out
```

- ヘッドレス Chromium（スマホの画面 390×780）で `nishio-go.html` を開き、通しで遊んでスクリーンショットと `playtest-out/playtest.json` を残します。
- 地図は `nishio-go/world.json` と `nishio-go/chunks/` を使うので、Overpass や標高タイルにはつながなくても動きます。
- ネットにつながらないときは `LEAFLET_DIR=<leaflet の dist>` を付けます。
- 自分で触るときは、`python3 -m http.server` などで repo の直下を配信して、`http://localhost:8000/nishio-go.html` を開きます。DevTools のスマホ表示がおすすめです。

## 遊んでほしいところ

ゲームの面白さの核は [docs/fun-core.md](fun-core.md) にあります。そのねらいどおりに遊べるかを見てください。

1. **はじめの画面**：何をするゲームか、すぐわかるか。
2. **操作して移動**：スティック・矢印キーで歩き、名所にチェックインします。🧭（おまかせ歩き）がオンなら、市民の話で決まった「イベント」の行き先へ自動で歩きます（手を離して1〜2分ようすを見てください）。
3. **みちしるべ**（🧭 次の行き先）：
   - 西尾の人に話しかけると、次の行き先をすすめてくれます。
   - 矢印と ▼ のとおりに行くと、次が決まります。
   - 札をタップしてひらくと、ほかの行き先（2つまで）に変えられます。
   - 「ほとんど人の話と環境で進み、少しだけ自分で選べる」が楽しいか。
4. **まちメモ**：チェックイン・たからばこ・おまかせ歩き・るすばん（閉じていた間）で、西尾と まわりのまちの話が集まります。
   - 放っておいても、土地のことが分かっていくか。報酬はわざときびしめです。
5. **軽トラ**：乗ると速く走れます。乗っている間は到着を数えません。
6. **せかいちず・きろく・バッジ・西尾の名物**。
7. **あるいて移動**：位置情報を使います。Playwright の `geolocation` で西尾市内の座標を渡します。

## 報告してほしいこと

- **面白かったところ**：もう一度遊びたくなった瞬間。
- **わかりにくかったところ**：迷った・止まった・説明が足りない所。どの画面で、何をしたときかも書いてください。
- **不具合**：再現手順・期待した動き・実際の動き。スクリーンショットがあれば添えてください。
- **改善の提案**：優先度の高い順に3つまで。

報告は PR かイシューへのコメントでお願いします。コードは直さなくてかまいません。
