## ★ 西尾にもあるが、ほかの所にもよくあるもの（5）

西尾の抹茶・海とつながっているが、絵そのものは どこの茶どころ・港にもある。

| 題材 | 西尾とのつながり | 気をつけること |
|---|---|---|
| 防霜ファンの茶畑 | 西尾は抹茶の産地 | 防霜ファンは静岡など茶どころどこにでもある。西尾の茶畑についての出典は見つけていない |
| 茶畑と摘採機 | 同じ | 摘採機も茶どころ共通 |
| 抹茶ソフトクリーム | 西尾の抹茶 | 抹茶ソフトは全国どこにでもある |
| 抹茶パフェ | 同じ | 同じ |
| 漁港と漁船 | 一色・幡豆の漁港 | 絵の漁港は型どおり |

## 確かめて直したこと

- **手筒花火 → 西尾祇園祭に入れかえ**：西尾市で手筒花火が行われる出典は見つからなかった（手筒花火は豊橋が発祥といわれ、リポジトリの出典も幸田町の花火大会だけ）。いちばん「西尾ならでは」ではない題材だったので、出典のある西尾祇園祭（大名行列の毛槍・駕籠、神輿の渡御、市民総踊り）にかえた。番号（No.8001〜8400 など）は同じで、絵と名前がかわる
- **八ツ面山の桜 → 八ツ面山**：八ツ面山が桜の名所という出典は見つからなかったので、桜とは言わない名前にした（絵の木は、ほかの題材と同じく季節で色がかわるだけ）
- **海苔ひび**：出典で確かめられたのは一色町の沿岸だけなので、一色でだけ出るようにした（幡豆・吉良では出さない）
- **鳥羽の火祭りの神男**：黒い服で描いていたのを、古い幟でつくった衣装（赤・白・青の継ぎ合わせ）にした

## まだ確かめていないこと

- 防霜ファン・摘採機が西尾の茶畑で使われていること（茶どころで広く使われるので、たぶんあるが、西尾についての出典はない）
- 絵の細部（丑寅櫓の窓の数、鍮石門の形など）は、写真を見て描いた名所の絵（pixel.js）ほど忠実ではない。48×48 の景色として、それらしく見えるところまで
