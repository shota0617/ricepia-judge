## ★ 西尾にもあるが、ほかの所にもよくあるもの（0）

防霜ファンの茶畑・抹茶ソフトクリーム・漁港と漁船は、下のとおり入れかえた。

## 確かめて直したこと

- **西尾市を調べなおして（docs/nishio-research.md）、のこりの★3題材を入れかえ、2題材を足した**：防霜ファンの茶畑 → 実相寺（西尾茶のはじまり）、抹茶ソフトクリーム → てんてこ祭、漁港と漁船 → 一色さかな広場。足したのは 金蓮寺弥陀堂（国宝）と 三河万歳（国の重要無形民俗文化財）。入れかえた題材は、No.1〜10000 の番号はそのままで、絵と名前がかわる

- **抹茶パフェ → カーネーションの温室、茶畑と摘採機 → 稲荷山茶園**（Codex レビューの指摘。どちらもこのPRで足した題材なので、持っている絵は変わらない）。西尾の大きな産業の「花」が題材に1つもなかったので、施設園芸の生産額が全国トップクラスのカーネーションを入れた

- **手筒花火 → 西尾祇園祭に入れかえ**：西尾市で手筒花火が行われる出典は見つからなかった（手筒花火は豊橋が発祥といわれ、リポジトリの出典も幸田町の花火大会だけ）。いちばん「西尾ならでは」ではない題材だったので、出典のある西尾祇園祭（大名行列の毛槍・駕籠、神輿の渡御、市民総踊り）にかえた。番号（No.8001〜8400 など）は同じで、絵と名前がかわる
- **八ツ面山の桜 → 八ツ面山**：八ツ面山が桜の名所という出典は見つからなかったので、桜とは言わない名前にした（絵の木は、ほかの題材と同じく季節で色がかわるだけ）
- **海苔ひび**：出典で確かめられたのは一色町の沿岸だけなので、一色でだけ出るようにした（幡豆・吉良では出さない）
- **鳥羽の火祭りの神男**：黒い服で描いていたのを、古い幟でつくった衣装（赤・白・青の継ぎ合わせ）にした
