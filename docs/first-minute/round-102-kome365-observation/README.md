# 米づくり365：小さい縦画面の最初の1分

320×568で送った13操作はすべてカードの変化・翌日進行・新しい理由表示につながり、送信後の無反応は0/13だった。初めて変形を記録するまで入力から350.5 ms、最初の○のDOM記録まで1.0315秒。新しい修正対象は確定せず、製品・テストは変更していない。人の離脱率を測った結果ではない。

やめそうな所の候補は、日付が進んでも次の農作業へ近づいていることが分かりにくい可能性。原画は1月1日→3日→8日→14日と進み、状態語は「田おこし まえ」のままだった。これは既存UIの引用（[index.html:3756](https://github.com/shota0617/ricepia-judge/blob/4a38d1e15f8919dd8345f95df935c0a8c0246ddd/kome365/index.html#L3756)）で、初見者の理解や離脱を確定するものではない。

[441行](https://github.com/shota0617/ricepia-judge/blob/4a38d1e15f8919dd8345f95df935c0a8c0246ddd/kome365/index.html#L441)には、箱・点の列・稲の列を運営者の判断でやめ、育ちは大きな絵とことばで見せると明記されている。これらを戻す案は運営者の判断に回し、変更しない。既存の状態語に次の工程を添える案は今回検証できなかった設計仮説として保留する。

## 遊び方と記録

対象は `4a38d1e15f8919dd8345f95df935c0a8c0246ddd` の `/kome365/index.html`。最上位の `python3 -m http.server 8000` からローカルChromiumで開き、新しいcontext、isMobile/hasTouch、CPU1、CDP `Input.dispatchTouchEvent` で操作した。手元の資産を使い、外部要求の記録は0、追加導入はない。

10秒無操作の後、写真の保存を待ってから60秒の入力時計を開始。現在見える手本、または同じカードで先に明瞭に見えた手本の向きを使った。22回の選択機会のうち13回送信（すべて左、現在の手本4・同じカードの記憶9）、向きが確定しない9回は入力しなかった。この9回を「9回触って反応しなかった」とは数えない。要求スワイプ120 msに対し、実送信の開始〜終了は119.5〜127.1 msだった。

| プレイ時計 | 記録されたこと |
| --- | --- |
| 0.252秒 → 0.6025秒 | 初入力 → カード変形の初DOM標本（差350.5 ms） |
| 1.2835秒 | 翌日と最初の○をDOMで記録（入力から1.0315秒） |
| 53.410秒 → 54.2105秒 | 最後の送信 → 1月14日へ進み、新しい理由を記録 |

○9・✗4はDOMの理由表示開始の数。4原写真に判定の吹き出しは写っていないが、60秒間なかったとは扱わない。最初の○は観察開始から16.9565秒で、そこには観察写真の保存待ち5.574秒が含まれる。この待ちはプレイ時計の外で、入力応答の遅延へ足さない。

イベント時刻からcapture handlerまで273.1〜462.2 ms、handlerからdrag DOMまで3.5〜17.6 ms。配送・描画・測定負荷を分離できず、preview計算を遅れの原因と断定しない。変形のDOM時刻は物理的な描画開始ではない。

## 検証と限界

通常プレイの実 child/outer exitは1。`/favicon.ico` の404が2件あり、原文は `Failed to load resource: the server responded with a status of 404 (File not found)`。104送信は全ACK、入力処理・driver・遅い終了処理のエラーは0。保護3ファイルを含むsource前後一致、CPU復帰・browser閉鎖を確認したが、実行全体をエラーなしとは扱わない。

`pytest tests/` は実 exit127、`/bin/bash: line 1: pytest: command not found`（実結果のchunk `5397ef`）。suiteは実行できなかった。修正対象が確定せず、再現10回・追加回帰テストのRED/GREEN・製品の変更前後比較・5サイズ比較は未実施で、成功数に足していない。

方法成績は A（入力・時刻）0件、B（原画）0件、C（入力経路・状態）0件の新規確定欠陥。今回の勝者はなく、各方法を次の周へ継続する。短い斜め操作・カード外入力・背景復帰などは未再現。速いスワイプ、タップ非選択、理由の位置と2秒、手本0.3秒、30秒カード、音、かかし・太陽などの運営境界は維持した。
