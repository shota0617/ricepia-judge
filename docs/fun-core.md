# にしおさんぽGO の面白さの核

## 「このゲームの何が面白いの？」への答え

> **西尾と まわりのまちを、さんぽして知る。** まちの人の話や、季節・天気・まわりのようすが、次に行く所をすすめてくれる。
> すすめられた所へ行くと、そこでまた次の話と「まちメモ」が待っている。放っておいても（おまかせ歩き・るすばん）まちのことが分かっていく。

もとにある考え方：**人生は自分で決めるものではなく、まわりの環境や人の話を聞いて進んでいくもの。**
ふつうのゲームは「どこへ行くか」をプレイヤーが選びます。このゲームでは、ほとんどを西尾の人と環境にゆだねます（少しだけ自分でも選べる）。
思いがけない所へ連れて行かれること、そこで出会った人がまた別の所を教えてくれること、そのたびに土地のことを知ること。それが面白さです。

## しくみ：みちしるべ

- **人の話で決まる（イベント）**：西尾の人（`nishio-go/npcs.js`）に話しかけると、話の最後に、その人が次の行き先をすすめてくれる（「📜 イベント」。着くと「🎉 イベント達成」）。
  人にはそれぞれ「知り合い」がいて（`refer`）、まだ会っていない知り合いを、その人のことばで紹介してくれる（例：茶畑のおじいさん →「茶の種を宇治から取り寄せた話は、紅樹院の近所のおばあさんにきいてみりん」）。知り合いにみんな会ったら、環境が次を決める。
  画面の下に「🧭 次の行き先」として出て、ドット絵の地図では水色の矢印と ▼ が、ふつうの地図では点線が、そこを指す。
- **環境で決まる**：すすめる中身は、そのときの環境しだい。
  - 今月・来月に行事がある → その会場へ
  - まだ話していない人がいる → その人のところへ
  - まだ行っていない名所 → そこへ
- **日付と季節で決まる（こよみ）**：`nishio-go/season.js`。地図の左上に「10/17（土）🍁秋・寒露のころ・🌾稲刈り」のような札が出る（タップで節気の意味・田んぼのようす・いまの見ごろ）。
  - 季節の見ごろ（梅・桜・しだれ桜・茶摘み・バラ・あじさい・海水浴・筆柿・紅葉・碧南のにんじん）の場所が、まわりのようすの行き先になる（「季節（🌸春・春分のころ）」の話として）
  - 田んぼの色が月で変わる（田おこし→田植えの水田→青田→黄金色の稲穂→刈田）。森は紅葉のころに色づき、公園には桜のころに桜の木
  - 話しかけると、時間帯のあいさつ（おはよう／こんにちは／もう夕方だねえ／こんばんは）。その場所が見ごろなら、その話も
  - 土用の丑の日（暦の計算による）は、うなぎにゆかりの場所の人が うなぎの話をする
- **天気で決まる**：`nishio-go/weather.js`。気象庁のアメダス（岡崎・蒲郡・大府・一色）と、きょうの天気予報（愛知県西部・東部）から、いまの天気を出す。雨がふっていると、屋根のある所（博物館・資料館・美術館・水族館・図書館）が いちばん先の行き先になる（「天気（☔雨）」の話として）。こよみの札に天気と気温、ドット絵には雨や雪がふり、人は天気のひとことを言う
- **着いたら次が決まる**：すすめられた所に着くと、まわりのようすから次の行き先が決まる（人のところなら、話しかけたときに決まる）。
- **少しだけ自分で選べる**：みちしるべの札をタップしてひらくと、ほかの候補（2つまで）が出て、押すとそこへ変えられる（前の行き先も候補に残るので戻せる）。選ばなければ、すすめのとおりに進む。ほかの人の話を聞けば、行き先はその人のすすめに変わる。

決め方は `nishio-go/game.js` の `decideGuide`。話した人の知り合い、雨なら屋根のある所を先に。それ以外は話を聞くたびに「名所・人」の順番を入れ替えて、同じ種類ばかりにならないようにしている。

## 行った先で知ること：まちメモ

着いた名所（チェックイン）・たからばこ・おまかせ歩きの道すがら・るすばん で、その土地の「まちメモ」が1つずつ集まる。
中身は、地区の豆知識・注目スポットの説明・行事・名物（どれも出典つき）と、本店から15kmの円に入る まわりのまち（刈谷・知立・半田・東浦・阿久比・武豊：`nishio-go/machi.js`）の話。
いまいる所の近くの話から選ぶ（7市町の外にいるときは そのまちの話から）。きろくの「📖 まちメモ」で読み返せる。

（以前あった「米屋の仕事」＝籾集め・選別・精米・米袋は、なくした。当店は名所のひとつ・特典のお店として残っている）

## 報酬はきびしめ（いまの設定）

| ルール | 値 |
|---|---|
| すすめられた所に着いた | +5pt（1日5回まで） |
| 人とはじめて話した | +10pt（同じ人は1回だけ） |
| るすばん（操作して移動・閉じていた間） | 15分に1pt・まちメモ1時間に1つ（最大3つ）。10分から、上限4時間（おまかせ強化でのびる） |

数字は `nishio-go/game.js` の `GUIDE_PTS`・`GUIDE_DAILY`・`IDLE` で変えられる。

## 既存の遊びとの関係

名所のチェックイン・今日のクエスト・たからばこ・西尾の名物は、みちしるべで連れて行かれた先で出会うもの。
