# にしおさんぽGO の面白さの核

## 「このゲームの何が面白いの？」への答え

> **西尾の田んぼを歩いて籾（もみ）を集め、お米屋さんの目で選別して、精米する。自分の米袋が少しずつ重くなっていく。**
> いいお米を見分ける目がうまくなるほど、1等米がたくさん貯まる。

ほかの位置情報ゲームにはない「米屋の仕事」を、西尾の本物の田畑と当店（近藤米穀店・らいすぴあ秀幸）でやってみるゲームです。

## 3つの手応え

| | 何をする | 何が面白い | 米屋ならではのところ |
|---|---|---|---|
| ① 集める | 田畑のマスを歩くと籾が集まる（1マス1日1回） | まだ歩いていない田んぼを探して、西尾の田園を歩きまわる | 西尾の田んぼ。ricepia.jp でも五代目が田んぼの実りを記録している |
| ② 目利き | 当店に持ち込み、12秒で悪い粒（着色粒＝カメムシのあと・未熟粒・砕粒）を取りのぞく | 目と指の勝負。うまくいくと1等、あせると3等 | 店主は農産物検査員。「しっかり選別して、きれいなお米だけをお届け」（ricepia.jp） |
| ③ 精米 | 5分づき・通常・クリーン精米をえらんで白米に。米袋へ | 5kg → 10kg → 30kg → 1俵（60kg）と、袋が満ちていく | らいすぴあのコイン精米所と同じ3つの仕上がり。精米のたびに当店の一言（精米したての味・翔米・ドライブスルー40年など） |

このくり返しが、そのまま **当店への来店（持ち込み）** になります。あるいて遊ぶ人は本物のお店へ、操作して遊ぶ人もゲームの中で当店へ足を運びます。

## 報酬はきびしめ（いまの設定）

| ルール | 値 |
|---|---|
| 籾の量（田畑1マス・1日1回） | あるいて 0.3合／操作 0.15合 |
| 1日に集められる籾 | あるいて 60合／操作 30合 |
| 集まらないとき | 車に乗っている・地図のタップで飛んだ・GPS の誤差が大きい・乗り物で移動中 |
| 持ち込み | 籾5合から。当店2店舗のチェックインできる距離でだけ |
| 白米の量 | 籾 × 0.8（もみすり）× 仕上がり（5分づき0.95・通常/クリーン0.9）× 等級（1等1.0・2等0.9・3等0.75） |
| 等級 | 1等：悪い粒を全部取って、まちがいなし／2等：7割以上取って、まちがい1つまで／3等：それ以外 |
| ポイント | 米袋の目標に届いたときだけ：5kg 50pt・10kg 100pt・30kg 300pt・1俵 600pt |

数字は `nishio-go/game.js` の `RICE`・`POLISH`・`RICE_GOALS` で変えられます。1合＝約150gで kg に直しています。

## 既存の遊びとの関係

- 名所のチェックイン・今日のクエスト・たからばこ・西尾の人たち・西尾の名物は、「西尾を歩く理由」を増やす脇役。
- 核（集める→目利き→精米）は、それらと並行して進む「ずっと続く目標」。
