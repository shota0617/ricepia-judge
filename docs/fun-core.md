# にしおさんぽGO の面白さの核

## 「このゲームの何が面白いの？」への答え

> **行き先は、自分では決めない。** 西尾の人の話や、季節・時間・まわりのようすが、次に行く所を教えてくれる。
> 話を聞いて、すすめられた所へ行くと、そこでまた次の話が待っている。

もとにある考え方：**人生は自分で決めるものではなく、まわりの環境や人の話を聞いて進んでいくもの。**
ふつうのゲームは「どこへ行くか」をプレイヤーが選びます。このゲームでは、それを西尾の人と環境にゆだねます。
思いがけない所へ連れて行かれること、そこで出会った人がまた別の所を教えてくれること。それが面白さです。

## しくみ：みちしるべ

- **人の話で決まる**：西尾の人（`nishio-go/npcs.js`）に話しかけると、話の最後に、その人が次の行き先をすすめてくれる。
  人にはそれぞれ「知り合い」がいて（`refer`）、まだ会っていない知り合いを、その人のことばで紹介してくれる（例：茶畑のおじいさん →「茶の種を宇治から取り寄せた話は、紅樹院の近所のおばあさんにきいてみりん」）。知り合いにみんな会ったら、環境が次を決める。
  画面の下に「🧭 次の行き先」として出て、ドット絵の地図では水色の矢印と ▼ が、ふつうの地図では点線が、そこを指す。
- **環境で決まる**：すすめる中身は、そのときの環境しだい。
  - 籾がたまって重い → お店へ（日曜は本店がお休みなので らいすぴあへ。営業時間は ricepia.jp のとおり）
  - 今月・来月に行事がある → その会場へ
  - 9〜10月は新米の季節 → 近くの田畑へ
  - まだ話していない人がいる → その人のところへ
  - まだ行っていない名所 → そこへ
- **着いたら次が決まる**：すすめられた所に着くと、まわりのようすから次の行き先が決まる（人のところなら、話しかけたときに決まる）。
- **自分では選べない**：行き先を自分で選ぶボタンはない。変えたいときは、ほかの人の話を聞く。

決め方は `nishio-go/game.js` の `decideGuide`。籾が重いときはまずお店、それ以外は話を聞くたびに「行事・人・田畑」の順番を入れ替えて、同じ種類ばかりにならないようにしている。

## 行った先でやること：米屋の仕事（米屋ならでは）

すすめられた田畑やお店で、当店（近藤米穀店・らいすぴあ秀幸）の本物の仕事をゲームにしたものができる。

| | 何をする | 米屋ならではのところ |
|---|---|---|
| ① 集める | 田畑のマスを歩くと籾が集まる（1マス1日1回） | 西尾の田んぼ。ricepia.jp でも五代目が田んぼの実りを記録している |
| ② 目利き | 当店に持ち込み、12秒で悪い粒（着色粒＝カメムシのあと・未熟粒・砕粒）を取りのぞく。1等〜3等 | 店主は農産物検査員。「しっかり選別して、きれいなお米だけをお届け」（ricepia.jp） |
| ③ 精米 | 5分づき・通常・クリーン精米をえらんで白米にし、米袋へ（5kg → 10kg → 30kg → 1俵） | らいすぴあのコイン精米所と同じ3つの仕上がり。精米のたびに当店の一言 |

籾がたまると、みちしるべが当店へ案内する。だから、遊ぶことがそのまま当店への来店（持ち込み）になる。

## 報酬はきびしめ（いまの設定）

| ルール | 値 |
|---|---|
| すすめられた所に着いた | +5pt（1日5回まで） |
| 人とはじめて話した | +10pt（同じ人は1回だけ） |
| 籾の量（田畑1マス・1日1回） | あるいて 0.3合／操作 0.15合 |
| 1日に集められる籾 | あるいて 60合／操作 30合 |
| 籾が集まらないとき | 車に乗っている・地図のタップや「ここへ移動」で飛んだ（操作は十字ボタンの1歩だけ）・GPS の精度が35mより悪い・ゆらぎ程度の移動・乗り物の速さ |
| 持ち込み | 籾5合から。当店2店舗のチェックインできる距離でだけ |
| 白米の量 | 籾 × 0.8（もみすり）× 仕上がり（5分づき0.95・通常/クリーン0.9）× 等級（1等1.0・2等0.9・3等0.75） |
| 等級 | 1等：悪い粒を全部取って、まちがいなし／2等：7割以上取って、まちがい1つまで／3等：それ以外 |
| 米袋のポイント | 目標に届いたときだけ：5kg 50pt・10kg 100pt・30kg 300pt・1俵 600pt |

数字は `nishio-go/game.js` の `GUIDE_PTS`・`GUIDE_DAILY`・`RICE`・`POLISH`・`RICE_GOALS` で変えられる。1合＝約150gで kg に直している。

## 既存の遊びとの関係

名所のチェックイン・今日のクエスト・たからばこ・西尾の名物は、みちしるべで連れて行かれた先で出会うもの。
