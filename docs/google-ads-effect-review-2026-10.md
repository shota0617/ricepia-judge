## 2. 意見が分かれたところ

- **新米２**：Opus は「すぐ減らさない」（9月は CV 28件・1件 ¥551。ほぼ LINE なら #2 より安かったかも）。Fable は「増やさない」（28件に電話などがまざっているかも。8月の ¥2,069 で見る）。
  → 決め手は「9月の28件のうち LINE が何件か」。下の書き出しの 4章・5章で分かる。
- **判断する日**：Fable は 11/12 ごろ、Opus は「変更が入った日から4〜5週間後」。どちらも、それまで予算と入札は動かさない。

## 3. 先にやること

1. **数字をそろえる**：`tools/google-ads-effect-2026-10.js`（Google広告スクリプト・読むだけ）を管理画面で「プレビュー」する。マイドライブに `ricepia_google_ads_effect_<日付>.txt` ができる
   - 中身：キャンペーンと入札・コンバージョンの設定と入札に使う目標（10/15 の変更が入ったか）・変更の前と後・週ごとの LINE 1件の費用・日ごとの CSV・変更履歴（いつ何が変わったか）・検索語句・P-MAX の検索カテゴリ（店名の検索にお金を使っていないか）
   - API の認証情報があれば `node tools/google-ads-run.js --job effect --out effect.txt` でも同じ
2. **LINE の本当の友だち追加を週ごとに出す**：LINE公式アカウントの管理画面（分析 → 友だち）で 8月からの週ごとの追加数・ブロック数を出し、上の「LINE（全CV）」と並べる
3. **広告から来た人専用の LINE の入口を作る**：ricepia.jp の LINE ボタンは、ボタンごとに別の lin.ee（`AULbClm`・`3Ha8FUJ`・`uPhkiiv`・`o5IAq4y` など）になっている。LINE公式アカウントで広告用の lin.ee を1つ作り、広告から来た人（URL に `gclid` か `utm_source=google`）にはそれを出すようにすれば、「広告から増えた友だち」が LINE 側で数えられる。lin.ee ができたら、サイトの差しかえを作る（`ricepia-jp/`）
4. **LINEヤフー広告の数字の意味を確かめる**：Drive の「YDA日次」は `2026-10-23 | 1600 | 911` の1行だけで、列名が無い。費用・表示・クリック・友だち追加の列名つきで出す

## 4. 判断のめやす（仮。粗利と追加完了率が分かったら直す）

- 「友だち 1人の費用」＝ 費用 ÷ 本当に増えた友だち
- 仮の上限：LINE クリック 1件 約 ¥700（粗利 ¥700 × 2回来店 × 追加完了 50%）。友だち1人なら約 ¥1,400
- 上限を4週間こえ続けるキャンペーンは予算を減らす。下回り、「予算で制限」が続くなら2割ふやすのを試す
- ルート検索（サブ）が半分以下に落ち、店の客数も落ちたら、LINE だけにした副作用として見直す
- 新米２ は件数が少ない（1日 0.3〜0.9件）ので、4週間ではぶれが大きい。クリック単価・検索語句もあわせて見る。「新米」の文は 12/31 までに止めるので、年明けに続けるかを決める

## 6. 止めるかどうかの判断（2026-10-24）

`tools/google-ads-pause-2026-10.js`（Google広告スクリプト）を貼って「プレビュー」→「実行」（または `node tools/google-ads-run.js --job pause` → `--apply`）。管理画面で「一時停止」を押しても同じ。

| もの | 判断 | 理由 |
|---|---|---|
| キャンペーン「新米２」 | **先に中身を見る**（見直し：Fable） | 8月（8/3〜9/1）は LINE 1件 ¥2,069・クリック単価 ¥53 だが、6件だけ。9月までの30日（8/23〜9/21）は CV 28件・1件 ¥551・クリック単価 ¥35 と大きく良くなっている。8/23〜9/1 の LINE は4件なので、9/2〜9/21 は約24件（中身が LINE かは未確認）。新米の需要がいちばん高い時期で、「新米」の文は 12/31 まで |
| P-MAX #2 | 止めない | 広告費の8割。LINE 1件 ¥786 は採算ライン（仮 ¥700）を12%こえている（少し赤字側）。止めると広告がほぼ全部止まる。10/15 の LINE 重視の結果（4週間後）で決める |
| 業務用米_検索 | 止めない（止めても同じ） | 30日 表示0回・費用 ¥0。止めても何も減らない。業務用の需要はある（#2 のサイトリンク「飲食店様向け米 太郎」164クリック）ので、表示されない原因を調べる |
| #2 のサイトリンク「無洗米Q&A」「コスパ米 穂のぼの」 | 止めない | クリック率は低い（9.6%・8.8%）が、サイトリンクはクリックされたときだけ費用がかかる。サイトリンクごとの LINE の数は無いので、悪いとは言えない |
| にしおさんぽGO ゲーム | 始めない（いまも停止） | ゲームに計測のラベルが入るまで |
| LINEヤフー広告 | 判断できない | 「1600 / 911」の意味が分からない。1600 が1日の費用なら月 約 ¥48,000 で、Google の #2 に近い。列名つきの数字が要る |

- **新米２ の決め方**：管理画面 → キャンペーン → 新米２ → 期間 8/23〜9/21 → 分割（セグメント）→ コンバージョン アクション。LINE が20件以上なら止めずに文だけ直す（反映スクリプトの第1週）。10件以下なら止める（`tools/google-ads-pause-2026-10.js`）。見られないあいだは、予算を半分にして待つ（クリック数の最大化なので学習のやり直しはほぼ無い）
- 古い広告文（「安い」「新米予約」）は、止める理由ではなく直す理由
- 新米２ を止めると、そこに付けたゲームのサイトリンクも出なくなる
- もっと大きいお金の疑い：P-MAX #2 のサイトリンク以外のクリック（約 ¥20,900・約4,700クリック・1クリック約 ¥4.4）。管理画面の P-MAX の配信先レポートでアプリ面の割合を見る（どのクリックから LINE が出たかはデータに無いので、無駄と決めつけない）
- 反映スクリプトの第1週は 新米２ に「業務用・卸・飲食店」の除外を入れる。業務用米_検索が表示0のままだと業務用の検索がどこからも出なくなるおそれ（推測）
