### 問題点

1. **#2 は、¥1 のルート検索を LINE と同じ重みで最適化しています。** Google広告では、キャンペーンの目標に入っているメインのアクションだけが「コンバージョン」列に入り、自動入札（スマート自動入札）はこの列を最大化します。#2 の CV の7割がルート検索なので、費用の8割を使うキャンペーンが実際にはルート検索を多く取りにいっていたことになります。
   - #1 では入札対象だったのにルート検索が0件で、#2 では 8/18 から急に計上され始めました。店舗住所やビジネスプロフィールの紐づけが関係している可能性があるので、あわせて確認してください。
2. **LINE は「ボタンのクリック」です。** 本当に友だちが増えたかは、LINE公式アカウントの管理画面でしか分かりません。
3. **価値（¥95・¥1）は入札に使われていません。** どのキャンペーンも件数を最大化する入札なので、¥95 も ¥1 も同じ1件として扱われます。
4. **新米２の目標に YouTube の成果が入っています。** 今の入札（クリック数の最大化）は CV を見ないので、現時点では影響しません。CV を基準にした入札に切り替える前に外しておく、予防のための作業です。
5. 電話を入札に使う設定なのに、新米２には電話アセットが付いていません。#2 には電話アセットがありますが、電話が CV に入っていません。

### 直し方

**① まず管理画面で現状を確認する**
- 目標 → コンバージョン → 概要 →「キャンペーンの目標」で、#2・新米２ の入札にどのアクションが使われているかを見る。
- LINE公式アカウントの友だち数を週ごとに見て、広告の「LINE追加クリック」の件数と比べる（8月〜10月）。

**② 何を成果とするかを決める（お店の判断）**
- **A. 来店を増やしたい**：ルート検索と電話を主な成果に含めます。
  - ドライブスルーのお店にとって、ルート検索は来店の強いサインです。
  - 仮にルート検索1件を¥900（10kg ¥4,500 × 来店率20%）とすると、#2 のルート検索116件の見込み売上は約¥10.4万です。ただしこれは売上で、利益ではありません。広告費¥39,314 を回収するには、ほかの費用を除いても粗利率が約38%以上必要です。原価・平均購入額・リピート（再購入）の価値を確かめてから、増額するかを判断してください。
  - 注意：ルート検索の価値だけ上げて LINE を¥95のままにすると、入札はさらにルート検索に寄ります。LINE にも「友だち1人がもたらす売上 × 追加完了率」で釣り合う価値を付けてください。
- **B. LINE友だちを増やしたい**：#2 の入札に使う成果を LINE と電話にします（電話は追加が必要）。ルート検索を外すと、来店も減るおそれがあります。

**③ 決めた定義に合わせて、全キャンペーンの目標をそろえる**
- YouTube の2つのアクションは「サブ」にして、入札に使わないようにする。
- 「広告からの電話」に通貨 JPY と価値を設定する。
- 入札戦略（コンバージョン値の最大化など）を変えるのは、目標をそろえた後にする。

### 決定：LINE重視（2026-10-15）— 設定の手順

お店の判断で **B. LINE友だちを増やす** に決めました。入札に使う成果を「LINE友だち追加クリック」の1つだけにします。ほかのアクションは削除せず「サブ」にするので、件数は「すべてのコンバージョン」列で引き続き見られます。

**手順1：ほかのアクションを「サブ」にする**（目標 → コンバージョン → 概要 → 各アクション → 設定を編集 →「アクションの最適化」）

| アクション | 変更後 | 理由 |
|---|---|---|
| LINE友だち追加クリック | **メイン（そのまま）** | 唯一の成果 |
| ローカル アクション - 経路 | サブ | #2 の CV の7割を占め、入札を引っぱっていた |
| 広告からの電話 / Clicks to call | サブ | 件数が少なく、計測もそろっていない（通貨 `XXX`）。サブにする前に通貨を JPY に直しておく |
| Local actions - Other engagements / Website visits | サブ | 集計外だが、念のため入札対象から外す |
| YouTube follow-on views / channel subscriptions | サブ | 検索・P-MAX の成果ではない |

**手順2：キャンペーンの目標をアカウントの設定にそろえる**
- P-MAX #2：キャンペーン設定 → 目標 →「アカウントのデフォルトの目標を使用」に切り替える。今はキャンペーン独自の目標です。
- 新米２：すでにアカウントの設定を使っているので、手順1だけで LINE のみになります。
- 変更後、目標 → 概要 →「キャンペーンの目標」で、どちらも「登録（LINE友だち追加クリック）」だけになっていることを確認してください。

**手順3：入札はそのまま**
- P-MAX #2 は「コンバージョン数の最大化」のまま。目標CPAはまだ入れません。
- 新米２ は、第1週の作業（アセット・除外キーワード・地域）が終わってから「コンバージョン数の最大化」に切り替えます。
- 予算は据え置きます。3〜4週間たって、LINE 1件の費用が見えてから判断します。

**変更後に起きること（失敗ではありません）**
- 管理画面の「コンバージョン」の件数は大きく減ります（#2 は約7割がルート検索だったため）。CV単価は見かけ上上がります。比べるときは、変更前の数字も LINE だけで比べてください。
- 1〜2週間は学習期間で、配信量や費用がぶれます。この間は設定を変えないでください。
- ルート検索が減ると、来店が減る可能性があります。「すべてのコンバージョン」列のルート検索の件数と、店頭の客数を一緒に見てください。

**毎週見る数字**

| 指標 | どこで見るか | 比べる基準 |
|---|---|---|
| LINE追加クリック 1件の費用 | Google広告（LINE友だち追加クリックの CV単価） | #2 の8月：¥786（#1 の¥198は5日間だけの数字なので目安） |

| ルート検索の件数（サブ） | Google広告「すべてのコンバージョン」 | 変更前：#2 で1日4〜17件 |

3〜4週間たって LINE 1件の費用が安定したら、その金額を目安に目標CPAを入れるか、予算を増やすかを判断します。
