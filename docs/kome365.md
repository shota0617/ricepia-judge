# 米作り365（kome365.html）

西尾の田んぼ一枚（10a・コシヒカリ）で、1年のお米づくりを **スワイプだけ** で進めるゲーム。1ファイル（`kome365.html`）で動く。ビルド不要・ライブラリなし・スマホ縦画面が主。
運営者の指示は「米作り365はスワイプする楽しさを軸に」。ボタンは「はじめる」と「もう一回」だけ。

## あそび方（1周目）

1日目は 4月1日。右へスワイプすると あしたになり、田んぼが変わる。収穫まで行くと 検査の結果（等級・収量・整粒歩合・食味）が出る。

| 場面 | ↑ | ↓ | → | ← |
|---|---|---|---|---|
| たねもみ（4月） | 桶の水に つける | 芽が出たら 苗箱に まく | あしたへ（積算水温が たまる） | 見る |
| なえ（約30日） | じょうろで 水（土が かわくと しおれる） | — | あしたへ | 20日目から 田うえへ |
| 田うえ | — | — | — | 1列ずつ うえる（4回） |
| たんぼ | 水を入れる（長さで 量。最大 15cm） | 水を落とす（空にすると 中干し） | あしたへ | 追肥・穂肥（できる時。水が ある 時だけ）／稲刈り（5回）／ふだんは 1株を 掘り出して 見る（札に 株と ものさし） |
| かんそう | — | — | 1日ずつ かわく（約3.4%）。15.5% 以下で めくりが 止まる | 15% まで 下がったら 検査へ |

- こめつぶ（点の目のキャラクター）が、短い吹き出しで いまの様子と つぎの一手を言う。ていねい語。
- HUD は 日づけ・きょうの天気と気温・あすの天気（2周目）・いまの数（水 cm など）。
- パソコンは 矢印キーでも 同じ（Shift+→ で 6日）。

### スワイプの手ごたえ（「スワイプする楽しさ」を 1つずつ）

- **→ はじくと パラパラ**：指をはなす直前の速さと長さで 1〜14日が きまり（ふつうの速さ 0.6px/ms までは 1日、1.5px/ms で 4日、3px/ms で 9日、最大 10日。引いて 止めてから はなすと 1日。3周目）、日めくりが 持ちあがって とび、間隔が だんだん ゆっくりになる（慣性）。1日ごとに「ぺら」の音と 田んぼの変化。3日ごとに 軽い振動。
- **めくれている とちゅうで 指を おく／← で 止まる**（ブレーキ）。乾燥は 15.5% 以下になると めくりが 自動で 止まる（乾燥機の 仕上がりの 合図。2周目）。もう一度 → すると 乾かしすぎ。
- **↑↓ は 指について 水面が 動く**：引いている間は 水面が指の高さに ついてきて（みせかけ）、はなした瞬間に 本当の水位になり、ばねで ゆれて 落ちつく。「ちゃぷ」「ざーっ」の音と 振動。
- **← の しごとは 回数で 手ごたえ**：田うえは 4回、稲刈りは 5回（1列ずつ 切り株になる）。できた時は「済」の はんこが「ポン」と 落ち、肥料や もみが 飛ぶ。
- 台風の日は 画面が ゆれる。5〜6月の 水には オタマジャクシ、7〜9月は トンボ（3周目）。
- 音は WebAudio で作った素朴な音（外の音は使わない）。振動は `navigator.vibrate`（iPhone の Safari では 鳴らない）。

## 生育のしくみ（ゲーム内の 簡略モデル）

運営者のアーティファクト「稲育成ゲーム」の生育モデル（茎数・草丈・茎幅・葉色SPAD・根・水管理・追肥・倒伏・白未熟粒・整粒歩合・等級・食味値）を、**日ごとに進む形に 組みかえた**。数は ゲーム用で、本物の 予測ではない。

- 目標穂数 380本/㎡、標準の植え方 50株/坪（15.1株/㎡）→ 1株 25本が 目標茎数。
- 茎数は 田植え後 7〜50日に ふえる（浅い水ほど ふえ、深い水と 中干しは 抑える。葉色が 濃いほど ふえる）。目標を こえた茎は 45日以降に 枯れる。
- 草丈・茎幅・葉色（SPAD）は 日ごとに 変わる。追肥 N3kg で +10.8、穂肥 N2kg で +6.4（アーティファクトと同じ 換算）。
- 根：中干し（田植え後 30日〜出穂 26日前に 水が 1cm 未満）で ふえる。中干しの 間の 雨は 溝から 落ちる（本物の 溝切りの 代わり：ゲームでは 雨の 3割だけ たまる）。12日を こえる 強い中干しは 減らす。深水 10cm 以上は 少し減る。
- 出穂は 田植え後 80日（寒い日で 少し おくれる）。出穂後は 日平均気温を 積算し、刈取の 目安に使う。
- 開花・穂づくりの時期の 水切れ、登熟期の 早い落水、出穂後 20日間の 高温（水を 入れかえた日は 和らぐ）、台風（倒伏）が 品位を 下げる。
- 検査：整粒歩合＝100 −（白未熟・青未熟・胴割れ・被害粒）− 6。等級は 70/60/45%。食味値は タンパクと 整粒から。水分 16% を こえたままなら 規格外。

## 出典（本物の こと）

ゲーム内の 吹き出しに「（栃木県）」のように 出どころを 添えている。数は 資料の「目安」で、地域・年で 変わる。

- 玄米の検査規格：整粒の最低限度 1等 70%・2等 60%・3等 45%、水分 15.0%。[農林水産省 玄米の検査規格](https://www.maff.go.jp/j/seisan/syoryu/kensa/kome/k_kikaku/index.html)
- 浸種：積算温度 120℃ が目安（日平均水温×日数）。催芽は はと胸まで。[栃木県 水稲 育苗管理](https://www.pref.tochigi.lg.jp/g58/seisangizyutsu/documents/suitoukannri-ikubyou.pdf)（WebSearch の要約で確認）
- 育苗日数：中苗で 30〜40日 とする資料がある（WebSearch の要約。どの県の資料かは 確定できず、ゲームでは「30日ほど」と ぼかした）。
- 活着期：田植え直後は 植えいたみで 吸水が落ちるので、葉先が出る程度の 深水で 苗を守る。[岩手県 稲作情報](https://www.pref.iwate.jp/agri/_res/projects/project_agri/_page_/002/000/188/gogai0518.pdf)
- 分げつ期：浅水管理で 水温・地温を上げ 初期生育を 促す。[全農 高品質米づくり（初期の水管理）](https://www.zennoh.or.jp/ty/einou/high_quality_rice/pdf/production_001_05.pdf)
- 中干し：目標茎数を 確保したら 直ちに始める。窒素吸収を 一時的に抑えて 過剰分げつを防ぎ、根を深く伸ばす。[岩手県 2023 水稲 第4号](https://www.pref.iwate.jp/agri/_res/projects/project_agri/_page_/002/007/047/2023suitou04.pdf)。期間は 7〜10日、田面に 1〜2cm の亀裂・足跡がつく程度。幼穂形成期の前に 終える。[秋田県 R8 稲作情報 第4号](https://www.pref.akita.lg.jp/uploads/public/archive_0000080784_00/R8稲作情報04-0626.pdf)。強い中干しは 根を切る おそれ。[福井県 2026 第8号](https://www.pref.fukui.lg.jp/doc/noushi/inasaku_2026_d/fil/20260612_No8.pdf)
- 出穂：5月上旬植えの コシヒカリは 7月下旬に 出穂（茨城県の例。愛知の値ではない）。[茨城県 水稲生育情報](https://www.pref.ibaraki.jp/nourinsuisan/nishinourin/bannofu/keiei/documents/r8suitouseiikuno5.pdf)
- 高温登熟：出穂後 20日間の 平均気温が 26℃を こえると 白未熟粒が ふえる。[千葉県 高温障害対策](https://www.pref.chiba.lg.jp/ninaite/system/documents/kouonsyougaitaisaku.pdf)。出穂後 20日間の 掛け流しで 地温が下がり 品質が上がる。[福島県](https://www.pref.fukushima.lg.jp/uploaded/attachment/448369.pdf)。間断かん水・かけ流しで 基部未熟粒を抑え、早期落水を 避ける。[栃木県 成果](https://www.agrinet.pref.tochigi.lg.jp/nousi/seikasyu/seika40/seika_ken1komemijyuku.pdf)
- 刈取適期：出穂後の 積算気温 1000℃ 前後（一部 950℃）。[栃木県 2023 水稲](https://www.pref.tochigi.lg.jp/g59/documents/20230818suitou2.pdf)。1,200℃ を こえると 胴割粒が ふえる。[福島県 水稲の刈取り](https://www.pref.fukushima.lg.jp/sec/36210a/suitoukaritori.html)。積算 1,001℃ の時点で 籾水分 25% 前後（埼玉県の 2024年の例）。[埼玉県 籾水分情報](https://www.pref.saitama.lg.jp/documents/53276/momisuibunzyouhou4.pdf)
- 愛知県：平坦地では 極早生の コシヒカリ・早生の あいちのこころ・中生の あいちのかおりSBL などを 組み合わせ、収穫は 8月中旬〜11月。[愛知県 愛知産の穀類](https://www.pref.aichi.jp/soshiki/engei/aichisan-kokurui-cha.html)。西尾市の 主力品種は この周では 確定できなかった（同ページで コシヒカリの 主な産地は 豊田・豊橋・安城）。ゲームの 品種は 参考にした アーティファクトと 同じ コシヒカリ。

### 作らなかった・言いきらなかった もの

- 西尾の 本物の 気象（ゲームの 天気は 山なりの 気温と 梅雨・台風を 乱数で 作った もの）。
- 減水深（1日に 水が へる 量）、蒸発の 量：出典を 確かめていないので、ゲームでは「晴れで 1.2cm」のような ゲーム用の 値。
- 代かき・溝切り・除草・病害虫・乾燥機の 温度：1周目では 入れていない。
- 西尾市の 主力品種。

## 確かめ方

- `node tools/kome365/check.js`：Playwright・ヘッドレス Chromium。吹き出しの 矢印だけを 見て 遊ぶ「お客さん」（`customer`）が 収穫・検査まで 行けることも 見る（4周目）。本物の `PointerEvent`（`pointerType:'touch'`）で スワイプを送り、→ で日が進む（ゆっくりは 1日・はじくと 何日も・← で止まる）、↑↓ で水位が変わる（長さで量・ばね）、1年を スワイプだけで 通して 結果が出る（追肥・穂肥・中干し・刈る・乾燥 15%）、何もしないと 365日で おわり、390×844 と 360×560 で HUD・吹き出し・結果の字が 画面の中、1コマ 60ms 以内、を見る。ぜんぶ ✔ で 0 で 終わる（1周目：45 こ）。`KOME_FILE=<前の版>` で 前の版を 試せる。
- `node tools/kome365/shots.js [幅 高さ]`：おもな画面の スクショと ならべた 1枚（`sheet.png`）。出力は `KOME_OUT`（リポジトリの外）。
- ページは `window.K3` を出している（`K3.manual = true` で `K3.step(dt)` が 1コマ、`K3.fixedSeed` で 同じ天気、`K3.jump('heading')` などで 場面へ 一気に）。手でコマを進める時は スワイプの速さの時計も `K3.step` の時間になる。

## 記録

### 1周目（サイクル1：最小の遊べる版）

- 作った：種もみ → 苗 → 田うえ → 水管理・中干し・追肥・穂肥 → 出穂 → 登熟 → 稲刈り → 乾燥 → 検査 → 結果。上の 4方向の スワイプ。
- check.js の 1年通し（seed 3、ていねいな管理のボット）：160日目に 検査、スワイプ 213回、一等・471kg/10a・整粒 87%・食味 90。
- 直したこと：手でコマを進める テストでは スワイプが ぜんぶ「はじき」になっていた（本物の時計を 見ていた）→ 手動の時は `K3.step` の時間を 時計に。HUD の 水の数が スワイプの直後に 古いまま → スワイプの あとに 書きなおす。天気を HUD の右に 置くと 小さい画面で つぶれる → 日づけの下へ。暦と HUD が 低い画面で かさなる → 暦を 下げた。
- まだの こと（つぎの周の 候補）：天気の 予報を 出す（いまは その日の朝に わかる）、乾燥の 行きすぎを 止めやすく、1株を 掘り出す 絵、代かき・溝切り、西尾の 本物の 気象の 出典、本物の スマホでの 手ごたえ（速さの しきい値 0.35px/ms、1回の 最大 14日）。

### 2周目（スワイプの手ごたえ・乾燥・1株の札）

- **→ の日数を ゆるく**：1周目は 0.35px/ms から日数が ふえていて、ふつうの速さの スワイプでも 3〜5日に なっていた（中干しや 刈りどきの 1日きざみが しにくい）。0.6px/ms までは 1日、そこから 5日/(px/ms)、長さ 140px から +1日/100px。最大 14日は そのまま。
- **乾燥の 行きすぎ**：15.5% 以下に なったら めくりの 列を 止めて「ぴん」と 15% の札（乾燥機の 仕上がりの 合図）。もう一度 → すれば 乾かしすぎに なる（遊びとして 残す）。
- **← 見る で 1株を 掘り出す**：クラフト紙の 札に 1株（茎の数・草丈・根）と ものさし、草丈の 赤い線。字は 草丈だけ。2.4秒で 消える。
- **あすの 天気**を HUD に（掛け流し・落水の 段取りの ため）。本物の 予報では なく、ゲームの 天気の 先読み。
- check.js に `dry`（札が 出て 消える・15% で 止まる・もう一度で 乾かしすぎ・あすの 天気）を 足し、49 こ ✔。1年通しは 同じ（160日目・一等・471kg）。
- 別のエージェントに 辛口レビュー（スワイプの楽しさ・お客さん目線・リアルさ・かわいさ）を たのんだ。指摘は 3周目で 扱う。

### 4周目（お客さん目線の 通しと コードレビュー）

- **吹き出しだけで 遊ぶ お客さん**（矢印が あれば その向き、なければ →）を 台本に して 通した。1周目の 版では 田うえの あと「↑で 水を」の あとに 返事が なく、ずっと ↑ を くり返して 止まっていた → ↑↓ の あとは「みず 7.5cm。→で あした」「中干しです。ひびが 入るまで →で 日を」と 返す。田うえ・稲刈りの 途中は「←で つづけて」。直した 版では 159日目に 一等・469kg（206回）。`check.js` の `customer` に した。
- **コードレビュー（/code-review medium）の 10件**を 確かめて 直した：
  - 茎数の 目安が 段階ごとの モデルの まま（45日目に 目標の 35〜50%）で、ふつうの 年でも「茎が ふえすぎ」と 言っていた → 45日目の 目安を 50〜85%・草丈 60cm・茎幅 8.5mm に。結果の 声は 95% 超で「ふえすぎ」、45% 未満で「少なめ」。
  - 稲刈りの 1回目で 切り株が 出なかった（5回を 4列に 割る 式）→ 1,2,2,3,4 列。
  - 「もう一回」で 見た目の 状態（1株の 札・めくりの 間隔・指の 状態）が 前の 年から のこっていた → ぜんぶ もどす。
  - 田うえの 日に 株が かかれなかった → かく。
  - 中干し中の 雨で「乾いた 日」が 0 に もどり、「ひび」の 合図が ほぼ 出なかった → 乾いて いるのは 1cm 未満、中干し中の 雨は 3割だけ たまる（溝切り）。
  - 毎コマ `offsetHeight`・`getComputedStyle` を 読んでいた → 字の 名前は 1回、吹き出しの 高さは 言った 時と 画面が かわった 時だけ。
  - 浸種の 水の 動きが `setTimeout` で ずれていた → 同期に。使って いない 変数・分岐（`preview`・`log`・`body.menu`・常に 真の 条件 など）を けした。`K3.jump` の 知らない 名前は 止める。`shots.js` は ページの エラーで 1 で 終わる。
- check.js 56 こ ✔。1年通し（ていねいな ボット）は 160日目・一等・491kg（茎数の 目安が 合って 一穂の もみが ふえた）。
- Artifact の 更新は 1日の 上限（200回）に 当たったので、次の 周で（UTC 0時 すぎ）。
