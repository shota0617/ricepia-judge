# お米ころころ（どんぐりころころのような操作性）の検討

童謡「どんぐりころころ」の どんぐりのように、ひと粒のお米が ころころ転がる操作。気持ちよさの元と、操作の方法をくらべるための試作を作った。

- 試作：`nishio-go/korokoro.html`（ゲームからは まだリンクしていない。検索にも出さない）。台地の茶畑から坂を下り、田んぼのあぜ道をぬけて、ごはん茶わんへ。
  池（どじょうのいる池）に落ちると「どじょうが出てきて こんにちは」で、ひとつ前の旗から
- 3つの操作を、画面の下のボタンで切りかえて くらべられる

## 「ころころ」の気持ちよさの元

1. **勢い（慣性）**：押すのをやめても すぐには止まらず、少しずつ ゆっくりになる（ころがり抵抗）。止めたい所で止める むずかしさが遊びになる
2. **坂**：下り坂では ひとりでに速くなる。台地（碧海台地）から 低い田んぼへ下る、西尾の土地の形をそのまま坂にできる
3. **転がって見える**：お米は たて長のつぶなので、転がった道のりだけ回すと、たての長さが のびちぢみして「ころころ」に見える（試作で入れた）
4. **当たると はねる**：あぜや石垣に当たると少しはね返る
5. **歌のできごと**：池に落ちて どじょうに会う、が「失敗」でも笑える場面になる

## 操作の くらべ

| | 📱 かたむける | 👆 はじく | ✋ なぞる（指へ向かって転がる） |
|---|---|---|---|
| どんな操作 | スマホを傾けた向きへ転がる | はじいた向きと強さで1回ずつ転がす（ゴルフ） | 指のある所へ向かって転がる。はなすと勢いで転がりつづける |
| ころころ感 | いちばん強い（手の傾きが そのまま坂になる） | 1回ずつ「ころころ…ぴた」が気持ちいい | ほどよい（指で引っぱる感じ） |
| むずかしさ | 止めるのが むずかしい（ちょうどよい挑戦にもなる） | 考えて はじく。あわてない | やさしい。子どもや お年寄りにも |
| 歩きながら | **向かない**（スマホを傾けながら歩くのは危ない） | 立ち止まって遊ぶ向き | 立ち止まって遊ぶ向き |
| 片手で | できる | できる | できる |
| 気をつけること | iPhone は はじめに「動きと向き」の許可がいる（ボタンを押したときに聞く）。パソコンは使えない（矢印キーで代わり） | はじく強さの感じ方が人によってちがう | 指でお米がかくれる（指の少し先へ向かうと よいかも） |
| 遊びの形 | タイムアタック | 少ない回数でゴール（パー） | タイムアタック・やさしい道 |

## おすすめ

- **はじめは「なぞる」**：だれでも すぐ遊べて、歩きながらにならない。ミニゲームの入り口として いちばん失敗が少ない
- **「かたむける」は 選べる遊び方に**：ころころ感が いちばん強いので、なれた人の「本気モード」に。立ち止まっているとき（歩く速さが0のとき）だけ開けるようにする
- **「はじく」は 毎日のチャレンジに**：「きょうのコースを ○回で」が作りやすく、回数をシェアしやすい
- 3つとも同じコース・同じ物理（勢い・坂・はね返り）で動くので、作るのは1つで済む

## ゲームに入れるとしたら

- **入り口**：田んぼのそば（いまの「田んぼのイベント」と同じ所）や、当店にチェックインしたあと。ゴールのごはん茶わんを、当店（らいすぴあ）の茶わんにすると、米屋のPRにもなる
- **コース**：西尾の土地の形をそのまま坂に（碧海台地 → 段丘の坂 → 田んぼ → 矢作川の水路）。季節で田んぼの すがた（苗・青い稲・金色の稲穂）を変える
- **ごほうび**：1日1回のポイント（ほかのミニゲームと同じ）。★：ゴールした・池に落ちなかった・目標の時間（または回数）
- **音**：転がる「ころころ」の小さな音、池に落ちる「どぶん」、ゴールの音（効果音は tools/make-sound.py のオリジナル）

## まだ確かめていないこと

- 試作は、パソコンのブラウザで 矢印キーを自動で押して、ゴールまで行けることを確かめた（12秒・池に1回）。**スマホを実際に傾けたときの感じは、この環境では確かめられない**ので、スマホで さわってみて決めたい
- 傾きの強さ（いまは 30度で いちばん強く）・ころがり抵抗・はね返りの強さは、さわった感じで調整する

## ゲーム本体に入れた（第1段：2026年10月）

運営者の決定：**ゲーム全体を、主人公が歩くのではなく、スマホを傾けてお米が転がるゲームにする**。その第1段として、主人公の絵と動きを入れかえた。

- **お米の絵**：`tools/blender/rice.py`（Blender）→ `nishio-go/art/rice.png`。32×32 が 横8 × たて2（歩く地図には 2マスで描く。ドットの大きさは ほかの絵と同じ）。つぶは細かい球（64×32）で なめらかな丸みにし、まわりの線のでこぼこも ならす。止まっている絵の顔（丸い目2つ・はしが上がった 細くて広い にっこりの口）は、見本のとおりに点で描く。
  運営者が見せてくれた「顔のある お米」のイメージ（たて長で立っている・右上の かたに胚芽のところの くぼみ・丸い目・にっこりの口・白くて やわらかい影）に合わせて、形を作りなおした（絵そのものは写していない）。
  1行め：右へ でんぐり返る8コマ（左は反転）、2行め：手前へ転がる8コマ（上は逆の順）。止まっているときは1コマめ（立って、こっちを見て にっこり）
- **転がる絵**：転がった道のり（1マスで ひとまわり）で コマを進める。あるいて移動（GPS）・スティック・おまかせ歩き・傾け のどれで動いても転がる。足もとに影
- **かたむけて転がす**（操作して移動。はじめはオン。📱 ボタンで オン・オフ）：`pixel.js` の `rollStep`。
  スマホを傾けた向き（25度で いちばん強く。ふつうに持った35度くらいを まっすぐに）へ、勢いをつけて転がる。傾きのない端末は スティックの倒し具合・矢印キーが そのまま傾き。
  押すのをやめても すぐには止まらない（ころがり抵抗）。建物・水には入れず、当たると少し はね返る（ぶるっと ふるえる）。人にぶつかると話しかける。
  新しいマスに入るたびに、1歩と同じこと（呼びとめ・生きもの など）が起き、位置は少し動くたびに game.js へ送る（チェックインの範囲・たからばこ・歩いた距離は いままでどおり）
- iPhone は、📱 ボタンを押したときに「動きと向き」の許可を聞く（許可がないときは スティックで転がす）
- あるいて移動（GPS）は、実際に歩いた所へ お米が転がって ついていく（傾けて動かすのは 操作して移動だけ。歩きながら傾けるのは危ないので）
- ふつうの地図（地理院タイル）の主人公の印も お米に
- 確かめたこと：`tools/playtest.js` に「右の矢印キーを1秒おすと、1マスより先へ転がり、転がった分だけ絵が回る」チェックを足した（3.1マス転がった）。台本の歩く手順は1マスずつのまま（`nsg_roll` を 0 に）

### つぎ（候補）

1. **坂で転がる**：地図の高さ（標高のデータ）から坂の向きを出して、下り坂では ひとりでに転がる（台地 → 段丘の坂 → 田んぼ）
2. **はじく・なぞる** も選べるように（試作の3つの操作）
3. 転がる音（ころころ）・池や川に落ちたときの「どぶん」とやり直し（どじょうが「こんにちは」）
4. スマホで さわってみて、傾きの強さ・ころがり抵抗・はね返りを調整する

## 第2段（2026年10月）：おまかせ歩き・さんぽ犬をなくし、傾きを直す

運営者の指示：「自動操作削除、散歩犬削除。傾けて転がるようになってない」

- **おまかせ歩き（🧭）をなくした**：ボタン・自動で歩くしくみ・おまかせ強化の「はやあし」。るすばん（閉じている間のさんぽ）は残し、強化の名前を「るすばん強化」に。タップした所へ歩く道すじ（A*）は残した
- **さんぽ犬をなくした**
- **傾きで転がらなかった原因と直し**：
  1. iPhone は「動きと向き」の許可がないと傾きが届かない。いままでは 📱 をオフ→オンにしたときしか許可を聞いていなかった（はじめからオンなので、だれも押さない）→ 転がすのがオンなら、**画面をはじめてさわったときに許可を聞く**
  2. 「ふつうに持つと35度」と決めつけていたので、寝かせて持つと ずっと上へ押され、立てて持つと下へ押されていた → **はじめに読めた持ち方（8回の平均）を「まっすぐ」にする**（📱 を押しなおす・アプリにもどると やりなおす）。20度で いちばん強く、手のふるえ（少しの傾き）は無視
  3. 画面を横にしたときは、左右と前後を入れかえる
  4. あるいて移動（GPS）では傾けても動かない（歩いた所へ転がる）。傾けたら1回だけ「傾けて転がすのは 操作して遊ぶ で」と教える
- 確かめたこと：`tools/playtest.js` で、傾きの知らせ（DeviceOrientationEvent）を送って「40度の持ち方を まっすぐにして、左へ20度傾けると 左へ2.3マス転がる」ことを確かめた。`tools/ai-play.js` の `auto` を `tilt`（傾けて転がす）に入れかえた

## 第3段（2026年10月）：なめらかに転がる・かわいい米粒に

運営者の指示：「なめらかに転がるように改善」「可愛い米粒に修正」

- **なめらかに転がる**：8コマの でんぐり返し（45度ずつ）をやめて、止まっている お米の絵（にっこり）を、進んだ道のりだけ その場で回す（`pixel.js` の `riceSpin`。右・下へは時計まわり、左・上へは反時計まわり。1マスで約136度）。どの角度にも回るので かくかくしない。顔は いつも見える
- **起き上がりこぼし**：止まると、ばねのように ゆらゆらして、立って こっちを見る
- 傾きのセンサーの細かいゆれを ならす（前の値と まぜる）。位置を game.js へ送るのは 0.45マスごとか 0.25秒ごと（多すぎて重くならないように）
- **かわいい米粒**：つぶを少し ずんぐりに。右上の かたに、胚芽が欠けた所の凹み（まるく えぐって、内がわに うすい影）。顔は たて長の まっ黒な目2つ・うすいピンクのほっぺ・はしが上がった にっこりの口（点で描く）

## 第4段（2026年10月）：クセになる転がり方

運営者の指示：「クセになる転がり方」。玉ではなく お米だから気持ちいい、を ねらった（`pixel.js` の `riceFeel`）

- **コロン、コロン**：たて長のつぶは、寝ころぶと まん中が下がり、立つと上がる（だ円が転がるときの高さを そのまま計算）。玉のように するする ではなく、でこぼこの リズムで転がる
- **コトン**：寝ころぶたびに、木の小さな「コトン」（Web Audio で作る音。音の設定がオフなら鳴らさない）。速いほど はっきり
- **ぺたっ、ぷるん**：かべ（建物・水）に当たると、当たった向きに つぶれて、ばねで ぷるんと もどる。強く当たるほど つぶれ、画面が少しゆれて、低い「ゴトッ」と ぶるっ
- **土ぼこり**：速く転がると、うしろに ふわっと土ぼこり
- 止まると 起き上がりこぼしのように ゆらゆらして立つ（第3段）

## 第5段（2026年10月）：転がり方のバリエーション

運営者の指示：「転がり方にもバリエーションをつける」。速さ・向き・足もとの地面で、転がり方が かわる（`pixel.js` の `riceSpin`・`riceFeel`・`groundAt`）

- **よちよち**（ゆっくり：1秒に1.1マスより おそい）：転がらずに、立ったまま 左右に ゆれながら進む（起き上がりこぼしの まま）
- **ころころ**（横へ）：でんぐり返って転がる（第3・4段の転がり方）
- **くるくる**（たて＝上・下へ）：立ったまま こまのように回る。顔 → よこ（細く）→ うしろ姿（顔のない絵。胚芽の くぼみは反対がわ）→ 顔。ななめに進むときに ころころ と くるくる が入れかわりつづけないよう、切りかえに ゆとりをもたせた
- **ぴょん**（とても速い：1秒に4.2マスより速い）：コトンの2回に1回 とびはねる（影が小さくなる）。つくと ぺたっと つぶれて コトン、土ぼこりが ぱっ
- **足もとの地面**：
  | 地面 | 転がり | 音 | とぶもの |
  |---|---|---|---|
  | 道・町・線路 | するする（ころがり抵抗 0.72倍。いちばん速くなり、ぴょんも出る） | コトンが はっきり | 灰色の ほこり |
  | 草地・公園・畑・茶畑・田んぼ（稲） | もさもさ（1.35倍。ぴょんまでは速くならない） | 小さめ | 緑の葉っぱが はねる |
  | 田おこしの田んぼ | 1.6倍 | 小さめ | どろ |
  | 水を張った田んぼ | ぱしゃぱしゃ（1.7倍） | こもる | 水しぶき |
  | 砂浜 | ずぶずぶ（1.9倍。すぐ止まる） | こもる | 大きな砂けむり |
- 確かめたこと：Playwright で矢印キーを ちょんちょん（よちよち）・上へ長押し（くるくる・ぴょん）・左へ長押し（ころころ・ぴょん）して、`nishioPixel.roll.kind` がそれぞれになり、絵（細くなる・うしろ姿・とぶと影が小さい）を見て確かめた

## 第6段（2026年10月）：本当の高低差で転がる

運営者の指示：「マップにリアルな高低差をつけて転がり」

- **本当の標高**：国土地理院の標高タイル（`dem_png`・ズーム14＝約8mごと。地図を作るときにも使っているもの）を、いまいる所のまわりだけ ブラウザで読み、となりの点と なめらかに まぜて、どの位置の標高も出す（`pixel.js` の `heightAt`）。海は 0m
- **坂で ひとりでに転がる**（`slopeAt`・`rollStep`）：となりのマス（前後左右 8m）との標高の差から 傾き（勾配）を出し、下る向きへ 加速する。上りは おそくなり、下りは いつもより速くなる（いちばん速い速さが 最大 1.35倍）
  - 勾配 1.5% より ゆるい所は 止まっていられる（標高データの細かい でこぼこで 勝手に動かないように）。西尾の平野は ほとんど平らなので、ふだんは いままでどおり
  - 碧海台地のへり（段丘の崖）・八ツ面山・幡豆の山では、ゆるい坂は よちよち、急になると ころころ・ぴょんと 速くなって 下まで転がる
  - 本当の重さで計算すると 8mのマスでは ほとんど動かないので、ゲームでは 勾配1あたり 45マス/秒²（いちばん強くて 12）と 強めにしている
- **等高線**（`drawContours`）：半マスごとに標高の段を調べ、段が変わる さかいに 茶色の点の線を引く。30mまでは 2mごと・150mまでは 10mごと・それより上は 25mごと。10m・50mごとの線（計曲線）は 2点の太さで こく。水・建物の上には引かない。ゲームボーイの4色では引かない
- **標高と坂の札**：お米の右上に「⛰17m ←3%」（いまの標高・下る向きと勾配。2%より ゆるい坂は 向きを出さない）
- あるいて移動（GPS）では 坂で動かない（歩いた所へ転がる）。等高線と標高の札は出る
- 確かめたこと：
  - この環境からは 国土地理院に つながらないので、Playwright で 標高タイルを 作った絵（台地 18m → 段丘の崖 → 平野 3m）に差しかえた。台地の上では動かず、崖へ押すと よちよち → ころころ と速くなって下った
  - `tools/playtest.js` に「平らなら動かない・10%の坂を差しこむと さわらなくても下る」チェック（`nishioPixel.setHeightFn`）を足した
  - 本物の標高で どこが どれくらい急かは、スマホで 西尾の段丘のへり（西尾駅の北・八ツ面山）を転がして見てみたい

## 第7段（2026年10月）：米粒に丸みを出す

運営者の指示：「米粒がペラペラな感じになっているので、丸みを出して」

- ペラペラに見えた原因：
  1. 絵を そのまま回していたので、絵に描いた影も いっしょに回った（光が あちこちから当たる＝紙を回しているように見える）
  2. くるくる（たてに転がる）では、横を向くと 細い線のように つぶしていた
- **光を当てなおす**（`pixel.js` の `drawRiceBall`）：
  - お米を 点の大きさ（絵の1点＝画面の1点）のまま回す
  - つぶを たまごの形（よこ・たて・厚み）とみて、点ごとに 面の向きを出し、いつも左上から光を当てる
  - 回っても、てかりは左上・影は右下のまま
  - 影は5段（深い影・影・なか・つぶの色・明るい）と、てかり。段のさかいは 点をまぜて なめらかに
  - 胚芽の くぼみの内がわは 中へ向く面として影をつける
  - ふちどりは 回したあとに描きなおす（なめらかに回してから 半分より濃い所を つぶにするので、ふちが がたがたしない）
  - 顔は 画面の細かさで描く（点の大きさで回すと 目が くずれるため）
- **くるくる**：横を向いても つぶの厚み（88%）は残す。顔は つぶの まわりを すべって、うしろへ回ると見えなくなる（うしろ姿では くぼみが反対がわ）
- ゲームボーイの4色でも、同じ影を4色で描く（絵が毎回かわるので、4色にする処理は ここで行う）
- 確かめたこと：`tools/playtest.js` は ok（errors・failures なし）。止まっている・よちよち・くるくる・ころころ・ぴょん・ゲームボーイの4色を 画面で見た
