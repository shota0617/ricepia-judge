# 名所のドット絵の参考にした写真

`nishio-go/pixel.js` の名所の専用の絵（`LANDMARK_ART`）は、Wikimedia Commons にある自由に使える写真（CC0・パブリックドメイン・CC BY・CC BY-SA）の外観を見て、32×32 のドット絵として描きなおしたものです。写真そのものはゲームに入れていません。

Googleストリートビューの画像は、Google マップの利用規約で、画像をもとにした作品づくりが認められていないため使っていません（当店の2店舗だけは、お店の方から受け取った画面写真をもとにしています）。
