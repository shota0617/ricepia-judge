# 位置情報ゲームの面白さの本質と、にしおさんぽGO への活かし方（2026年10月）

世界中で大ヒットした「モンスターを集める位置情報ゲーム」（以下、先行のゲーム）が、なぜ毎日歩かせることができたのかを分解した。
そのうえで、にしおさんぽGO に何があって何が足りないかを比べ、足りないところを足した。
（よそのゲームの名前・キャラクター・絵は、ゲームの中では使わない。ここで学ぶのは「しくみ」だけ）

## 1. 面白さの本質（8つ）

| # | 本質 | 先行のゲームでの形 | 心理 |
|---|---|---|---|
| 1 | **ふだんの道が遊び場になる** | 家のまわり・通勤路に何かが出る | 見なれた街が「何かあるかも」に変わる。外へ出る理由 |
| 2 | **歩くこと自体が前へ進む** | 歩いた距離でかえるタマゴ（2km・5km・10km） | 目的がなくても歩く価値がある。歩くほど期待がふくらむ |
| 3 | **当たりの大きさが毎回ちがう** | めったに出ない色違い・強い個体 | 当たりが不定期だと、もう1回が止まらない（変動比率の報酬） |
| 4 | **集めて、そろえる** | 図鑑の「あと何種類」・地域限定 | 進み具合が目に見える。地域限定は「行く理由」 |
| 5 | **数秒で1回遊べる** | 出たら投げて、つかまえる（10秒） | すき間の時間に開ける。重くない |
| 6 | **土地の名所を知る** | 名所が道具の補給所になる | 知らなかった近所の石碑や祠に気づく |
| 7 | **みんなと同じ時に同じことをする** | 月1回の集まる日・期間限定のイベント | 「今週だけ」が戻ってくる理由。人がいるとうれしい |
| 8 | **毎日の小さな約束** | 連続ログインのボーナス・毎日の課題 | 続けるほど得、という小さな習慣 |

いちばん大きいのは 1・2・3 の組み合わせだと考える。
「歩く → 何かが起きるかもしれない → たまに大当たり」の輪が、歩くことそのものを楽しくしている。

## 2. にしおさんぽGO と比べて

| # | 本質 | にしおさんぽGO にあるもの | 足りなかったこと |
|---|---|---|---|
| 1 | ふだんの道が遊び場 | 実際の地図のドット絵の街・たからばこ・西尾の人 | —（ある） |
| 2 | 歩くこと自体が前へ | 歩いた距離のポイント（1日に上限あり）・クエスト「500m歩く」 | **ポイント以外に、歩いた先の「お楽しみ」がない。** 上限に届くと歩いても何もない |
| 3 | 当たりの大きさが毎回ちがう | ドット絵の★（めずらしさ） | **どの絵が出るかは場所・季節・天気で決まり、運の大当たりがない** |
| 4 | 集めてそろえる | 西尾ドット絵帳（題材37・天気5）・バッジ・地区のめぐり具合 | —（ある） |
| 5 | 数秒で1回 | チェックイン・たからばこ（近づくと開く） | —（ある） |
| 6 | 土地の名所を知る | 名所 2,251か所・まちメモ（出典つき） | —（ある。いちばんの強み） |
| 7 | 同じ時に同じこと | 今月の行事（本物のおまつり）・期間のキャンペーン | **毎週のリズムがない。** 行事は月に数回で、場所も限られる |
| 8 | 毎日の小さな約束 | 連続日数のボーナス・今日のクエスト3つ・あしたのおたのしみ | —（ある） |

## 3. 足したもの

### おみやげ袋（本質 2：歩くこと自体が前へ進む）
- たからばこを開けると4回に1回、注目スポットではじめてチェックインすると必ず、「おみやげ袋」がもらえる（その遊びかた（あるいて移動／操作して移動）ではじめて袋が出る たからばこ では必ず1kmの袋）。持てるのは3つまで
- 袋には **1km・2km・5km** の3種類があり（もらえる割合 50%・35%・15%）、**先頭の袋だけ**、歩いた距離で中身がたまる。決めた距離を歩くと開く
- 中身は、ポイント（30・80・200）とドット絵（1枚・2枚・3枚）。ドット絵は袋をもらった場所の絵で、**まだ持っていない題材を先に**、なければ まだ持っていない絵を選ぶ。遠くまで歩くほど、絵帳が大きく進む
- 歩いた距離のポイントの1日の上限に届いても、袋は歩いた分だけ進む（歩く理由がなくならない）
- 操作して移動では、歩く地図を歩いた分（スティック・タップした所へ歩く・おまかせ歩きの1歩）だけ進む。ふつうの地図のタップは瞬間移動なので進めない（タップだけで数秒で開けられないように）
- 地図の下の案内に「🎒 0.4/2km」のように出して、いつも見えるようにする。きろく に袋の一覧

### キラの絵（本質 3：当たりの大きさが毎回ちがう）
- ドット絵をもらうたびに **約3%（32回に1回）** で、その絵が「キラ」になる。金色にかがやく額縁と「キラ」のリボン
- キラは絵ごとに記録し、絵帳では金のふちで分かる。絵帳の数に「キラ n枚」
- もう持っている絵でもキラになることがある（同じ絵をもう一度もらう楽しみ）

### 今週のテーマ（本質 7：みんなと同じ時に同じことをする）
- 週ごと（月曜はじまり・日本時間）に、6つのテーマが順番に回る：⛩️ 神社・🛕 お寺・🌳 公園・🏯 史跡と城・🌊 海と展望・🖼 アートと資料館
- テーマに合う名所でチェックインすると、そのスポットのポイントが **2倍**、袋の空きがあれば **おみやげ袋が必ず** もらえる（テーマの名所の袋は1日3つまで。公園の週は公園が千か所あるため）
- だれが遊んでも同じ週は同じテーマ（日付だけで決まる）。こよみの札と きろく に「今週は ⛩️ 神社の週」と出す
- ねらい：毎週「今週は何の週？」で戻ってくる理由と、ふだん行かない種類の名所へ足が向くこと

### 第2弾（遊んだ人の目線のまとめから）
先行のゲームの「はじめの1分・歩く理由・集める楽しさ・毎日戻る理由」の見直しから、さらに5つを足した。
- **絵帳の影と手がかり**（集める楽しさ・歩く理由）：まだの題材は、ぼんやりした絵（何の絵かは分からない）と「一色の 海辺・まちなかで 見つかる」のような手がかりを出す。題材は地区と土地利用で決まる（`dots.js` の areas・lu）ので、それをそのまま「次に行く所」にした
- **はじめの1枚を えらぶ**（はじめの1分）：ようこそ たからばこ（歩く地図）では、その場所で出る絵から題材のちがう3枚を出し、1枚えらぶ。えらばずに閉じたら1枚目。「自分の1枚」から絵帳を始める
- **7日連続の特別な1枚**（毎日戻る理由）：連続7日・14日…のチェックインで、まだ持っていない題材の めずらしい天気（雪・満月・虹）の キラの絵。連続日数がポイントだけで終わらない
- **先週のまとめ**（毎日戻る理由）：月曜からの週ごとに、歩いた距離・チェックイン・新しい絵の数を記録し、きろく と週はじめの知らせに「先週のさんぽ」を出す
- **キラの時間**（この時間だけ）：毎週土曜の10時台（日本時間）は キラの率が2倍（1/16）。その時間に開くと知らせる

### 第3弾（PCで遊べるほかのドット絵ゲームを、実際に遊んで）
ブラウザで動くドット絵ゲームを3つ、ヘッドレスのブラウザで実際に操作して遊んだ（ゲームサイトは開けない環境なので、npm で配られているもの）。
よそのゲームの名前・絵・音は使わず、「しくみ」だけを持ちこんだ。

| 遊んだもの | 遊んで気づいた面白さ | にしおさんぽGO に足したもの |
|---|---|---|
| 1982年のアーケードの「穴を掘って進む」ゲームの再現（taizo-hori） | 掘った1マスごとに +10点。掘ったトンネルが画面にずっと残り、どこを通ったか一目で分かる。最高点がいつも上に出ている | **あしあと**・**はじめての道**・**自己ベスト** |
| 縦のパドルゲーム（retro-paddle） | 試合が終わると「ひとこと」と、その試合の見どころ3つ（いちばん速い球・取ったアイテム・いちばんのリード）が出る | **きょうのさんぽ**のカード |
| ドット絵のRPG・なぞときの道具立て（pixel-story-engine） | 話しかけると、人の頭の上に「♪」「！」の吹き出しがぽんと出る。人の話がつながって、次の人の答えが変わる | 話しかけた人の**気持ちの吹き出し** |

- **あしあと**（本質 1・2）：歩いたマス（8m）が、歩く地図に足あととして残る。せかいちずでは、歩いた所の100mのマスが もも色になる。記録はモードごと・版ごと（`pixel.js` の trailWalk。localStorage は記録のかぎ＋`_trail`、区画ごとのビット列）
- **はじめての道**（本質 2・3）：はじめて歩いたマスが50ふえるごと（約400m）に +5pt、1日50ptまで。同じ道ばかりより、知らない道を歩くほど得になる（いつもの道の「歩いた距離」のポイントは そのまま）。数えるのは歩いた分だけ（GPS で歩いた分、操作して移動では歩く地図の1歩。タップの瞬間移動は数えない）
- **自己ベスト**（本質 8）：いちばん歩いた日の距離を覚え、ほかの日の記録（300m以上）をこえたら その日1回だけ知らせる
- **きょうのさんぽ**：きろく のいちばん上に、歩いた・はじめての道・チェックインの3つと、ひとこと（「知らない道をたくさん歩きました」など）、自己ベスト・これまでに歩いた道
- **気持ちの吹き出し**：話しかけた人の頭の上に、はじめて会った人は「！」、2回目からは「♪」か「♥」が1.6秒

### 第4弾（ほかのゲームを、もう2つ実際に遊んで）
npm で配られている、ブラウザで動く農場のゲームと、文字の画面で動く倉庫番（箱を押してゴールへ運ぶパズル）を、それぞれ最後まで操作して遊んだ。
これまでと同じく、よそのゲームの名前・絵・音は使わず、「しくみ」だけを持ちこんだ。

| 遊んだもの | 遊んで気づいたこと | にしおさんぽGO に足したもの |
|---|---|---|
| 農場のゲーム（種を買う・植える・水をやる・日を進める・収穫して売る） | 日を進めると「雨で水やりがすんだ」「カラスが作物を食べた」のような 前の日のできごとが まとめて出る。実績の画面に、全体の何%まで来たかと、ひとつずつの進み具合が出る。いっぽうで、同じ知らせが何枚も積み上がって畑が見えなくなる（よくない点） | **前回のさんぽ**・**バッジの達成率と もうすぐ**・**同じ知らせを重ねない** |
| 倉庫番（Sokoban） | まちがえても「1手もどす」で取り消せるので、やりなおしが こわくない。面ごとに いちばん良い記録が残り、メニューの「つづき」から まだ解いていない面に入れる | **稲刈りの ↶ もどす**・**ミニゲームの面ごとの自己ベストと つづき** |

- **前回のさんぽ**：日がかわって はじめて開いたとき、前に遊んだ日の「歩いた距離・チェックイン・新しい絵」を1回だけ知らせる（きのうなら「きのうのさんぽ」、もっと前なら「前回（10月18日）のさんぽ」）。きろく の きょうのさんぽ の下にも出す。少しも歩いていない日は出さない。週はじめの知らせ・キラの時間の知らせが出る日は、そちらを先に
- **バッジの達成率と もうすぐ**：きろく の バッジの見出しに「12/40（30%）」。その下に、進み具合がいちばん進んでいる まだのバッジを2つ「もうすぐ」として出す（あといくつか も）。次に何をすればいいかが分かる
- **同じ知らせを重ねない**：いま出ている知らせ・待っている知らせと同じものは、もう一度ならべない（出ている間に同じものが来たら、出しておく時間をのばすだけ）
- **稲刈りの ↶ もどす**：コンバインを1マスずつ もどせる（Z・Backspace でも）。刈ったマスは稲にもどり、曲がった回数・むだ走りも その手の前にもどる（倉庫番と同じく、取り消した手は数えない）。目安（いちばん少ない曲がる回数）と組み合わせて、考えながら解くパズルにした
- **ミニゲームの面ごとの自己ベストと つづき**（稲刈り・段丘をのぼる）：成功した面ごとに いちばん良い記録（★、★が同じなら 稲刈りは曲がった回数の少ないほう・段丘は のこり時間の多いほう）を残し、結果の画面に「自己ベスト」「自己ベスト更新！」。開くと まだ成功していない いちばん前の面から始まり、結果の画面で 成功した面と その次の面を えらべる。1日1回のごほうびは これまでどおり（記録をのばす楽しみは、ポイントと切りはなした）

### 第5弾（落ちものパズルと 2048 を、実際に遊んで）
npm で配られている、ブラウザで動く昔ながらの落ちものパズル（そろった横の列が消える）と、2048（同じ数字を重ねて倍にしていく）を、自動で操作して遊んだ。
落ちものパズルはヘッドレスのブラウザでキーを送って、面を進めた。2048 は5回遊んで、大きな数字がはじめて出た手数を数えた。
これまでと同じく、よそのゲームの名前・絵・音は使わず、「しくみ」だけを持ちこんだ。

| 遊んだもの | 遊んで気づいたこと | にしおさんぽGO に足したもの |
|---|---|---|
| 落ちものパズル | 1列ずつ消すより、まとめて消すほうが ずっと得（1列40点・2列100点・3列300点・4列1200点。どれもレベル+1をかける）。だから「次もつなげよう」と考えて置く。10列ごとにレベルが上がり、点・列・レベルがいつも画面に出ている | **めぐりの れんさ** |
| 2048 | 次の大きな数字までの手数が、だいたい倍ずつふえる（5回の平均で 16 が16手、32 が32手、64 が52手、128 が104手）。いまの いちばん大きい数字と「次は その倍」がいつも見えていて、もう少しやろうと思える | **歩いた道の節目** |

- **めぐりの れんさ**（本質 3・6）：名所にチェックインしてから30分以内に、ちがう名所にチェックインすると「れんさ」がつながる。2つ目から そのチェックインの名所の点に ×1.2、3つ目 ×1.5、4つ目から ×2（ふえる分だけを足す）。同じ名所では つながらない。つながっている間は、上の行に「🔗 れんさ 3 のこり12分」。いちばん長い れんさは きろく の きょうのさんぽ に出す（`game.js` の chainStep）。寄り道して いくつも まわるほど得になる
- **歩いた道の節目**（本質 2・8）：これまでに歩いた道（はじめての道の合計）が 500m・1km・2km・4km…と倍ずつの節目をこえるたびに、+30pt・+60pt・+90pt…。きろく の きょうのさんぽ に「つぎの節目 4.0km まで あと 1.6km」と出して、次の目あてがいつも見える（`game.js` の trailMiles）。もう歩いている人は、いまの距離までの節目を すんだものとして始める

## 4. あえて足さなかったもの

- **人と人のやりとり**（いっしょに戦う・交換）：サーバーと見守りの体制が要り、子どもも遊ぶので安全の確保が難しい。
  今週のテーマで「みんな同じ週に同じ種類の名所へ」という、ゆるい一体感にとどめた
- **課金のしくみ**（袋を同時に温める道具など）：お店の宣伝のゲームなので入れない。袋は先頭だけ進む、で待つ楽しみにした
- **戦い・強さ**：西尾を知る・さんぽする、という このゲームの核（`docs/fun-core.md`）から外れる

## 5. 見る数字（GA4）

- `bag_get`（もらった袋の距離・もらい方）・`bag_open`（開けた袋の距離）：袋が開くまで歩いてくれているか
- `dot_get` の `kira`：キラの出かた
- `checkin` の `theme`：テーマの週に、テーマの名所へのチェックインが増えているか
- 7日後に戻ってくる人の割合（`play_day` の `day_n`）が、足す前とくらべて上がるか
- `walk_best`（自己ベストの日）と、きろくの「はじめての道」：知らない道へ足を向けてくれているか
- `harvest_clear`・`dankyu_clear` の level：つづきから・面えらびで、2つ目・3つ目の面まで遊んでくれているか
- `checkin` の `chain`・`trail_mile`：30分以内に次の名所へ足を向けてくれているか・知らない道を歩きつづけてくれているか
