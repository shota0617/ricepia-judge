# らいすぴあ マーケティングの組み直し（2026年11月〜2027年3月）

- 作成：2026-10-25
- 型：Anthropic の Marketing プラグイン（1.2.0）の8つのスキル
  （campaign-plan・performance-report・draft-content／content-creation・brand-review・seo-audit・competitive-brief を使う。email-sequence は使わない）
- もとにした資料：`docs/google-ads-review-2026-10.md`・`docs/marketing.md`・`docs/ads-game-kit.md`・`docs/marketing-weekly/2026-10-24.md`・`ricepia-jp/current.html`（10/12 価格確認の版）・`.claude/skills/kokoku-shindan`

> **2026-10-25 追記**：常連さまポイントの Supabase に、広告・LINE・インスタ・Googleビジネスプロフィール・ポイントの数字が**毎日たまっている**ことが分かった（14章）。下の「数字がない」は、この表で埋められる。
>
> **この計画の数字について**：広告の最新データは Google広告の 9/22 時点まで。Meta・LINEヤフー広告の費用、店の売上・粗利率はリポジトリにないので、**数字を作らず「入れる欄」にしてあります**（9章）。LINE の友だちは **15,852人**（2026-10-25、LINE のプロフィール画面）。
> Marketing プラグインのコネクタは、クラウド環境のネットワーク設定でまだ止められています（13章）。つながるまでは、データの取りこみはいまの手順（CSV・管理画面の数字）のままです。

## 0. 結論（3行）

1. **ゴールを1本にする**：「LINE の友だち（実際の追加数）をふやし、その人に来店をくり返してもらう」。広告・SNS・HP・ゲーム・店頭は、すべてこの1本の線のどこかを受けもつ（1章）。
2. **やり方を「毎週・毎月の型」にする**：プラグインのスキルを、店のいまの道具（Marketing Studio・広告診断・週報・売り出し準備）に割りあてて、だれがやっても同じ品質で回るようにする（4章）。
3. **期限のある仕事を先に片づける**：12/31 までに「新米」の表示を止める、1/1 に「創業135年」へ直す、11月中旬に Google広告の LINE重視の評価をする（6章）。LINE のカバー画像（「新米 販売中」と価格）も 12/31 までに差しかえる。

## 1. いまの状態（診断）

### できていること
- 店の強みがはっきりしている：創業1892年・ドライブスルー40年（1986年〜）・2店舗（本店 米津町／らいすぴあ秀幸 永吉・年中無休）・24時間のコイン精米所・農産物検査員が選ぶお米・ポルトガル語の LINE 相談・業務用の配達
- ricepia.jp に価格一覧・FAQ・店舗情報がそろっていて、検索にも AI 検索にも拾われやすい形になっている
- 広告の目標を「LINE重視」に決めた（10/15）。Google広告の直し方とスクリプトもできている
- LINE の友だちが 15,852人（2026-10-25）いて、認証済みのアカウント。これがいちばん大きな財産
- LINE の常連さまポイント（1日1回の来店で+1pt、10ptで100円引き）という「また来る」しくみがある
- 発信の材料を作る道具がそろっている（Marketing Studio・週報・広告の画像と動画の自動作成）

### 組み直しが必要なところ

| # | 問題 | なぜ困るか |
|---|---|---|
| 1 | **成果の数え方がそろっていない**。Google広告の成果は「LINE ボタンのクリック」で、本当に友だちになったかは LINE の管理画面にしかない。ゲームの GA4 の数字はまだ届いていない（シークレット未設定）。Meta ピクセルは未設置 | どの広告・発信が効いたか比べられない。予算を動かす根拠がない |
| 2 | **チャネルごとに別々に動いている**。Google・Meta・LINEヤフー広告、インスタ、X、LINE配信、ricepia.jp、にしおさんぽGO、店頭が、それぞれの計画で動いている | 季節の切りかえ（新米→年末→新年）で、古い文や画像が残りやすい（例：P-MAX の夏向けの文） |
| 3 | **時間の多くがゲーム作りに向いている**が、ゲームから LINE・来店に何人つながったかはまだ数えられていない | 力のかけ方が正しいか判断できない |
| 4 | **ブランドの言い方がばらばら**（「らいすぴあ・秀幸」「翔米」「近藤米穀店 らいすぴあ」がビジネス名に混在。LINE の表示名は「らいすぴあぶろぐ」） | 広告の信頼・AI 検索での店の結びつきが弱くなる |

## 2. ゴールと「線」（ファネル）

プラグインの型（認知 → 比較 → 購入 → 継続 → 推奨）を、米屋の動きに置きかえます。

| 段 | お客さまの動き | 受けもつチャネル | 見る数字（KPI） |
|---|---|---|---|
| 知る | 「西尾に車で買える米屋がある」と知る | P-MAX・Meta・LINEヤフー広告、インスタ、X、にしおさんぽGO、店の看板 | 表示・リーチ・ゲームの `game_start` |
| 調べる | 値段・場所・営業時間を見る | ricepia.jp（価格一覧・店舗情報）、Googleマップ、検索広告「新米２」、AI 検索 | 価格一覧の閲覧、ルート検索、電話 |
| **友だちになる** | **LINE を追加する（ここが主なゴール）** | ricepia.jp の LINE ボタン、広告、店頭の POP・ドライブスルーの声かけ、ゲームの `line_add` | **実際の友だち追加数**（LINE 管理画面） |
| 来る・買う | 店頭・ドライブスルーで買う | LINE 配信、売り出し | 客数、常連さまポイントの利用 |
| また来る | 次のお米が切れる頃にまた来る | LINE 配信、常連さまポイント | 友だちのブロック率、ポイントの2回目以降 |
| すすめる | 口コミを書く・人に話す | Googleの口コミ、インスタでの写真 | 口コミ件数・★、タグ付け投稿 |

**主な KPI（1つだけ）**：LINE の実際の友だち追加数（週ごと）。
**そばで見る KPI**：LINE 1人あたりの広告費、客数（2店舗）、ブロック率、ルート検索の件数、口コミ件数。

## 5. ブランドの決まり（brand-review で使う）

### 名前
- **店の名前は「近藤米穀店 らいすぴあ」にそろえる**（広告のビジネス名・プロフィール・投稿の最後）
- LINE の表示名「らいすぴあぶろぐ」は、店の名前がすぐ分かる名前にするか検討する（認証済みアカウントの名前を変えると審査があるので、変える前に LINE の管理画面で確かめる）
- 2店舗を分けて言うときだけ「本店（米津町）」「らいすぴあ秀幸（永吉）」
- 「翔米」は店のブランド名（品種名ではない）。品種と混ぜて書かない

### 話し方
- 町のお米屋さんが、店先で話すような ていねいで やわらかい言い方。「〜です・〜ます」
- 自慢より、お客さまの手間がへること（車を降りなくていい・積んでもらえる・値段がすぐ分かる）を先に言う
- 絵文字は1投稿に2〜3こまで。「！」を続けない

### 言える強み（根拠あり）と、確かめること

| 強み | 根拠・確かめること |
|---|---|
| 創業1892年 | 2026年中は「創業134年」、**2027-01-01 から「135年」** |
| お米のドライブスルー 40年（1986年〜） | ricepia.jp の沿革 |
| 2店舗ともドライブスルー、らいすぴあ秀幸は年中無休 | 営業時間・定休日を変えたら すぐ直す |
| 24時間のコイン精米所（10kgごとに100円・硬貨のみ） | 料金が変わったら直す |
| ポルトガル語の LINE 相談 | 受けられる人・時間を確かめる |
| 業務用は配達あり／個人への配達・発送はしない | 個人向けの配達をうたわない |
| 精米したて・一年360日毎日精米 | 休業日がふえたら直す |

### 使わない言葉・気をつけること
- 根拠のない一番・比べる言葉：最安、日本一、No.1、一番おいしい、どこよりも安い
- 「安い」は比べる相手と根拠がないと使わない（「まとめ買いもOK」などに言いかえる）
- **「新米」は 12/31 まで**（その年に取れて、その年のうちに精米・袋づめしたものだけ）
- 産地・品種・年産は袋の表示どおり。「1等米」は検査を受けたものだけ
- 健康の効き目を言い切らない
- 値段を書くときは「税込」と、確かめた日。ricepia.jp・店頭・広告で同じ値段にする
- **口コミのお願いに、ポイントや値引きを付けない**（Google の口コミのルールで禁止。お願いするだけにする）

## 6. 2026年11月〜2027年3月のキャンペーン計画（campaign-plan）

### 6-1. 概要
- **名前**：「車のまま、精米したて。」（冬〜春の通しのテーマ）
- **ひとこと**：重いお米を車のまま買える西尾の米屋を、LINE でいつでも思い出せる店にする
- **主な目標**：LINE の実際の友だち追加数を、**11月第1週の数（基準）から3月末までに増やす**。目標の数は、基準の週の数が分かってから決める（9章）。10/25 の友だち数は 15,852人
- **ほかの目標**：LINE 1人あたりの広告費を下げる／ブロック率を上げない／Googleの口コミをふやす

### 6-2. 伝えること
- **いちばん言うこと**：「車に乗ったまま、精米したてのお米が買える。値段は LINE ですぐ見られる。」
- 支える言葉
  1. 重いお米は車まで積みこみ（雨・寒い日・子ども連れでも）
  2. 値段がいつでも見える（価格表・LINE）
  3. 選び方を相談できる（お好みでご案内、ポルトガル語の相談も）
  4. 2店舗・らいすぴあ秀幸は年中無休、コイン精米所は24時間

### 6-3. 月ごとの流れ

| 月 | テーマ | 広告の中心 | 期限・注意 |
|---|---|---|---|
| 11月 | 新米のおいしい季節（おにぎり・炊き方） | 新米２・P-MAX の新米グループ | 11月中旬：Google広告の LINE重視の評価（10/15 の変更から3〜4週） |

| 1月 | 新しい年・創業135年 | P-MAX（創業・精米したて） | **1/1 に「創業134年」→「135年」**。ricepia.jp・広告・プロフィールをいっせいに |

## 9. 予算のルールと、数字を入れる表

### 予算のルール（金額は店が決める）
- **いまの基準**：Google広告は 1日 約¥2,500（30日で約¥75,600。8/23〜9/21）。Meta・LINEヤフー広告の金額は入れてください
- いちばん成果が出ているチャネルに広告費の6〜7割、新しいこと（ゲームの広告・ポルトガル語の広告など）のテストに1〜2割、残りを予備にする
- 予算を変えるのは月1回、1回に2割まで（自動入札の学習を壊さない）
- 増やしてよい目安：**LINE 1人あたりの広告費 ＜ 友だち1人がもたらす粗利**。友だち1人の粗利 ＝ 平均購入額 × 粗利率 × 1年の来店回数（友だちになった人のうち）。この3つが分かるまでは増やさない
- 止めた予算の行き先を必ず決める（成果の良いチャネルへ、または新しい材料のテストへ）

2. claude.ai の「カスタマイズ → コネクタ」で、使うサービスにログインして許可する
