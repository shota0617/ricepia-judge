# にしおさんぽGO を広告・マーケティングに使う

> いま出している広告（Google・Meta・LINEヤフー広告）と LINE リッチメニューに出す手順と材料は `docs/ads-game-kit.md`。

にしおさんぽGO は、遊ぶことがそのまま当店（近藤米穀店・らいすぴあ）への来店や ricepia.jp への訪問につながるように作ってあります。
ここでは、広告やお店の企画にゲームを使うための しくみ をまとめます。

## 0. ゲームの中の当店（見つける → 行く → 買う → また来る）

お店のいちばんの目標（LINE の友だちをふやす）に合わせて、ゲームの中の当店を次のようにしています（2026年10月）。

- **見つける**：ドット絵の地図で、当店の建物は ほかの名所より大きく（4マス）描く。せってい でゲームボーイの4色にしても、当店の建物と看板だけは本物の色のまま
- **行く**：当店の窓に 営業時間と「いま営業中／いまは閉まっています（あす9:00から）」、電話（spots.json の hours・tel。ricepia.jp の店舗情報から）
- **買う・また来る**：当店でチェックインすると、ごほうびのあとに当店の窓が開き、お店の **LINE の常連さまポイント**（1日1回の来店で+1pt、10ptで100円引き）と「LINEで友だち追加」のボタンを出す。殿堂入りの画面にも、お米屋さんの ひとこと と同じボタン
- **また来る（ゲームの中）**：来店スタンプ（当店に来た日を1日1こ。3・5・10こで +100・+200・+500pt。お金のかかる値引きではなく、ゲームのポイント）
- **数える**：LINE のボタンは `line_add`（ricepia.jp と同じ Google 広告の成果「LINE友だち追加クリック」にも数える）。来店スタンプは `shop_stamp`、クーポンは `coupon_get`・`coupon_use`

## 0b. 西尾の四季ドット絵（西尾市のPRに）

西尾市（西尾・一色・吉良・幡豆・佐久島）の注目スポット82か所と、名物と景色8つ（覆いをかけたてん茶の茶畑・うなぎの養殖池と水車・三河湾のあさり・西尾の田んぼ・一色の海苔ひび・カーネーションの温室・三河一色の大提灯・饗庭塩の塩田。`tools/blender/giant-scenes.py`、説明は docs/dots-nishio.md の出典つきの表から）を、**見る向き4 × 季節4 × 時間帯4 ＝ 64枚ずつ、全5760枚**の特大ドット絵（96×96）にした（2026年10月）。

- 公開ページ：`nishio-go/pr.html`（地区・季節・時間帯でえらぶ。大きく見て、空の色つきの 1080×1080 の画像を保存できる。リンクで その1枚を開ける）。ゲームの「せってい」からも開ける
- 季節：春（若葉・桜の花びら）・夏（濃い緑）・秋（紅葉・落ち葉）・冬（雪・葉の落ちた木）。時間帯：朝・昼・夕方（窓に明かり）・夜（月あかり・窓と灯籠に明かり）
- 歩く地図でも、その82か所の特大の絵は、いまの季節と時間帯の絵になる（いつもの左前の向き）
- 作り方：形は歩く地図の特大の絵と同じ型（`tools/blender/giant.py`・`giant-gen.py`）を、`tools/blender/giant-pr.py`（Blender。向きを変えて描く）→ `tools/giant-pr-color.py`（季節と時間帯の色をのせる）。82か所 × 4向きの描きに約13分、色のせに約1分。一覧は `nishio-go/art/pr/list.json`
- 名所の説明はゲームの名所の窓と同じ文（spots.json）。絵は形の型から作ったもので、本物の建物の細かい所までは同じではない

## 1. 広告のリンク（どの広告から来たかを数える）

ゲームのURL `https://go.ricepia.jp/` に、次のパラメータを付けて広告やQRコードに使います。

| パラメータ | 例 | 何がおきるか |
|---|---|---|
| `utm_source`・`utm_medium`・`utm_campaign`・`utm_content` | `utm_source=meta&utm_medium=paid&utm_campaign=shinmai` | Google アナリティクス（GA4）でどの広告から来たかが分かる。ゲームの `landing` イベントにも入る |
| `play=1` | `?play=1` | はじめての人も「操作して遊ぶ」ですぐ始まる（はじめの画面をとばす）。家で見る広告向け |
| `spot=スポットのid` | `?spot=kondo-beikoku` | そのスポット（spots.json の id）を見せる。「操作して遊ぶ」ならそこへ移動、「あるいて遊ぶ」なら地図をそこへ |
| `c=キャンペーンのid` | `?c=shinmai-sample` | そのキャンペーンから来た人として数え（`campaign_landing`）、キャンペーンをお知らせする |
| `from=どこから` | `?from=pop-honten` | チラシ・店頭POP・車のステッカーなど、紙やモノから来た人を数える |

例：
- Meta 広告（家で遊んでもらう）：`https://go.ricepia.jp/?utm_source=meta&utm_medium=paid&utm_campaign=game&play=1`
- 本店のレジ横のQR：`https://go.ricepia.jp/?from=pop-honten&spot=kondo-beikoku&utm_source=qr&utm_medium=offline&utm_campaign=honten`
  - 印刷して置けるA4のPOP：`https://go.ricepia.jp/nishio-go/pop.html`（このQRと、ゲームの画面・「スマホのカメラで読みこむだけ／無料・登録なし／家からでも遊べます」。右下の「印刷する」で印刷。検索にはのせない）。QRを作り直すときは `python3 tools/make-pop.py`（segno が要る）

## 2. 数えられること（計測）

計測タグは `nishio-go/analytics.js`（ricepia.jp と同じ GA4・Google 広告・LINEヤフー広告。Meta ピクセルはデータセットIDが決まったら入れる）。
公開しているドメインでだけ動き、「せってい」でオフにできます。現在地の座標は送りません。

| イベント | いつ |
|---|---|
| `landing` | 広告・QR・シェアのリンクから来た（utm_*・c・spot・from・play） |
| `game_start` | 遊びかたをえらんで始めた（端末ごとに1回。累計プレイ人数はこの数） |
| `play_day` | その日はじめて遊んだ（端末ごとに1日1回） |
| `checkin`・`shop_checkin` | 名所・当店にチェックインした（当店は Meta では「Lead」） |
| `idle_return`・`idle_fact`・`idle_upgrade`・`guide_pick` | るすばんから戻った・おまかせ歩きで まちメモ・おまかせ強化・行き先を自分で変えた |
| `guide_set`・`guide_arrive`・`npc_talk` | みちしるべ・人との会話 |
| `share_open`・`share` | シェアの画面を開いた・シェアした（kind：log（きろく）／dot（見つけたドット絵）／lvup（レベルアップ）、via：x／line／facebook／copy／image／native） |
| `share_prompt` | ごほうびの画面の「📣 シェア」を押した（kind：dot／lvup） |
| `friend_bonus` | 友だちのシェアから来た人が、はじめて遊んで +20pt をもらった（シェアから増えた人の数） |
| `campaign_landing`・`campaign_bonus`・`campaign_link` | キャンペーンのリンクから来た・当店チェックインのボーナス・くわしいページへ |
| `sponsor_link` | 協賛スポットのサイトへ進んだ |
| `line_add` | 当店の LINE の友だち追加（常連さまポイント）を押した（from：game-card 当店の窓／game-ending 殿堂入り）。Google 広告の「LINE友だち追加クリック」の成果にも数え、Meta では「Lead」 |
| `shop_stamp` | 当店に来た日の来店スタンプ（n：何こめ。3・5・10こで +100・+200・+500pt） |
| `coupon_get`・`coupon_use` | とくてん（クーポン）と交換した・お店で使用済みにした |
| `code_make`・`code_load` | ひきつぎの あいことばを出した・あいことばで続けた（機種変更などで遊び続けた人の数） |
| `shop_link` | 当店のサイト・道案内へ進んだ（Meta では「Lead」） |

当店のサイト・道案内・キャンペーン・協賛のリンクには、`utm_source=nishio-go&utm_medium=game` が自動で付きます。

## 3. シェア（口コミ）

「きろく」の 📣 シェア から、X・LINE・Facebook・コピー・端末のシェアができます。
シェア用の画像（1200×630）は、その人のレベル・めぐった名所・話した人と、こよみ（季節）、当店の名前・go.ricepia.jp をのせて、その場で描きます（どこにも送りません）。
シェアのリンクには `utm_source=share` が付くので、シェアから来た人を数えられます。

- **うれしい場面でシェアをすすめる**：はじめて見つけたドット絵と、レベルアップのごほうびの画面に「📣 シェア」のボタン（`game.js` の showReward）。ドット絵のときは、シェアの画像の右にその絵を金の額縁で大きく描き、文は「西尾ドット絵帳で「〇〇」の絵を見つけたよ」。
- **友だちの紹介ボーナス**：シェアのリンク（`utm_source=share`）から来た、まだ遊んだことのない人は、はじめて遊ぶときに +20pt（端末ごとに1回。`share.js` が `nsg_friend` を立て、`game.js` の friendBonus がわたす）。シェアの文にも「このリンクから始めると +20pt もらえるよ」と書く。シェアした人へのごほうびは、サーバーがないので数えられず、まだありません。

## 3b. 検索・AI検索に見つけてもらう

- ゲームのページ（`nishio-go.html`）に schema.org の説明（JSON-LD：VideoGame・無料・西尾市・運営は近藤米穀店 らいすぴあ）。
- go.ricepia.jp のサイトマップ `sitemap-go.xml`（`robots.txt` から案内。robots.txt は ricepia-judge.vercel.app と同じファイル）。
- `llms.txt` にゲームの説明（URL・遊び方・無料・運営）。

## 4. キャンペーン（お店の企画と連動）

`nishio-go/campaigns.json` に書きます。

```json
{ "id": "shinmai2026", "active": true, "from": "2026-10-01", "to": "2026-11-30", "icon": "🌾",
  "title": "新米キャンペーン", "text": "期間中、当店で…", "bonus": { "shopCheckin": 50 }, "url": "https://ricepia.jp/..." }
```

- `active: true` のものだけ本番で出ます（`false` はサンプルとして「操作して遊ぶ」でだけ出ます。いまは新米キャンペーンのサンプルが入っています）
- 期間中は「きろく」のいちばん上に出て、`bonus.shopCheckin` があれば当店でのチェックインに1日1回そのポイントが足されます
- 店頭の特典（値引きなど）は、ゲームのポイント交換（`nishio-go/rewards.json`）と組み合わせられます。特典の中身と期間は、お店で決めてから `active` にしてください

## 5. 協賛スポット（地元のお店といっしょに）

`nishio-go/spots.json` の注目スポットに `sponsor` を書くと、説明に「🤝 協賛」の札と、そのお店のサイトへのボタンが出ます（`sponsor_link` で数えます）。

```json
"sponsor": { "name": "〇〇菓子店", "text": "抹茶だんごが名物", "url": "https://example.jp/" }
```

## 6. 広告用の動画と画像（ほんとうのゲーム画面から）

`tools/make-promo.js`（Actions の「Make Nishio promo」）が、ヘッドレスのブラウザで「操作して遊ぶ」を台本どおりに進め、字幕をのせて作ります。

- 縦長の動画（9:16・1080×1920・約30秒・mp4・音はゲームの BGM。`tools/record-page.js` で画面を2倍の解像度で撮ってつなぐ）：はじめの画面 → まちを歩く → 人の話で行き先が決まる → 季節と天気 → おまかせ歩きで まちメモ → ほかの行き先も選べる → せかいちず → エンドカード（go.ricepia.jp・当店の名前）。Reels・ショート・ストーリーズ、店頭のモニターに
- デモプレイ動画（インスタのリール用。9:16・1080×1920・約42秒・mp4・音はゲームのオリジナル BGM）：`tools/make-reel.js`。はじめの画面 → スティックで西尾城跡のあたりを歩く → まちの人の話で「イベント」発生 → おまかせ歩きで放っておいても進む（まちメモ） → 名所でチェックイン → お店も本物そっくり → せかいちず → エンドカード。字幕はリールのボタンや説明文に隠れない上のほうに出す。ワークフローの Artifacts に `nishio-go-reel.mp4` として入る

### インスタのリールに投稿するとき（お店のアカウントで）

1. Instagram アプリの「＋」→「リール」で `nishio-go-reel.mp4` を選ぶ（音はそのまま。アプリの音楽をのせるなら、元の音を小さくする）
2. カバーは、はじめの画面（ロゴと「西尾のまちを歩く ドット絵のお散歩ゲーム」）のところを選ぶ
3. キャプション（そのまま貼れます。リンクは押せないので、プロフィールのリンクを go.ricepia.jp に）：

```
西尾のまちを、ドット絵で歩こう🚶
「にしおさんぽGO」は、西尾市と まわりのまちを歩くお散歩ゲーム。

・本物の道・川・田んぼから作った ドット絵の地図
・まちの人の話で「イベント」発生
・🧭おまかせ歩きで、放っておいても主人公が歩いて「まちメモ」が集まる
・西尾城跡、岩瀬文庫、佐久島… 名所でチェックイン

無料・登録なし。スマホでそのまま遊べます👉 プロフィールのリンク（go.ricepia.jp）から

#にしおさんぽGO #西尾市 #西尾 #愛知県 #三河 #ドット絵 #レトロゲーム #お散歩 #散歩 #位置情報ゲーム #西尾観光 #らいすぴあ #近藤米穀店
```
4. 広告のリンクで数えたいときは、プロフィールのリンクを `https://go.ricepia.jp/?utm_source=instagram&utm_medium=social&utm_campaign=reel&play=1` にする（1. のとおり）
- 場面ごとの静止画（9:16）と、リンク広告用の横長画像（1200×630）

動画は Actions の実行ページの「Artifacts」（nishio-go-promo）から取り出します。画像は `mkt/nishio-go/` にもコミットされます。
字幕は `docs/fun-core.md` と ricepia.jp に書いてあることだけです。字幕を変えるときは `tools/make-promo.js` の `caption(...)` を書きかえて、Actions を手動で実行します。
