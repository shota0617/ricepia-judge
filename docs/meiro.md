# 西尾めいろ（傾けて お米を ゴールへ）

運営者の指示（2026-10-22）：「西尾マップの迷路を傾けて米粒をゴールに導くゲームに変更」（キーホルダーの 玉ころがし迷路の写真つき）

- はじめの画面の いちばん上のボタン「🌀 傾けて めいろ」で始まる（地図の 🌀 ボタン・きろく の「🌀 西尾めいろ」の札でも開く。札には 何面まで・★の合計）。いままでの「傾けて さんぽ」「あるいて遊ぶ」も のこす
- 盤は 本物の西尾の地図の一部（ドット絵の地図と同じ絵。`pixel.js` の `paintRegion`）。めいろの1マスは 地図の 3×3マス（約24m）
  - 床：道（大きな道・道・小道）が 2つ以上ある マス。公園・境内（7つ以上）も 広場として 床。道の ない マス（家の かたまり・田畑など）は 壁の かたまり
  - となりの床へ 通れるのは、さかいを またいで 道が つながっている ときだけ。つながっていなければ 細い壁（キーホルダーの 迷路の 線のように）。
    はじめは「まん中を 道が通る マスだけ 通路」にしたが、マスの はしを通る道や ななめの道が とぎれて、多くの名所で めいろが つくれなかった（道のりも 10マスほど）
  - 運営者の声「迷路になってない」（2026-10-23）：道が 広い所（駅前など）は 壁が なく 広場に なっていた。いまは、道が つながる さかいの 中から 穴ほりで 1本道の 木を えらび、のこりは 細い壁で ふさぐ（通れるのは 本当の 道が つながる 所だけ のまま）。はじめの 面ほど ぬけ道を 多く（1面 3割 → 7面から 6%）。盤ごとに きまるので だれでも 同じ めいろ。スタートは ゴールから 道のり 28＋面×5（いちばん長くて 78）までで いちばん遠い所
  - 通路（ゴールへ つながる 床）は 明るく、つながらない 床と 壁の かたまりは 暗く、壁の 線は 太く して、迷路が うかんで 見えるように。作り方を かえたので、前の ベスト・はずした名所・ゴーストは 消した（`ver: 2`）
  - 壁は 立った プラスチックの 壁に 見せる（右下に 影・紺の 壁・上と左の ふちに 光。さかいごとに 1回だけ 描く）。
  - 通れない さかいに 黒い太い線。わくは 水色の プラスチック、盤には ガラスの てかり
  - 落とし穴：川や池（水が5マス以上）と、2面から ふえる マンホールの穴（ゴールまで ほかの道で 行けるときだけ 置く）。おちると スタートに もどる
- ゴールは 西尾の名所（西尾駅 → 西尾城跡 → らいすぴあ → 岩瀬文庫 → 近藤米穀店 → …）。スタートは ゴールから 道を たどって いちばん遠い所
- 金の米つぶ（1面に3つまで）：ゴールへの 近道から はずれた 行き止まりに うかんでいる。寄り道して とると 上に 🌾 の数、結果にも
- 本当の高低差：盤に 等高線（国土地理院の標高。とどいたら 描きなおす）。5%より 急な坂（台地の ふちなど）では、ひとりでに 下り坂へ 転がる
- 🐢 ゆっくり（上の ボタン。この端末に のこる）：押す強さ 0.55倍・いちばん速い速さ 0.6倍、★の 目やすの時間は 1.6倍。傾きに なれていない人・小さな子に
- はじめに 3・2・1（「スマホを まっすぐ 持ってね」）。「1」の あいだに いまの持ち方を「まっすぐ」に しなおす（開いた しゅんかんの 持ち方が 傾いていても だいじょうぶ）
- 転がし方：スマホの傾き（`pixel.js` の傾きと同じ。開いたときの持ち方を「まっすぐ」に）・矢印キー・盤を なぞる
- タイムと ★（落ちずに・ヒントを見ずに 目やすの時間 以内で ★3）。「💡 ヒント」で いまの所から ゴールへの 道すじの 先8マスが 3秒 点で 見える。ベストと 進んだ面は この端末（localStorage `nsg_meiro`）
- めいろの あいだは うしろの 歩く地図を 止める（`meiroApi.pause`）
- 道の すくない所で めいろが つくれない名所は、その面から はずして つぎの名所にする。はずした名所は この端末に のこす（開きなおしても 面の ならびが かわらない）。地図が よめなかった だけの ときは はずさない
- ベストタイム・★は 名所の id ごとに のこす
- 📣 シェア（ゴールの カード）：「西尾めいろ ☀️きょうの めいろ で「名所」まで 何秒 ★」の 文と、右に めいろの 盤を 入れた 絵（`share.js` の `openShare('meiro')`。シェアの 窓は めいろの 上に 出す）
- シェアの リンクに `?meiro=daily`（きょうの めいろ）・`?meiro=1`（めいろ）。はじめての人は いちばん上の ボタンが「☀️ きょうの めいろ に ちょうせん」になり（iPhone の 傾きの 許可を タップの その場で 聞くため）、もう 遊んでいる人は すぐ ひらく（傾きの 許可は めいろを さわった ときに 聞く）
- 👻 ゴースト：ベストを 出した ときの 走り（0.1秒ごとの 位置）を のこし、つぎから 水色の わの うすい お米が いっしょに 走る（タイムが 動きだしてから）。localStorage `nsg_meiro_ghost`（新しい 40面ぶん）。盤の 大きさ・スタート・ゴールが かわっていたら 出さない
- ☀️ きょうの めいろ（「いちらん」の いちばん上）：日本時間の 日づけで きまる 名所（はじめの 3面は のぞく。まだ 進んでいない面の 名所も 出る。その端末で はずした名所に 左右されないよう、はずす前の ならびから えらぶ。その むずかしさで つくれない名所なら つぎの名所）。むずかしさは いつも 中くらい（7面と 同じ 盤・穴8つ）。とけても 面は すすまない。ベスト・★は ふつうの面とは べつに のこす（`day:名所id`。きろく の ★の合計には 入れない）
- 確かめ：道すじを たどって 傾けを あやつる 自動プレイで、1〜9面（西尾駅・西尾城跡・らいすぴあ・岩瀬文庫・近藤米穀店・金蓮寺・常福寺・…）が ぜんぶ 7〜12秒で ゴールできた（道のり 24〜46マス）
- コード：`nishio-go/meiro.js`。プレイテスト `tools/playtest.js` の `meiro`
