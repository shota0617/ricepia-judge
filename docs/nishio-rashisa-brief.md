# 西尾らしさブリーフ（にしおさんぽGO開発用）

調査日：2026-10-29。にしおさんぽGOのコンテンツを「西尾らしい」ものにするための素材集。
ゲーム側の現状：`nishio-go/areas.json` に5地区（西尾・一色・吉良・幡豆・佐久島）＋近隣6市町が定義済み。本ブリーフは地区ごとの中身（名物・生き物・場所・季節）を厚くするための材料。

## 西尾らしさの柱

### 1. 抹茶のまち（西尾地区）
- 抹茶の原料「てん茶」の生産量が日本有数。温暖な気候・矢作川の川霧・土壌が育てる。
- 稲荷山茶園公園から茶畑を一望できる。茶摘みは4月末〜5月、石臼で挽いて自分で点てる体験、旧近衛邸（西尾市歴史公園）で抹茶をいただける。
- ゲームへの示唆：茶畑・茶摘み・石臼・茶席は西尾地区の象徴。季節（春の新茶）と結びつけやすい。

### 2. 一色産うなぎと港町（一色地区）
- 一色町は国内有数のうなぎ産地で、全国生産の約2割。養鰻は明治27年（1894年）から。
- 三河一色さかな広場／さかな村、えびせんべいも地域ブランド（いずれも特許庁の地域ブランド認定・ふるさと納税の顔）。
- 一色大提灯まつり：巨大な提灯で知られる既存の祭りコンテンツと相性が良い。

### 3. 佐久島（佐久島地区）
- 三河湾最大の島。一色港から高速船で約20分。三河湾国定公園。
- 島内にアート作品が点在（22箇所とも言われる）。「祭りとアート」がキーワード。黒壁の集落景観。
- アサリ・タコ・磯ガキなど海の幸。トンボロ現象（干潮時に海の道が現れる）も市内の見どころの一つ。

### 4. 城下町と祇園祭（西尾地区）
- 西尾城は鎌倉時代初期に足利義氏が築いた西条城が始まり。大給松平家6万石の城下町。
- 西尾市歴史公園：本丸丑寅櫓、鍮石門、旧近衛邸、尚古荘。西駅西側は寺社が多く「三河の小京都」。
- その栄華は西尾祇園祭として今も残る。華蔵寺・花岳寺・金蓮寺弥陀堂などの史跡。

### 5. 吉良と黄金堤（吉良地区）
- 吉良上野介義央の里。吉良温泉・吉良ワイキキビーチ、三河ガラス工芸美術館の巨大万華鏡。
- **黄金堤（こがねづつみ）**：貞享3年（1686年）、吉良義央が私財を投じて領民と一夜で築いたと伝わる堤防（長さ180m・高さ4m）。その後水害がなくなり、金色の稲穂が田を彩ったことから「黄金堤」と呼ばれる。農林水産省の郷土遺産的な紹介もある。
- ゲームへの示唆：お米・田んぼが主役のこのゲームにとって、黄金堤は「西尾の稲作の原点」として格別の物語性がある。

### 6. 矢作川と田んぼの生き物（全地区の土台）
- 矢作川は西尾市で三河湾に注ぐ。河口部は三角州・干拓地が広がり、黄金堤などに守られた水田地帯。
- 矢作川・水田・用水に生きる生き物（国交省・愛知県の調査より）：
  - 魚：メダカ（絶滅危惧II類）、イチモンジタナゴ（EN）、アカザ（VU）、ドジョウ、モツゴ、ギンブナ、カマツカ、シマドジョウ
  - 干潟：アサリ、ヤマトシジミ、ウミニナ
  - その他：ニホンイシガメ（水田や畑を餌場・産卵場に使う）、コアジサシ・コチドリ（汽水域）、ミサゴ、ユリカモメ
- ゲームへの示唆：メダカは「水のある場所」にだけ出す（PR #425 の指摘とも一致する生態の正確さ）。生き物の出し分けを地区・水辺タイプ（田んぼ／川／干潟）で分けると西尾らしさと生態の両方が立つ。

### 7. その他の素材
- 三ヶ根山（幡豆地区の山並み・スカイライン）、カーネーション（花き産地）、あじさい、ひまわり畑。
- 名物食：うな丼・ひつまぶし、抹茶パフェ・かき氷（4月末〜9月）、碾茶飯・茶そば、えびせんべい焼き体験、味噌蔵。

## 設計原則（ユーザー指示・最優先）

**西尾らしさは、主人公の米粒（お米つぶ）の周りに配置する。**
名物・生き物・場所・行事は、手帳や図鑑のような周辺コンテンツに散らすのではなく、主人公のセリフ・出会い・持ち物・行動・住処まわりを通じて出すこと。プレイヤーが主人公と一緒にいる場面で西尾を感じるのが正解で、主人公と無関係な場所に置くのは不正解。

## 大きな西尾らしさの候補（ユーザー指示：細かな文言修正ではなく、大きな追加を1つ）

1. **黄金堤をランドマーク／スポットとして追加**：吉良の田んぼ地帯に黄金堤そのものを登場させ、稲穂の季節・お米イベントと結びつける。お米が主役のゲームの「聖地」になり得る。
2. **茶畑と茶摘みの要素**：西尾地区に茶畑の風景・茶摘み（新茶シーズン）・石臼などの体験要素をまとめて追加する。
3. **佐久島アートめぐり**：船で渡る移動と、島内のアート作品スポットを巡る要素を追加する。
4. **一色のうなぎと海の幸**：養鰻池・さかな広場など、一色の港町らしい要素をまとめて追加する。
5. **水辺タイプ別の生き物出し分け**：田んぼ／川／干潟で出る生き物を分ける（メダカは水場だけ、干潟はアサリ・シジミ、など）。生態の正確さと地区の個性が同時に立つ。

**実装済み（claude/nishio-rashisa-2）**：5「水辺タイプ別の生き物出し分け」。生きもの手帳に where `kawa`（海ではない川・池・用水。`pixel.js` の `waterKind` が国土数値情報の土地利用で海水域の有無を見分ける）を足し、メダカ・ドジョウ・ニホンイシガメ（田んぼ）／アカザ・カマツカ（川・池）／ミサゴ（水べ）／コチドリ・ヤマトシジミ（一色干潟）の8種と16×16のドット絵を追加。出典は国交省 矢作川流域の自然状況（本ブリーフの出典欄）。ノートの文は、ブリーフの一覧に載っていること（絶滅危惧II類の区分・水田を餌場・産卵場に使う・汽水域・干潟の貝）だけ。出典PDFは作業環境から開けず原文では未確認。1〜4は未着手。

**実装済み（claude/nishio-rashisa-3）**：設計原則に沿った「お米つぶの 西尾ばなし」。行き先に着いたとき、主人公の お米つぶ（あいちのかおりちゃん）が、着いた名所の地区（西尾・一色・吉良・幡豆・佐久島）と今の月に合わせて、その地区の名物・場所・行事を自分との関わりとして話す。データは `nishio-go/komebanashi.js`（24話。抹茶・城下町・祇園祭／うなぎ・えびせん・大提灯／黄金堤・万華鏡・温泉／三ヶ根山・カーネーション／佐久島の船・アート・トンボロ・海の幸／どこでも：矢作川・メダカ・ニホンイシガメ）。`game.js` の `komeBanashi(g)` が「着いたね！」の次に1話ぶん足す（`S.komeSeen` で話した話を覚え、同じ地区をひとめぐりするまで繰り返さない。月の合う話を先に）。内容はこのブリーフの調べた事実だけ。黄金堤の1686年・一夜・180m・4m も入れた。残りの候補：1（黄金堤のスポット化）〜4。

**実装済み（claude/nishio-rashisa-4）**：「お米つぶの みちくさ」。転がっている最中、お米つぶがいる所（国土数値情報の土地利用：田／川・池／海べ／田以外の農用地、pixel.js の `here.town` の町名）と今の月に合わせて、吹き出し（`riceSay`）でひとりごとを言う。名所に着いたときに話す3周目とは違い、道ばたで自分で気づく形。データは `nishio-go/michikusa.js`（田んぼ：メダカ・ドジョウ・イシガメ／吉良の田：黄金堤・稲穂の金色／川・池：アカザ・カマツカ・ミサゴ／海べ：アサリ・ヤマトシジミ・コチドリ／町：うなぎ・えびせん・大提灯・黄金堤・三ヶ根山・抹茶／農用地：茶摘み・てん茶・カーネーション。畑の種類は土地利用では分からないので「かも」で言う）。`pixel.js` の `mzMichikusa` が45〜75秒に1回まで（はじめは15秒後）、西尾市の中だけで言い、言ったことは `nsg_michikusa` に覚えてひとめぐりするまで繰り返さない。残りの候補：1（黄金堤のスポット化）〜4。

**実装済み（claude/nishio-rashisa-5）**：「お米つぶの おとも」。転がっている町と今の月に合わせて、西尾の名物がお米つぶのあとをころころついてくる（出てきたとき、お米が吹き出しで一言）。畑のそばで出る季節の作物（いちご・なす・大豆。`nakama`）と同じしくみで、町の名物版。データは `nishio-go/otomo.js`（一色：うなぎ・えびせんべい／西尾：てん茶の葉（4〜5月は茶摘みの言いかた）／吉良：金色の稲穂（9〜10月）／一色・吉良・幡豆の海べ：アサリ）。`pixel.js` の `nakamaStep` が60〜100秒に1回まで（はじめは20秒後）、西尾市の中だけで出し、前と同じおともは続けない。小さなドット絵は `drawNakama` に追加。内容はブリーフの事実だけ。残りの候補：1（黄金堤のスポット化）〜4。

**実装済み（claude/nishio-rashisa-6）**：「お米つぶの にもつ」。名所に着くと、その地区の名物を お米つぶが あたまに のせて転がる（持ち物＝主人公の見た目が変わる）。データは `nishio-go/nimotsu.js`（西尾：てん茶の葉（4〜5月）・抹茶わん／一色：うなぎ・えびせんべい・提灯／吉良：金色の稲穂（9〜10月）・稲穂／幡豆：カーネーション／佐久島：アサリ）。`game.js` の `komeNimotsu(g)` が着いた名所の地区と月で1つ選び（前と同じものは続けない）、`S.nimotsu` に記録して「着いたね！」の話に1ページ足す。地区のない所（となりの市町）では持ち物を変えない。1日たつか、つぎの名所に着くまで のせている。`pixel.js` の `drawNimotsu` が転がっているお米のあたまに描く（ねむっているときは描かない。絵は `drawNakama` を共用し、抹茶わん・提灯・カーネーションを追加）。内容はブリーフの事実だけ。残りの候補：1（黄金堤のスポット化）〜4。

いずれも「データ＋ロジック＋表示まで一貫した、ゲーム体験が目に見えて変わる追加」が条件。文言1行の修正は不可。

## 開発上の制約（このリポジトリの流儀）
- セリフの言いかたは統一が進んでいる（直近コミット f5ac758）。装飾の絵文字（✨🎯💦🍚🏁）は付けない。♪・💨 は数を表すときだけ。
- データは `nishio-go/areas.json` のような構造化データを優先し、ゲーム本体（game.js）は大きく書き換えない。
- テスト：`python3 -m unittest discover -s tests -v` を必ず通す。
- 事実関係は本ブリーフと一次情報（西尾市公式・国交省・農林水産省）に基づく。創作の地名・施設を作らない。
