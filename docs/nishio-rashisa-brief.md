# 西尾らしさブリーフ（にしおさんぽGO開発用）

調査日：2026-10-29。にしおさんぽGOのコンテンツを「西尾らしい」ものにするための素材集。
ゲーム側の現状：`nishio-go/areas.json` に5地区（西尾・一色・吉良・幡豆・佐久島）＋近隣6市町が定義済み。本ブリーフは地区ごとの中身（名物・生き物・場所・季節）を厚くするための材料。

## 西尾らしさの柱

### 1. 抹茶のまち（西尾地区）
- 抹茶の原料「てん茶」の生産量が日本有数。温暖な気候・矢作川の川霧・土壌が育てる。
- 稲荷山茶園公園から茶畑を一望できる。茶摘みは4月末〜5月、石臼で挽いて自分で点てる体験、旧近衛邸（西尾市歴史公園）で抹茶をいただける。
- ゲームへの示唆：茶畑・茶摘み・石臼・茶席は西尾地区の象徴。季節（春の新茶）と結びつけやすい。

### 2. 一色産うなぎと港町（一色地区）
- 一色町は国内有数のうなぎ産地で、全国生産の約2割。養鰻は明治27年（1894年）から。
- 三河一色さかな広場／さかな村、えびせんべいも地域ブランド（いずれも特許庁の地域ブランド認定・ふるさと納税の顔）。
- 一色大提灯まつり：巨大な提灯で知られる既存の祭りコンテンツと相性が良い。

### 3. 佐久島（佐久島地区）
- 三河湾最大の島。一色港から高速船で約20分。三河湾国定公園。
- 島内にアート作品が点在（22箇所とも言われる）。「祭りとアート」がキーワード。黒壁の集落景観。
- アサリ・タコ・磯ガキなど海の幸。トンボロ現象（干潮時に海の道が現れる）も市内の見どころの一つ。

### 4. 城下町と祇園祭（西尾地区）
- 西尾城は鎌倉時代初期に足利義氏が築いた西条城が始まり。大給松平家6万石の城下町。
- 西尾市歴史公園：本丸丑寅櫓、鍮石門、旧近衛邸、尚古荘。西駅西側は寺社が多く「三河の小京都」。
- その栄華は西尾祇園祭として今も残る。華蔵寺・花岳寺・金蓮寺弥陀堂などの史跡。

### 5. 吉良と黄金堤（吉良地区）
- 吉良上野介義央の里。吉良温泉・吉良ワイキキビーチ、三河ガラス工芸美術館の巨大万華鏡。
- **黄金堤（こがねづつみ）**：貞享3年（1686年）、吉良義央が私財を投じて領民と一夜で築いたと伝わる堤防（長さ180m・高さ4m）。その後水害がなくなり、金色の稲穂が田を彩ったことから「黄金堤」と呼ばれる。農林水産省の郷土遺産的な紹介もある。
- ゲームへの示唆：お米・田んぼが主役のこのゲームにとって、黄金堤は「西尾の稲作の原点」として格別の物語性がある。

### 6. 矢作川と田んぼの生き物（全地区の土台）
- 矢作川は西尾市で三河湾に注ぐ。河口部は三角州・干拓地が広がり、黄金堤などに守られた水田地帯。
- 矢作川・水田・用水に生きる生き物（国交省・愛知県の調査より）：
  - 魚：メダカ（絶滅危惧II類）、イチモンジタナゴ（EN）、アカザ（VU）、ドジョウ、モツゴ、ギンブナ、カマツカ、シマドジョウ
  - 干潟：アサリ、ヤマトシジミ、ウミニナ
  - その他：ニホンイシガメ（水田や畑を餌場・産卵場に使う）、コアジサシ・コチドリ（汽水域）、ミサゴ、ユリカモメ
- ゲームへの示唆：メダカは「水のある場所」にだけ出す（PR #425 の指摘とも一致する生態の正確さ）。生き物の出し分けを地区・水辺タイプ（田んぼ／川／干潟）で分けると西尾らしさと生態の両方が立つ。

### 7. その他の素材
- 三ヶ根山（幡豆地区の山並み・スカイライン）、カーネーション（花き産地）、あじさい、ひまわり畑。
- 名物食：うな丼・ひつまぶし、抹茶パフェ・かき氷（4月末〜9月）、碾茶飯・茶そば、えびせんべい焼き体験、味噌蔵。

## 開発上の制約（このリポジトリの流儀）
- セリフの言いかたは統一が進んでいる（直近コミット f5ac758）。装飾の絵文字（✨🎯💦🍚🏁）は付けない。♪・💨 は数を表すときだけ。
- データは `nishio-go/areas.json` のような構造化データを優先し、ゲーム本体（game.js）は大きく書き換えない。
- テスト：`python3 -m unittest discover -s tests -v` を必ず通す。
- 事実関係は本ブリーフと一次情報（西尾市公式・国交省・農林水産省）に基づく。創作の地名・施設を作らない。
