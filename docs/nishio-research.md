# 西尾市のリサーチ（2026年10月に調べなおし）

西尾ドット絵帳など、ゲームの題材を「西尾ならでは」にするための下調べ。西尾市の公式サイト、西尾市観光協会、愛知県の観光サイト（Aichi Now）、愛知県・農林水産省・文化庁の資料などで確かめたことだけを書く。数字は出典の時点のもの。

## 西尾を形づくる7つの柱

| 柱 | ひとことで |
|---|---|
| 1. 抹茶 | てん茶（抹茶の原料）の国内生産量の約2割。「西尾の抹茶」は地域ブランド。お茶の始まりは実相寺 |
| 2. 一色のうなぎと三河湾の幸 | 一色産うなぎは全国トップクラス。あさり・えびせんべい（一色が発祥）・海苔・トラフグ |
| 3. 花 | カーネーションは施設園芸の生産額が全国トップクラス、バラは県内2位。「にしおフラワー」 |
| 4. 吉良 | 吉良氏・今川氏の発祥の地。地元では名君と語られる吉良上野介、黄金堤と赤馬。国宝の金蓮寺弥陀堂 |
| 5. 祭りと芸能 | 国の重要無形民俗文化財が2つ（鳥羽の火祭り・三河万歳）。三河一色大提灯まつり、西尾祇園祭、てんてこ祭 |
| 6. 城下町と佐久島 | 西尾城（六万石）・岩瀬文庫・旧近衛邸と尚古荘。アートの島・佐久島と黒壁集落 |
| 7. 海と山の景色 | 三ヶ根山のあじさい（約7万本）、一色干潟、前島のトンボロ干潟、八ツ面山 |

ほかに、自動車部品などの製造業が多いまちでもある（デンソー・アイシン系の工場など）。ただしドット絵の題材には向かないので、ここでは扱わない。

### いまの題材で、西尾らしさが弱いもの

| いまの題材 | 弱いところ | 入れかえ・直す案 |
|---|---|---|
| 防霜ファンの茶畑 | 防霜ファンは茶どころ共通。西尾の出典なし | 「稲荷山茶園」に名前と絵を寄せる（茶摘みの季節、丘の茶畑） |
| 茶畑と摘採機 | 摘採機も茶どころ共通 | 「稲荷山茶園の茶摘み（茶摘み娘の衣装）」 |
| 抹茶ソフトクリーム | 全国どこにでもある | 「カーネーションの温室」 |
| 抹茶パフェ | 同じ | 「てんてこ祭」 |
| 漁港と漁船 | 型どおりの漁港 | 「一色さかな広場の朝市」 |

ほかに「金蓮寺弥陀堂」「三河万歳」も、いまの★★★の題材と同じくらい西尾ならではなので、足す価値がある。
