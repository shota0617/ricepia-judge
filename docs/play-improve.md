# AI が遊んでは直す（プレイ→改善のループ）

にしおさんぽGO を AI（Claude）に実際に遊ばせ、気づいたことを1つずつ直していくしくみです。
ほかのゲーム（ゲームボーイのポケモン赤・緑など）も AI に遊ばせて、面白さを生んでいる「しくみ」を見つけ、にしおさんぽGO に持ちこみます。

```
 ほかのゲームを遊ぶ（tools/gb-play.py）──→ 「つぎにやること」の候補
                                               │
 にしおさんぽGO を遊ぶ（tools/ai-play.js）──→ 1つ直す ──→ 遊んで確かめる（ai-play.js・playtest.js）──→ 記録（このファイル）
        ↑                                                                                              │
        └──────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 道具

| 道具 | すること |
| --- | --- |
| `tools/ai-play.js` | にしおさんぽGO を、AI が手順（JSON）で操作して遊ぶ。1手ごとにスクリーンショットと様子（ポイント・行き先・開いている窓の文）を残し、記録を引きついで続きから遊べる |
| `tools/playtest.js` | 決まった台本で通しに遊んで、こわれていないか確かめる（呼びとめ もここで確かめる） |
| `tools/play-improve-prompt.md` | ループ1周ぶんの、Claude Code への指示（遊ぶ→1つ直す→確かめる→記録） |
| `.github/workflows/play-improve.yml` | 上の1周を、指定した回数まわして PR にする（Actions の「Nishio play-improve」→ Run workflow。回数は5回まで） |
| `tools/gb-play.py` | ゲームボーイのゲームを Claude に遊ばせ、にしおさんぽGO に持ちこめるしくみを `gb-play-out/report.md` にまとめる（手元で動かす） |

### ループを手元でまわす

```sh
npm install --no-save --no-package-lock playwright@1.48.2 && npx playwright install chromium
node tools/playtest.js .play/before                     # 通しのプレイテスト
claude -p "$(cat tools/play-improve-prompt.md)"         # Claude Code が遊んで1つ直す（.play/ に画面が残る）
```

### ポケモン赤・緑を遊ばせる（手元で）

```sh
pip install pyboy anthropic pillow
export ANTHROPIC_API_KEY=...                           # または ant auth login
python3 tools/gb-play.py --rom ~/roms/red.gb --episodes 6 --steps 40
python3 tools/gb-play.py --rom ~/roms/red.gb --resume    # 続きから
```

- ROM は**自分で持っているカセットから吸い出したもの**だけを使います。リポジトリには入れません（`.gitignore` で `*.gb` `*.gbc` `gb-play-out/` を除いています）。Actions でも動かしません（ROM をサーバーに置かないため）
- できた `gb-play-out/report.md` を読んで、よいものを下の「つぎにやること」に足すと、次の周回で Claude Code が1つずつ持ちこみます
- 持ちこむのは**遊びのしくみだけ**です。キャラクターや技の名前、絵、音楽、文章はまねしません（効果音も `tools/make-sound.py` のオリジナル）
- 1エピソード40手で、画像は1枚 約120トークンです。6エピソードで 240 回 Claude に考えさせます

## つぎにやること（候補）

ポケモン赤・緑から考えた候補は、ひととおり入れた。`tools/gb-play.py` で実際に遊ばせたまとめ（`gb-play-out/report.md`）から、よいものをここに足す。

1. **西尾の生きものを、もっと出典つきで**：いま西尾ならではの話があるのは、重要野鳥生息地（IBA）の資料で確かめた ケリ・セイタカシギ・スズガモ と、アサリ。矢作川の魚などは、出典を開いて確かめられたら足す
2. **しらべるの手がかりを、もっと人ごとに**：いまは人の見た目ごとに2つずつ。目立つ人（ガイドさん・漁師さんなど）は、npcs.js に その人だけの言い方（1行）を持たせてもよい

済んだもの：呼びとめ（周回1）・聞いた／行った の2段の記録と区切りのほめことば（周回3）・さんぽ仲間のライバル（周回4）・ライバルを歩く地図に立たせる（周回5）・しらべると見つかるまちメモ（周回6）・生きもの手帳（周回7）・西尾の生きもの（周回8）・人のことばの手がかり（周回9）・おまかせ歩きが はじめの1枚 で止まる（周回10）・おとどけもの（周回11）・話したときの知らせを短く（周回12）・いまいる市の まちメモ（周回13）・地区のしるし（周回14）・プレイ画面をシンプルに（周回15）・クリア（殿堂入り）（周回16）・生きもの手帳の賞状（周回17）・クリア後の となりの市町のしるし（周回18）。
「行ったことのある名所へ ひとっとび」は、もうある（操作して移動のとき、名所の窓の「ここへ移動」。周回4で確かめた）。

## ポケモン赤・緑を はじめから クリアまで たどる（しくみの洗い出し）

この作業の環境では、本物のゲーム（ROM）は遊べない（ROM がなく、手に入れることもしない）。ゲームの はじめから 最後（殿堂入り・クリア後）までの流れを順にたどり、
場面ごとの「面白さを生んでいる しくみ」を、にしおさんぽGO に入っているか・入れられるかで分けた。持ちこむのは しくみだけ（名前・絵・音・文章はまねしない）。
本物で確かめるときは、自分のカセットから吸い出した ROM で `tools/gb-play.py` を手元で動かす。

| 場面 | しくみ | にしおさんぽGO |
| --- | --- | --- |
| はじまり | 草むらに入ろうとすると呼びとめられる／はじめの1匹を3つから選ぶ | ✅ 呼びとめ（周回1）／はじめの1枚を3枚から（前から） |
| はじまり | 先回りするライバル | ✅ さんぽ仲間のライバル（周回4・5） |
| 次の町 | 荷物をあずかって届ける | ✅ おとどけもの（周回11） |
| 次の町 | 図鑑をもらう（見た／つかまえた の2段） | ✅ 聞いた名所／めぐったスポット（周回3）・生きもの手帳（周回7） |
| 道路 | 目が合うと勝負 | ✅ 呼びとめ（話しかけに。周回1） |
| 草むら・水べ | 歩くと出会う・場所と季節で出るものがちがう | ✅ 生きもの手帳（周回7・8。西尾ならではの生きもの） |
| どこでも | 何もない所を しらべると道具 | ✅ しらべる（周回6・9） |
| 町ごと | 町の人に認めてもらって しるしを集める | ✅ 地区のしるし（周回14） |
| 町ごと | 区切りで博士が ほめて、次をすすめる | ✅ ほめことば（周回3） |
| 乗りもの | 自転車で速く動ける | ✅ 軽トラ（前から）。手に入れる話はない → 候補 |
| 道具 | 技で通れる所がふえる（切る・泳ぐ・照らす） | ❌ 本当の道を ふさぐことになるので入れない |
| 港 | 一度だけの船のイベント | ❌ 出典で確かめられる行事しか出さないので、作り話のイベントは入れない |
| 特別な場所 | 歩数の決まった場所で、めずらしいものを探す | 候補：「きょうの さんぽ 100歩チャレンジ」のような短い遊び |
| 水べ | 釣りざおで、水べで出会えるものがふえる | 候補：生きもの手帳を、水べで しらべると出会える しくみに |
| 選ぶ | 2つから1つだけ もらえる（もう1つは もらえない） | 候補：地区のしるしのあとに、2つの絵から1枚を選ぶ |
| 集める | 図鑑がそろうと 賞状 | ✅ 生きもの手帳の賞状（周回17）。ドット絵帳は1万枚なので そろえる目標にはしない |
| 最後 | しるしを全部集めて、最後に認めてもらう → 記録が残る（殿堂入り）→ エンディング | ✅ クリア（周回16） |
| クリア後 | 行ける所・出会えるものが ふえる | ✅ となりの市町のしるし（周回18。殿堂入りのあとだけ出る） |

### 周回18（2026-10）：クリア後の となりの市町のしるし

  殿堂入りのあとだけ、となりの6市町（岡崎・安城・碧南・高浜・幸田・蒲郡）にも しるしが出る。その市町の人（岡崎城の観光ボランティアガイドさん・安城の歴史博物館のガイドさん・
  碧南の無我苑のガイドさん・高浜の鬼みちの案内の人・幸田の郷土資料館のガイドさん・蒲郡の竹島の観光ガイドさん）に会いに行くと もらえる（`SEAL_POST`）。蒲郡は注目スポットが3か所なので3か所で
- クリアするまでは、となりの市町のしるしは バッジの一覧にも出さない（画面をにぎやかにしない）。クリアの条件は、いままでどおり西尾市の5つの地区だけ
- **確かめたこと**：クリア前は しるしが5つだけ。クリア後は11になり、蒲郡の3か所をめぐって竹島の観光ガイドさんと話すと「🔖 蒲郡のしるし」

### 周回16（2026-10）：クリア（殿堂入り）

- **持ちこんだしくみ**：赤・緑の、町ごとの しるしを全部集めて 最後に認めてもらい、記録が残って エンディングになる しくみ。これまで にしおさんぽGO には「クリア」がなかった
- 5つの地区のしるしが そろうと「🏯 5つのしるしが そろった！ 西尾市歴史公園（西尾城跡）の観光ボランティアガイドさんに会いに行こう」。ガイドさんと話すと「西尾さんぽ 殿堂入り」（`clearGive`・`showEnding`）。
  エンディングには、ガイドさんのことば・ここまでの記録（めぐった名所・話した人・歩いた道のり・ドット絵・まちメモ・生きもの）・しるしをくれた5人・ライバルのことば（「つぎは となりの市町も いっしょに歩こまい」）。
  バッジ「👑 殿堂入り」。バッジをタップすると、いつでも 殿堂入りした時点の記録（殿堂入りした日つき）をもう一度見られる。クリアしても そのまま遊べる。
  レビューで、記録をクリアの時点で とっておくようにし、ごほうびの画面や絵の読みこみ待ちが終わってから エンディングを出すようにした
- **確かめたこと**：4つの地区のしるしを持って、西尾の5か所をめぐり、ガイドさんと話すと「西尾のしるし」と「殿堂入り」が同時に出て、エンディングが出た

### 周回15（2026-10）：プレイ画面をシンプルに

- **遊んで見つけたこと**：歩く地図の上に、こよみの札・右上の丸ボタン3つ（せかいちず・＋・－）・スティック・車・おまかせ歩き・下のパネル2段（行き先の札と「📘 2　📜 0/3　🎒 0.7/1km」）・タブ5つが出ていた。
  おまかせ歩きを押すたびに「おまかせ歩き：オン（行き先へ自動で歩きます。スティックや…）」の長い知らせが出た。行き先に着いた知らせは、次の行き先の理由の文までついて長かった
- **直したこと**（文字を少なく＝ふだんの表示だけ。文字を多くの表示は いままでどおり）
  - 下のパネル：気をつけること（車・範囲外・GPS など）がないときは、数の段を出さず、行き先の札だけ（数は きろく・とくてん に）
  - 右上：＋ と － を 🔍 1つにした（押すたびに大きく、いちばん大きいと はじめの大きさへ）。せかいちずの 🌐 は残す
  - 知らせ：おまかせ歩きの くわしい知らせは はじめの1回だけ（オン・オフはボタンの色で分かる）。今週のテーマは「⛩️ 今週は「神社」で ポイント2倍」。行き先に着いたら「🧭 西尾城跡 +5pt → らいすぴあの店員さん」（理由の文は下の札に）
- **確かめたこと**：プレイテストが通る。おまかせ歩き3分で、知らせは12（まちメモ・人のことば・バッジ・クエスト）。文字を多くにすると、数の段と ＋・－ が もどる

### 周回12（2026-10）：話したときの知らせを短く

- **遊んで見つけたこと**：周回11で遊ぶと、ふだんの「文字を少なく」の表示なのに、人と話したときの知らせが4行になっていた
  （「💬 +10pt　📦 +10pt　🎉 Lv2　🎉 イベント達成：観光ボランティアガイドさんに会えた +5pt　📜 → …　🔍 旧近衛邸　📦 → …」）。
  話の窓が開いているあいだ、下の行き先の札は前の行き先のままだった
- **直したこと**：文字を少なくの表示では、ポイントを合わせて1つ、手がかりと荷物は印だけにした（「💬📦🎉 +25pt Lv2　📜 → お茶好きのお姉さん（旧近衛邸） 🔍📦」で2行）。
  文字の多い表示は、いままでどおり。行き先が変わったら、すぐ下の札を書きかえる（`setGuide` で `renderGuide`）

### 周回11（2026-10）：おとどけもの

- **持ちこんだしくみ**：赤・緑の、はじめの町で荷物をあずかって届けるしくみ。人が次の人をすすめたとき、半分くらいで「○○に、この手紙を届けてくれん？」と荷物をあずける。
  すすめられた人に話しかけると届けられて +10pt（1つずつ・1日3回まで。`giveParcel`・`deliverParcel`）。あずけた人の話の最後のページに「📦 ○○に、その手紙を よろしくね」
- 荷物は 手紙・ふろしき包み・回覧板・おすそわけの包み・かりていた本 の、どこにでもある物だけ。中身や、その人についての事実は言わない
- 人の話で進む、を「人と人をつなぐ」にも広げた。すすめられた人に会いに行く理由が1つふえる
- **確かめたこと**：駅前の学生から手紙をあずかり、西尾城跡のガイドさんに届けて +10pt。`tools/playtest.js` に おとどけもの のチェックを足した

### レビューで直したこと（周回8〜12のあと）

- **あるいて移動でも生きものに出会う**：生きもの手帳（周回7）は、操作して移動の1歩ごとにしか数えていなかった。あるいて移動（GPS）では、受けつけた歩きの あいだのマスで数える（`trailWalk` の each・`addTrail`。1回の位置の知らせで出会うのは1回まで）
- **選び直した行き先も、聞いた名所に**：みちしるべの「ほかの行き先」に選び直すと、聞いた名所に載らず、すすめた人の 🔍 の手がかりも出なかった。すすめた人（byId）を引きつぎ、聞いた名所にする（`pickAlt`）
- **選び直しも いちばん新しい すすめに**：同じ人から前に聞いた名所を選び直したとき、手がかりは別の名所のままだった。また すすめられた（別の人からも）・選び直したときは、いま すすめた人と時刻にする
- **ほめことばの地区**（周回3）：区切りの数がふつうのスポット（地区がない）だと、いまいる地区も すすめていた。いちばん近い注目スポットの地区で決める（`areaNear`）
- **聞いた名所・めぐったスポットをタップ**：ドット絵の地図では、隠れている ふつうの地図を動かしていて、何も起きないように見えた。名所の窓を出す
- **テストの直し**：おとどけもの・手がかりのチェックが、届けたあとに同じ人が次の荷物をあずける（半分の確率）と落ちていた。あて先と、どのページかに よらないようにした

### 周回10（2026-10）：おまかせ歩きが はじめの1枚 で止まる

### 周回9（2026-10）：しらべるの手がかりを、人のことばに
