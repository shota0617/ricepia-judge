# AI が遊んでは直す（プレイ→改善のループ）

にしおさんぽGO を AI（Claude）に実際に遊ばせ、気づいたことを1つずつ直していくしくみです。
ほかのゲーム（ゲームボーイのポケモン赤・緑など）も AI に遊ばせて、面白さを生んでいる「しくみ」を見つけ、にしおさんぽGO に持ちこみます。

```
 ほかのゲームを遊ぶ（tools/gb-play.py）──→ 「つぎにやること」の候補
                                               │
 にしおさんぽGO を遊ぶ（tools/ai-play.js）──→ 1つ直す ──→ 遊んで確かめる（ai-play.js・playtest.js）──→ 記録（このファイル）
        ↑                                                                                              │
        └──────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 道具

| 道具 | すること |
| --- | --- |
| `tools/ai-play.js` | にしおさんぽGO を、AI が手順（JSON）で操作して遊ぶ。1手ごとにスクリーンショットと様子（ポイント・行き先・開いている窓の文）を残し、記録を引きついで続きから遊べる |
| `tools/playtest.js` | 決まった台本で通しに遊んで、こわれていないか確かめる（呼びとめ もここで確かめる） |
| `tools/play-improve-prompt.md` | ループ1周ぶんの、Claude Code への指示（遊ぶ→1つ直す→確かめる→記録） |
| `.github/workflows/play-improve.yml` | 上の1周を、指定した回数まわして PR にする（Actions の「Nishio play-improve」→ Run workflow。回数は5回まで） |
| `tools/gb-play.py` | ゲームボーイのゲームを Claude に遊ばせ、にしおさんぽGO に持ちこめるしくみを `gb-play-out/report.md` にまとめる（手元で動かす） |

### ループを手元でまわす

```sh
npm install --no-save --no-package-lock playwright@1.48.2 && npx playwright install chromium
node tools/playtest.js .play/before                     # 通しのプレイテスト
claude -p "$(cat tools/play-improve-prompt.md)"         # Claude Code が遊んで1つ直す（.play/ に画面が残る）
```

### ポケモン赤・緑を遊ばせる（手元で）

```sh
pip install pyboy anthropic pillow
export ANTHROPIC_API_KEY=...                           # または ant auth login
python3 tools/gb-play.py --rom ~/roms/red.gb --episodes 6 --steps 40
python3 tools/gb-play.py --rom ~/roms/red.gb --resume    # 続きから
```

- ROM は**自分で持っているカセットから吸い出したもの**だけを使います。リポジトリには入れません（`.gitignore` で `*.gb` `*.gbc` `gb-play-out/` を除いています）。Actions でも動かしません（ROM をサーバーに置かないため）
- できた `gb-play-out/report.md` を読んで、よいものを下の「つぎにやること」に足すと、次の周回で Claude Code が1つずつ持ちこみます
- 持ちこむのは**遊びのしくみだけ**です。キャラクターや技の名前、絵、音楽、文章はまねしません（効果音も `tools/make-sound.py` のオリジナル）
- 1エピソード40手で、画像は1枚 約120トークンです。6エピソードで 240 回 Claude に考えさせます

## つぎにやること（候補）

ポケモン赤・緑の遊びのしくみから。上から順に、面白さの核（人の話と環境で進む）に合いそうなもの。

1. **田んぼ・川べりで出会う生きもの**：歩く地図の田んぼ・川べり・海べりを歩いていると、ときどき生きもの（サギ・カモ・カニなど）に出会い、ひとことと、いた場所が記録に残る（出典のある西尾の生きものだけ）
2. **しらべると見つかるもの**：人の話の手がかり（「お地蔵さんの裏をよう見てみりん」）の場所で「しらべる」と、まちメモが見つかる（たからばこと重ならないように）
3. **ライバルを歩く地図に出す**：いまは知らせのことばだけ。先回りした名所の前に、さんぽ仲間のドット絵を立たせる

済んだもの：呼びとめ（周回1）・聞いた／行った の2段の記録と区切りのほめことば（周回3）・さんぽ仲間のライバル（周回4）。
「行ったことのある名所へ ひとっとび」は、もうある（操作して移動のとき、名所の窓の「ここへ移動」。周回4で確かめた）。

## 周回の記録

### 周回4（2026-10）：さんぽ仲間のライバル

- **持ちこんだしくみ**：赤・緑の、先々で待っているライバル。行き先（名所・すすめられた人）に3回着くごとに1回、さんぽ仲間のソウタが「○○は もう見たじゃん！ おれは先に△△へ行っとるでね」と次の行き先へ先回りし、そこに着くと「おそかったじゃん！」と また会える（`nishio-go/game.js` の `rivalSay`）。
  次の行き先は、いままでどおり人の話と環境で決まる。ライバルは、それを人のことばで言う役
- **遊んで分かったこと**：おまかせ歩きで5分遊ぶと、行き先に着くのは名所1回・人2回くらいで、名所だけ数えるとライバルが ほとんど出なかった。人に会えたときも数えるようにした。人をすすめられたときは「その人がいる所」の名前で言う
- **確かめたこと**：おまかせ歩き5分で ライバルが出て、先回りした黄金堤で「おそかったじゃん！」と会えた
- **道具の直し**：`tools/ai-play.js` で日付を固定（PLAY_DATE）すると時計が止まり、おまかせ歩きが歩かない。説明に書いた

### 周回3（2026-10）：聞いた／行った の2段の記録

- **持ちこんだしくみ**：赤・緑の図鑑の「見た／つかまえた」。人にすすめられた名所（人をすすめられたときは、その人が立っている名所）が、きろく の「聞いた名所」に影の絵で載り、行くと「めぐったスポット」に入る。見出しに「行った数／聞いた数」（`heardOf`）。
  めぐったスポットが 5・10・20・30・50・100 か所になると、西尾城跡のガイドさんが ほめて、いまいる地区のほかで めぐった割合がいちばん低い地区をすすめる（`praiseCheck`。図鑑を見てくれる博士の役）
- **遊んで分かったこと**：人の話は、はじめは ほとんど「次の人」をすすめるので、名所だけ数えると「聞いた名所」がなかなかふえなかった → すすめられた人の立つ名所も入れた。
  ほめことばが、西尾にいるのに「つぎは西尾のほうも」と言っていた → いまいる地区をのぞいた。バッジの知らせに消されていた → バッジのあとに出す
- **確かめたこと**：2人と話すと 聞いた名所 が2つ（影の絵）。5か所目のチェックインで「もう5か所もめぐったじゃん！つぎは吉良のほうも歩いてみりん。まだ21か所あるに」。おまかせ歩き5分の中でも自然に出た。`tools/playtest.js` に 聞いた名所 のチェックを足した

### 周回2（2026-10）：ごほうびの題名

- **直したこと**：チェックインのごほうびで、いちばん大きな題名が「もらったドット絵」の名前で、着いた名所とまちがえやすかった（周回1で気づいたこと）。いちばん上に着いた所（「西尾市役所」など）、額縁の下の札に 🖼 と絵の題名、にした

### 周回1（2026-10）：呼びとめ

- **持ちこんだしくみ**：ポケモン赤・緑の「目が合ったら勝負」を、話しかけに。まだ話していない人の まっすぐ前後左右4マス以内に入ると、頭に「！」が出て、効果音（`eye.mp3`・オリジナル）が鳴り、その人が歩いてきて話しかけてくる。行き先もその人のすすめに変わる（`nishio-go/pixel.js` の `sightCheck`）。
  人の話で進む、という面白さの核を、こちらから話しかけなくても起きるようにした
- **遊んで見つけた不具合と直し**：歩いてきた人が「遠くて声が届かない」と言った（話せる距離を、その人のもとの場所から測っていた）。呼びとめた人とは、もとの場所から遠くても話せるようにした（`nishio-go/game.js` の `calledBy`）
- **確かめたこと**：歩いてくる間と話の間は動けない・話が終わると動ける・おまかせ歩きでも止まらずに続く（90秒遊ばせて確かめた）。`tools/playtest.js` に呼びとめのチェックを足した
- **テストの直し**：おみやげ袋のチェックが、歩き方しだいで落ちていた（店に着く前に袋が開くと、チェックインの知らせに消される）。一度出たかを見るようにした
