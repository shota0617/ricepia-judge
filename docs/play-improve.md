# AI が遊んでは直す（プレイ→改善のループ）

にしおさんぽGO を AI（Claude）に実際に遊ばせ、気づいたことを1つずつ直していくしくみです。
ほかのゲーム（ゲームボーイのポケモン赤・緑など）も AI に遊ばせて、面白さを生んでいる「しくみ」を見つけ、にしおさんぽGO に持ちこみます。

```
 ほかのゲームを遊ぶ（tools/gb-play.py）──→ 「つぎにやること」の候補
                                               │
 にしおさんぽGO を遊ぶ（tools/ai-play.js）──→ 1つ直す ──→ 遊んで確かめる（ai-play.js・playtest.js）──→ 記録（このファイル）
        ↑                                                                                              │
        └──────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 道具

| 道具 | すること |
| --- | --- |
| `tools/ai-play.js` | にしおさんぽGO を、AI が手順（JSON）で操作して遊ぶ。1手ごとにスクリーンショットと様子（ポイント・行き先・開いている窓の文）を残し、記録を引きついで続きから遊べる |
| `tools/playtest.js` | 決まった台本で通しに遊んで、こわれていないか確かめる（呼びとめ もここで確かめる） |
| `tools/play-improve-prompt.md` | ループ1周ぶんの、Claude Code への指示（遊ぶ→1つ直す→確かめる→記録） |
| `.github/workflows/play-improve.yml` | 上の1周を、指定した回数まわして PR にする（Actions の「Nishio play-improve」→ Run workflow。回数は5回まで） |
| `tools/gb-play.py` | ゲームボーイのゲームを Claude に遊ばせ、にしおさんぽGO に持ちこめるしくみを `gb-play-out/report.md` にまとめる（手元で動かす） |

### ループを手元でまわす

```sh
npm install --no-save --no-package-lock playwright@1.48.2 && npx playwright install chromium
node tools/playtest.js .play/before                     # 通しのプレイテスト
claude -p "$(cat tools/play-improve-prompt.md)"         # Claude Code が遊んで1つ直す（.play/ に画面が残る）
```

### ポケモン赤・緑・ドラゴンクエストを遊ばせる（手元で）

```sh
pip install pyboy anthropic pillow                     # ゲームボーイ（ポケモン赤・緑、ゲームボーイ版のドラゴンクエスト1・2 など）
pip install "numpy<2" nes-py anthropic pillow          # ファミコン（ドラゴンクエスト1〜3）。nes-py は numpy 2 で動かないので 1 に（Python 3.12 まで）
export ANTHROPIC_API_KEY=...                           # または ant auth login
python3 tools/gb-play.py --rom ~/roms/red.gb --episodes 6 --steps 40
python3 tools/gb-play.py --rom ~/roms/red.gb --resume    # 続きから（ゲームボーイだけ）
python3 tools/gb-play.py --rom ~/roms/dq1.nes --episodes 6 --steps 40 --out dq-play-out
```

- ROM は**自分で持っているカセットから吸い出したもの**だけを使います。リポジトリには入れません（`.gitignore` で `*.gb` `*.gbc` `*.nes` `*.fds` `gb-play-out/` を除いています）。Actions でも動かしません（ROM をサーバーに置かないため）
- ファミコンは とちゅうの状態をファイルに残せません（nes-py にない）。ドラゴンクエスト1・2 は、Claude が ふっかつのじゅもん を progress のメモに書き写すので、次はタイトルで それを入れて続けます。
  ファミコンの動きは、手で作った小さなテスト用の ROM（ボタンで画面の色が変わるだけ）で確かめた（本物のゲームは この環境に無い）
- できた `gb-play-out/report.md` を読んで、よいものを下の「つぎにやること」に足すと、次の周回で Claude Code が1つずつ持ちこみます
- 持ちこむのは**遊びのしくみだけ**です。キャラクターや技の名前、絵、音楽、文章はまねしません（効果音も `tools/make-sound.py` のオリジナル）
- 1エピソード40手で、画像は1枚 約120トークンです。6エピソードで 240 回 Claude に考えさせます

## つぎにやること（候補）

ポケモン赤・緑から考えた候補は、ひととおり入れた。ドラゴンクエストからの候補は、下の「ドラゴンクエスト（1）を はじめから クリアまで たどる」の表の「候補」（夜のさんぽ・ガイドさんへの報告・遠いほど めずらしい・はじめから見える最後の場所）。`tools/gb-play.py` で実際に遊ばせたまとめ（`gb-play-out/report.md`）から、よいものをここに足す。

1. **西尾の生きものを、もっと出典つきで**：いま西尾ならではの話があるのは、重要野鳥生息地（IBA）の資料で確かめた ケリ・セイタカシギ・スズガモ と、アサリ。矢作川の魚などは、出典を開いて確かめられたら足す
2. **しらべるの手がかりを、もっと人ごとに**：いまは人の見た目ごとに2つずつ。目立つ人（ガイドさん・漁師さんなど）は、npcs.js に その人だけの言い方（1行）を持たせてもよい

済んだもの：呼びとめ（周回1）・聞いた／行った の2段の記録と区切りのほめことば（周回3）・さんぽ仲間のライバル（周回4）・ライバルを歩く地図に立たせる（周回5）・しらべると見つかるまちメモ（周回6）・生きもの手帳（周回7）・西尾の生きもの（周回8）・人のことばの手がかり（周回9）・おまかせ歩きが はじめの1枚 で止まる（周回10）・おとどけもの（周回11）・話したときの知らせを短く（周回12）・いまいる市の まちメモ（周回13）・地区のしるし（周回14）・プレイ画面をシンプルに（周回15）・クリア（殿堂入り）（周回16）・生きもの手帳の賞状（周回17）・クリア後の となりの市町のしるし（周回18）。
「行ったことのある名所へ ひとっとび」は、もうある（操作して移動のとき、名所の窓の「ここへ移動」。周回4で確かめた）。

  殿堂入りのあとだけ、となりの6市町（岡崎・安城・碧南・高浜・幸田・蒲郡）にも しるしが出る。その市町の人（岡崎城の観光ボランティアガイドさん・安城の歴史博物館のガイドさん・

### 周回16（2026-10）：クリア（殿堂入り）

- **持ちこんだしくみ**：赤・緑の、町ごとの しるしを全部集めて 最後に認めてもらい、記録が残って エンディングになる しくみ。これまで にしおさんぽGO には「クリア」がなかった
- 5つの地区のしるしが そろうと「🏯 5つのしるしが そろった！ 西尾市歴史公園（西尾城跡）の観光ボランティアガイドさんに会いに行こう」。ガイドさんと話すと「西尾さんぽ 殿堂入り」（`clearGive`・`showEnding`）。

- Codex の指摘で直したこと：建物のマスがない館の置き場所を敷地の中の長方形に（3×3 まで）／参道の終わりを、置いた本殿・本堂の長方形の正面のすぐ前に／参道は敷地の中のマスだけをたどる道に（くぼんだ敷地で外を通らない）／名所の場所（まん中の 3×3）にある屋根の色つきの小さな建物（250㎡以下で住宅地 Q になったもの）も建物として扱う。あわせて、1マスの建物は敷地の中で 2×2 まで広げてから置き、建物・基壇がはみ出さない大きさに。「教会」でもキリスト教でない所（立正佼成会・金光教・御嶽教・観音・大師・寺・PL・イスラム など）には十字架を描かない。1000か所すべてで、建物・参道・基壇が地面のないマスに出ないことを確かめた
- Codex の2回目の指摘で直したこと：2×2 に広げた建物の長方形ぜんぶに木を植えない（本殿の上に木がかぶらない）／お寺の階段・館の玄関のひさし・教会の塔を長方形の中に。あわせて、ほかの部品もはみ出していないか全部調べて、次の3つを見つけて直した

  - 寄棟の屋根の部品（giant.py の roof）が、横と奥の長さがちがうと ひし形にゆがむ → 四角の向きを先に固定してから のばす
  - 駅舎・見どころの建物の最低の大きさ、神社の屋根のひさし、アートの像の場所（像は入口のマスに）
- 1000か所すべてで、木と地面のほかの部品（建物・屋根・階段・ひさし・参道・お墓・旗など）が地面のないマスに出ないことを確かめた
- Codex の3回目の指摘（運動場の競技面が、くぼんだ敷地で地面の外へはみ出す）で、こんどは木と地面のほかの すべての部品を調べなおし、競技面のほかにも見つけて直した：運動場・小さな池・古墳と山の盛り土は、敷地のマスに入るいちばん大きな長方形の中に／鳥居・山門・門は入口のマスの中に入る大きさで、マスのまん中に（稲荷の鳥居の列もマスの中に）／案内板はとなりの敷地のマスに／灯籠は参道の両わきのマスも敷地のときだけ／駅は線路・ホーム・電車が通るマスを地面に足し、線路は 7×7 マスの中に入る長さに。1000か所すべてで、木と地面のほかの部品が地面のないマスに出ないことを確かめた
- Codex の4回目の指摘（墓地のマスを通る参道にお墓が重なる）で、参道と入口のマスを先に決めてから、そこを除いてお墓を置くようにした。あわせて部品どうしの重なりも調べて直した：灯籠は参道の両わきのマスのまん中に（そのマスには木を植えない）／狐の像は入口から出ていく参道の向きの両わきに／入口と参道の終わりは ほかの建物のマスにしない／建物のマスがないアート（「大狸」のような大きな像）は館でなく像に

### 夜の開発（2026-10-22）

- 運営者のことば：「朝まで開発を続けて」。これまでの表（ドラゴンクエスト・NetHack）に残っていた候補を順に入れた
- **ガイドさんの記録**（昔のドット絵RPGの、王様に話すと「次のレベルまで あと○」と記録してくれる しくみ）：西尾城跡のガイドさんの話の さいごに「📒 記録しといたよ。つぎの レベル9まで あと393pt。しるしは 0/5。いちばん近いのは 西尾のしるしで、あと1か所めぐると もらえるよ。」。しるしが もらえる状態なら だれに会えばいいか、5つそろえば「わしに話しかけてくれりゃあ 殿堂入り」、クリア後は となりの市町のしるしを数える（`game.js` の guideRecord）
- **遠いほど めずらしい**（城から遠いほど よい宝）：西尾城跡のあたり（`CFG.center`）から 4km で キラの絵が 1.5倍、8km で 2倍 出やすい（キラの時間とも かけあわせる）。さかいを こえたら その日1回ずつ「✨ 西尾城跡から 8km こえた！」と知らせる（kiraFar・farNotice）。キラの行の「32回に1回」は、本当の確率を出すようにした（遠いと「16回に1回・遠くまで来たので 出やすい」、7日連続の特別なキラは「特別な1枚」）
- **路地の行き止まり**（NetHack の、通路が ぷつっと終わる所を しらべると 隠し扉）：歩く地図で 道がそのマスで終わる所（となり4マスで 道が1つだけ。`pixel.js` の alleyEnd）に入ると、+3pt と そのあたりの まちメモ1つ。1マス1回・1日3回まで（`game.js` の alleyFind）。まだ しらべていない行き止まりには、歩く地図で 黄色の「？」が小さく はねる（その日の分を見つけおわったら出さない。`pixel.js` の alleyHint）。斜めに描いた道は 角だけで つながるので、まわり8マスを ひとまわり見て 道が1かたまりの所だけにした（Codex の指摘）
- **知らせが たまりすぎない**：プレイテストで、転がり方・バッジ・節目の知らせが8つ以上 待ちの列にたまり、あとの知らせが30秒以上 おくれて出た。待っている知らせが2つ以上あるときは、1つを出しておく時間を 3.8秒 → 2.4秒にした（toastMs）
- **プレイテストの直し**：「かべに押しつけると がたがたする」が main でも落ちていた。押しつけている間に 1こまだけ小さな速さ（0.051）がつくのを、がたがたと見ていた（位置は動いていない）。さいごの1秒の位置のゆれ（0.02マス未満）で見るようにした
- **しるしの2枚**（ポケモンの「2つのうち 1つだけ もらえる」）：地区のしるしを もらって 人の話の窓を閉じると、その地区の題材の めずらしい天気（雪・満月・虹）の絵が2枚出る。えらんだ1枚だけが キラで絵帳に入る（もう1枚は もらえない。えらばずに閉じたら 左の1枚）。えらぶ前にアプリを閉じても、次に開いたとき出す（`game.js` の sealCands・sealPickCheck。「はじめの1枚」の窓 pickFirst を使いまわした）
- **殿堂入りの場所の札**（ドラクエの「城を出ると、最後の城が はじめから見えている」）：殿堂入りするまで、せかいちずの西尾城跡の上に 金色の札「👑 しるし 0/5」（`pixel.js` の goalTag）
- **水べで じっと見る**（ポケモンの「釣りざおで、水べで出会えるものが ふえる」）：歩く地図で 水の となりのマスに 4秒 止まっていると、水の中の生きものに出会う（1.5秒で「👀 水の中を じっと見とる…」）。動くまでは1回だけ、1日2回まで（生きもの手帳の1日5回にも入る。`pixel.js` の waterWatch・`game.js` の watchWater）。歩いて出会う 1/40 の運を待たずに、水べで足を止める理由になる
- **きょうの100歩たんけん**（ポケモンの「歩数の決まった場所で、めずらしいものを探す」）：その日 はじめて歩きだしたら始まり、100歩（1歩＝1マス 8m）のうちに はじめての道を何マス歩けるか。25歩ごとに数を出し、おわったら そのマスの数だけ pt（30まで）と、自己ベストならお祝い。1日1回、遊びはじめた日の次の日から。きろく の きょうのさんぽ にも出す（`game.js` の hundred）
