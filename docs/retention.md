# にしおさんぽGO：遊んだ人の離脱を減らす（2026年10月）

GA4 の数字（`nishio-go/stats.json`）はまだ届いていない（シークレット未設定）ので、まず、はじめて遊ぶ人の流れを4通りヘッドレスのブラウザで動かして、離れそうな所を探した。

## 見つかったこと（直す前）

| 場面 | 起きていたこと | 離脱しやすい理由 |
|---|---|---|
| はじめの画面 | 遊びかたのボタンが、スマホ（390×780）の画面の下にはみ出していた（中身の高さ 970px） | 説明の文を読み切らないとボタンが見えない |
| 操作して遊ぶ | はじめの人は「せかいちず」から始まり、そのあいだは おまかせ歩き が止まる。最初の行き先は約900m先 | 何もしないと、何も起きない。最初のごほうびまでが遠い |
| あるいて遊ぶ（西尾の外） | 「遊べる範囲の外です」と出るだけ | 次にすることがない（設定を開いてモードを切り替えるしかない） |
| あるいて遊ぶ（位置情報を拒否） | 「ブラウザの設定で許可して再読み込み」と出るだけ | 同じく、行きどまり |
| 次の日 | 連続日数のボーナスはあるが、遊んでいる間に「あした何があるか」が見えない。ホーム画面に置けない | もう一度開くきっかけが弱い |

## 直したこと

1. **はじめの画面**：遊びかたのボタンを上に（高さ 633px で、スクロールせずに見える）。くわしい説明は「くわしい遊びかた」にたたんだ
2. **はじめの1分でごほうび**
   - 操作して遊ぶ：歩く地図から始め、主人公から約40mの道に「ようこそ たからばこ」（+30pt とドット絵）を置く。おまかせ歩きも先に開けに行くので、何もしなくても約5秒で最初のごほうびが出る
   - あるいて遊ぶ：遊べる範囲で位置が取れたら「ようこそ」（+30pt とドット絵、次の行き先）
3. **行きづまらない**：位置情報が使えない・遊べる範囲の外のときは、案内パネルに「🎮 操作して遊ぶ に切り替える」ボタン（1タップで遊べる）
4. **あしたも来たくなる**
   - きろく のいちばん上に「📅 あしたのおたのしみ」（連続日数のボーナスの額、新しいクエスト、新しいたからばこ、るすばん）
   - 1日1回、その日2回目のごほうびのあとに、ボーナスの額を知らせる
5. **また開きやすく**：ごほうびを2回もらったら「ホーム画面に追加」をすすめる（7日に1回まで。追加ずみ・ホーム画面から開いているときは出さない）。Android の Chrome などは追加の画面を出し、iPhone の Safari は手順を出す。`nishio-go.webmanifest`・`nishio-go/icon-192.png`・`icon-512.png`

## はかる（GA4 のイベント）

| イベント | いつ | パラメータ |
|---|---|---|
| `intro_view` | はじめの画面を見た（はじめての人） | |
| `game_start` | 遊びかたを選んだ（前からある） | `mode` |
| `first_reward` | はじめてごほうびが出た（この計測より前から遊んでいる人は送らない） | `secs`（遊びかたを選んでからの秒数）、`mode` |
| `play_day` | その日はじめて遊んだ（前からある） | `mode`、`day_n`（はじめて遊んだ日から何日目か。0＝その日。-1＝この計測より前から遊んでいて、はじめての日がわからない人） |
| `session_end` | 画面を離れた | `secs`（遊んだ秒数。はじめての人は遊びかたを選んでから）、`pts`、`rewards`、`day_n`、`mode` |
| `geo_error` / `out_of_range` | 位置情報が使えない／遊べる範囲の外 | `code` |
| `rescue_switch` | 切り替えボタンで操作して遊ぶにした | `why`（`geo`・`range`） |
| `a2hs_shown` / `a2hs_click` / `a2hs_later` / `a2hs_installed` / `a2hs_open` | ホーム画面に追加のおすすめ・結果・ホーム画面から開いた | `how`、`outcome` |

GA4 の「探索」→「目標到達プロセスデータ探索」で、`intro_view` → `game_start` → `first_reward` → `play_day`（`day_n` = 1）と並べると、どこで何割が離れているかが見える。`play_day` を `day_n` ごとに数えると、次の日（1）・1週間後（7）に戻ってきた割合がわかる。

## まだしていないこと

- 数字を見てからの調整（ようこそ のポイント、おすすめを出す回数など）
