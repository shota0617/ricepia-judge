# 亜糊粉層を残せ（精米ゲーム）

近藤米穀店 らいすぴあの精米機をモデルにした、ブラウザで遊べる精米ゲーム。
`game/index.html` を開くだけで動く（外部ライブラリなし、フォントのみ Google Fonts）。

## 遊び方
- 開店前に玄米を3袋（10kg・30kg・10kg）精米する。
- 精米機の出口の抵抗板を、てこの棒に通した円筒の分銅（大3kg・小2kg）で押さえている。
  分銅を棒の先へずらすほど強く押して白く、手前へずらすほど黒く仕上がる。
- 出てきた米を「見る」（色・艶・ルーペで断面）と「触る」（手ざわり・温もり）で確かめて、分銅を加減する。
- 分銅を触れるのは 10kg袋で2回、30kg袋で3回。
- 「見る」では糠受けの糠の色（赤糠→中糠→白糠）も見られる。品種によっては見た目だけだと白く見えるので、手ざわりや糠と合わせて読む。
- 機械は温まるほどよく削れる。「触る」の温もりで先を読む。
- 黒すぎず白すぎず、亜糊粉層を残した米ほど高得点（特A / A / A' / B / B'）。
- 「日替わりの朝」は日付で注文が決まるので、同じ日なら誰が遊んでも同じ3袋になる。結果はコピーして共有できる。
- 右上の「音」で、モーター音と擦れる音（白くなるほど高く鋭くなる）を鳴らせる。

## 調整したいとき
`index.html` 冒頭の `VARIETIES` に品種ごとの値がある。
- `nuka`：ぬか層のやわらかさ（伝票に表示、1〜5）
- `ease`：分銅の効きやすさ（大きいほど削れやすい）
- `look`：見た目のクセ（＋だと実際より白く見える）

値はゲーム用の仮の数字なので、店の実感に合わせて書き換えてよい。
