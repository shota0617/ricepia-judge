精米品質AI判定とは

「らいすぴあ 精米品質AI判定」は、精米の写真をAIが解析し、品質を12項目・各0〜100点で採点してS・A・B・C・Dの5段階グレードを判定するWebツールです。

判定基準は、創業130余年の老舗米店近藤米穀店「らいすぴあ」の5代目が定めたもの。米店が実際に出荷前に見ているポイントを、スマートフォンで撮った写真から確認できます。

  • 判定内容：12項目の点数（0〜100点）、S〜Dのグレード、総合コメント、おすすめ用途
  • 使うもの：精米の写真1枚とAnthropic APIキー（ツールは無料・インストール不要）
  • 判定AI：AnthropicのClaude（画像を解析して採点）
  • 基準：近藤米穀店 らいすぴあ（愛知県西尾市）独自の基準。国の農産物検査の等級とは別物です

判定する12項目

外観品位

  1. 白度：米粒全体の白さと透明感（乳白・腹白・背白がないほど高得点）
  2. 光沢：米粒表面のツヤ。精米直後の新鮮な輝き
  3. 粒揃い：粒の大きさ・形・厚みの均一性
  4. 粒の充実度：品種標準に対する充実度（小粒・未熟粒の少なさ）

欠陥粒

  1. 割れ・欠け：胴割れ・砕け米・欠け米の少なさ
  2. 着色粒：茶・黒・紫などの変色粒やカメムシ被害粒の少なさ
  3. 乳白粒・未熟粒：白濁した未熟粒の少なさ
  4. 異物混入：石・わら・もみ・虫などの有無（混入ありは0点）

精米品質

  1. 精米仕上がり：糠残りがなく均一に精米されているか
  2. 鮮度感：酸化・黄ばみなど変質の少なさ
  3. 品種純度：異品種の混入がなく揃っているか
  4. 炊飯適性予測：写真から推測する炊き上がり品質

グレード基準（S〜D）

S
最高品質・贈答用。主要項目すべて90点以上。
A
優秀・直売向け。主要項目80点以上で、光沢・粒揃いが良好。
B
良品・家庭用。主要項目70点以上。
C
標準・業務用／加工向け。一部項目に課題あり。
D
要改善。出荷前に再精米・選別を検討。

異物混入や大量の着色粒など致命的な欠陥がある場合は、他の項目が良くてもC以下になります。

使い方

  1. Anthropic APIキーを入力して開始
  2. 精米をトレーに均一に広げ、明るい場所で真上から撮影
  3. 品種を選択（任意。未選択ならAIが推測）
  4. 「品質を判定する」で12項目の点数・グレード・おすすめ用途を確認。レポートの印刷も可能

対応している主な品種

つや姫、コシヒカリ（富山・長野・愛知）、雪若丸、夢しずく、ひとめぼれ、ミルキークイーン、ハツシモ、あいちのかおり、にこまる、あいちのこころ、ハイガ米・5分づき米・玄米など。品種がわからない場合もAIが写真から推測します。

よくある質問

精米の品質は何で判定しますか？

白度・光沢・粒揃い・粒の充実度（外観品位）、割れ欠け・着色粒・乳白粒/未熟粒・異物混入（欠陥粒）、精米仕上がり・鮮度感・品種純度・炊飯適性予測（精米品質）の12項目を各0〜100点で採点します。

グレードS・A・B・C・Dの違いは？

S：最高品質・贈答用（主要項目すべて90点以上）。A：優秀・直売向け（主要項目80点以上）。B：良品・家庭用（主要項目70点以上）。C：標準・業務用／加工向け（一部項目に課題あり）。D：要改善（出荷前に再精米・選別を検討）。異物混入や大量の着色粒など致命的な欠陥がある場合はC以下になります。

国の農産物検査の等級（1等・2等など）と同じですか？

違います。S〜Dは近藤米穀店 らいすぴあ独自の精米品質の基準です。農産物検査法に基づく等級（1等〜3等・規格外）は、登録検査機関が玄米などを検査して格付けするもので、このツールの判定は公的な検査や証明の代わりにはなりません。

玄米や分づき米も判定できますか？

品種の選択肢から玄米・5分づき米・ハイガ米を選んで判定できます。ただし白度や精米仕上がりなどは白米を想定した項目のため、玄米・分づき米の結果は参考値としてご覧ください。

利用料金はかかりますか？

ツール自体は無料です。判定にはご自身のAnthropic APIキーが必要で、API利用料はAnthropicの料金体系に従います。

スマートフォンだけで使えますか？

使えます。アプリのインストールは不要で、スマートフォンやPCのWebブラウザから撮影・判定・レポートの印刷まで行えます。

APIキーや写真は保存されますか？

APIキーはブラウザ内でのみ使用され保存されません。写真は判定のためにAnthropic APIへ送信されます。管理者が登録した学習データはその端末のブラウザ内に保存されます。

判定結果はどのくらい正確ですか？

写真1枚からの推定のため、照明や撮影角度で結果が変わります。写真で判断できない項目は中間値になります。米店の基準写真を学習データとして登録すると、判定がその店の基準に近づきます。

きれいに判定するための撮影のコツは？

明るい場所で、精米をトレーに均一に広げ、真上から水平に、ピントを合わせてブレを防いで撮影してください。
