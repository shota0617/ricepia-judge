この会議は、内容の確認のために発言が文字起こしされることがあります。文字起こし中は画面上部に「🔴 文字起こし中」と表示されます。
1ミーティングを開く開始すると招待リンクができます。LINEやメールでお客様に送るだけで、ブラウザから参加できます。
2自動で文字起こし参加者それぞれの端末が自分の発言を文字にし、話者名つきで全員の画面に共有します。字幕としても表示されます。
3AIがニーズを整理終了後、「要望分析」で明示・潜在ニーズ、根拠の発言、受け入れ条件、確認事項、次のアクションをまとめます。
4開発へつなぐニーズはバックログに溜まり、同じ要望は自動でまとまります。GitHub Issueや開発依頼書（Claude Code向けの依頼文つき）にできます。
動作環境・プライバシーについて
・映像と音声は参加者どうしで直接やりとりします（WebRTC）。接続の仲介には PeerJS の公開サーバーを使います。自社のサーバーを使う場合は URL に ?peerhost=ホスト名&peerport=443 を付けて開きます。
・少人数（目安6人まで）の打ち合わせ向けです。人数が増えると各端末の通信量が増えます。
・自動文字起こしはブラウザの音声認識機能を使います（Chrome / Edge / Safari）。Chrome では音声がブラウザ提供元の認識サーバーに送られます。ミュート中は文字起こしも止まります。
・「⏺ 録音」で会議の音声（全員分）を録音できます。録音は押した人の端末のブラウザ内に保存され、要望分析の画面で発言の時刻から聞き直せます。録音中は全員の画面に「⏺ 録音中」と表示されます。
・文字起こし・議事録・バックログは、この端末のブラウザ内にだけ保存されます（サーバーには送りません）。AI分析を実行したときだけ、文字起こしが Anthropic API に送られます。
・会議の前に、文字起こしをすることをお客様に一言お伝えください。

要望分析

会議の文字起こしから、AIがお客様のニーズ（はっきり言われたこと／言葉の裏にある本当の困りごと）を、根拠の発言つきで整理します。

設定は「開発バックログ」の「⚡ 自動化」。会議が終わると自動で動きます
外部の文字起こしを取り込む（Zoom・Google Meet・Teams・録音アプリなど）
文字起こしと同じ会議の録音を付けると、発言の時刻から聞き直せます（この端末にだけ保存）。
Zoom の「音声トランスクリプト（.vtt）」や「名前: 発言」形式のテキストを読み取ります。
書いておくと、AIが既存の仕組みとの関係まで踏まえて整理します。
ここに含まれない話者を「お客様」として読みます。この画面のミーティングは参加区分が自動で付きます。

準備（1回だけ）
1. 下の「GitHubリポジトリ」に開発先（例：shota0617/ricepia-judge）を入れる
2. GitHub →「Settings」→「Developer settings」→「Fine-grained tokens」で、そのリポジトリだけ・Issues：Read and write のトークンを作り、左に貼って「接続を確認」
3. ④を使うときは、開発先リポジトリに .github/workflows/claude-dev.yml（このリポジトリにあります）を置き、「Settings」→「Secrets and variables」→「Actions」に ANTHROPIC_API_KEY を登録、Claude GitHub App をインストール
公開リポジトリの場合、Issue にはお客様の名前と発言を載せません。
