# にしおさんぽGO の音楽（BGM・効果音）

このフォルダに mp3 を置くと、ゲームで流れます。ファイルが無い曲は鳴らさないだけなので、そろっていなくても動きます。

ふだんの曲は、雨なら「雨」、夜（19〜5時）は「夜」、朝（5〜9時）は「朝」、夕方（16〜19時）は「夕方」、それ以外は「昼」の曲から、1曲流し終わるたびに次の曲へ進みます（順番は開くたびにまぜます。無い曲は飛ばします）。
「昼」は `field`・`field2`・`field3` とアルバムの昼60曲、「朝」は `morning` とアルバムの朝10曲、のように、もとの曲とアルバムの曲がまざります。1分ごとに時間帯と天気を見て、変わったら曲を変えます。せかいちずは `world`。「せってい」に いまの曲名と「⏭ 次の曲」ボタンがあります。

新しい曲の旋律は、`make-sound.py` の `compose()` がコード進行に合わせて作ります（強い拍はコードの音、弱い拍は音階の音、はじめの句を終わりにくり返し、主音で終わる）。
アルバム「西尾の音」100曲は、西尾らしく聞こえるように、日本の音階（ヨナ抜き・民謡音階・律音階・都節）と、篠笛・琴・三味線・尺八・大太鼓・締太鼓・鉦・拍子木に似せたファミコン風の音で作っています。和音の進行ではなく、主音と5度の持続音の上に旋律をのせ（日本の音楽によくある形）、旋律は `compose_jp()` が作ります（4小節の句を A・A'・B・A に並べ、となりの音へ動き、句の終わりは核音〈主音・4度・5度〉でのばし、最後は主音。笛には前打音）。曲調は10種類：まつり気分（笛・大太鼓・締太鼓・鉦）・おどり（音頭のドン・ドドンと拍子木、三味線のかき鳴らし）・さんぽ（琴の分散音と手びょうし）・うた（三味線の旋律を笛がなぞる）・の波（波の音と琴）・かけあし（速い三味線）・の朝（律音階と鳥の声）・の夕ぐれ（琴と都節）・の夜（尺八と虫の声）・の雨（琴と雨つぶ）。
題名は、ゲームの名所・名物・祭り（`spots.json` などにあるもの：西尾城・岩瀬文庫・抹茶・茶畑・三河湾・佐久島・一色大提灯・鳥羽の火祭り・てんてこ祭・おまんと祭 など）の名前に曲調の言葉をつけたもので、曲調に合うものだけを組み合わせます。**どれもこのリポジトリで作ったオリジナルの曲で、その祭りや土地で実際に演奏される音楽（祭ばやし・民謡など）ではありません。**

110曲とも `python3 tools/make-sound.py` で作り直せる（`python3 tools/make-sound.py night rain` のように1曲ずつも）オリジナルのファミコン風の音（矩形波・三角波・ノイズだけ）です。作曲もこのリポジトリで行ったので、お店の宣伝にもそのまま使えます。

- 音楽は最初のタップ（はじめの画面のボタンなど）から流れます（ブラウザの決まりで、タップ前は音を出せません）。
- 「せってい」の「🎵 音楽（BGM）」で、いつでも消せます。効果音のあいだは BGM を小さくします。
- スマホの通信量を減らすため、BGM は 1〜2分・1曲3MB くらいまでがおすすめです（長い曲は短く切ってから置きます）。

## Suno AI の曲に差し替えるとき

1. Suno の「作成」で「アドバンスド」（カスタム）を選び、「インストゥルメンタル」（歌なし）をオンにする。
2. 下の「スタイル」をそのまま貼り、「タイトル」を入れて作成する。
3. 気に入った方を mp3 でダウンロードし、ファイル名を `field.mp3` / `world.mp3` にしてこのフォルダに置く。

ゲームや作曲者の名前（特定の作品名）は入れません。Suno が受け付けないことがあり、また既存の曲に似せないためです。
