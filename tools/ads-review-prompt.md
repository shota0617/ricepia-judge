## 見ること

1. **ポリシー・法令**：Google広告のポリシー（不実表示・編集）と景品表示法（優良誤認・有利誤認）。根拠のいる言い方（安い・最安・一番・〇年続く・創業〇年・価格・産年・品種・産地）。
2. **季節・期限**：今日は {{TODAY}}。夏向けの文、「新米」を 12月31日 をこえて出すこと、「新米予約」「入荷速報」など もう古い文、年が明けると変わる数字（創業134年 など）。
3. **成果の目標とのずれ**：アカウントの目標は「LINE 友だち追加」。その目標に合っているか、近くの人（西尾・安城・岡崎・碧南）に当たる文か。
4. **広告としての出来**：重複・言いかえだけの見出し、ブランド名のゆれ（らいすぴあ・秀幸／近藤米穀店 らいすぴあ／翔米）、文字数、見出しが単独で意味が通るか、アセットの足りなさ（サイトリンク・縦長動画・横長ロゴなど）、表示0回のキャンペーン。
5. **数字**：表示・クリック・費用・CV から読めること（読めないことは言わない）。

## 書き方

- 日本語で、小学生にも読める言い方で。
- 指摘は1件ずつ。**どの広告の、どの文か**（キャンペーン／アセットグループ／見出し・説明文などと、その文そのもの）を必ず書く。
- 重さは3段階：`must`（止める・直さないと不承認や法令違反・事実とちがうおそれ）／`should`（成果が上がる見込みが高い）／`nit`（好み・小さい）。
- 直し方があるときは、そのまま貼れる文を書き、全角=2で数えた文字数（例 24/30）をそえる。
- 事実を確かめないと決められないことは「お店に確かめること」として分ける（推測で言い切らない）。
- 最後に「この3つを先にやる」を3行で。

返事は Markdown だけ（前置きなし）。次の見出しで：

```
## まとめ（先にやる3つ）
## must
## should
## nit
## お店に確かめること
```
